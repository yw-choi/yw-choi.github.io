학부 때 했던 고민들 (2010–2016)

  • 일단 난 대학원에 갈 거야.. (정답은 없다. 선택과 책임)
  • 물리학? 천문학? → 물리학이 더 재미있었다
  • 무슨 분야? → 내가 잘하는 것, 너무 길이 좁아 보이지 않는 곳
  • 자대 대학원? 유학?
    • 국내: 익숙함, 국내 학계 복귀 시 유리
    • 유학: 넓은 선택의 폭, 불확실성

대학원 전반 (2016–2018)

  • 연구주제는 뭘로 하지?
  • '멋있어 보이는' 것과 '중요한' 것은 다르다
  • 학생 = 지식의 소비자 vs. 연구자 = 지식의 생산자
  • 대학원에서 중요한 것들:
    • Input: 논문 읽기, 학회 발표 듣기
    • Output: 논문 쓰기
    • Implicit: 평판 쌓기 (지도교수, 학회, 동료)

  • 해외 포닥 찾기: 논문 홍보, 학회 활동, Reference의 중요성

  • 가장 효과적인 방법: Reference
  • 포닥 채용은 입시나 공채가 아니다. PI의 funding 상황, 의도가 전부
  • 실적이 압도적이라면 상관 없음
  • Reference 만들기: 지도교수의 인맥, 학회 참석, 논문 홍보
