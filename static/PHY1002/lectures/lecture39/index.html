39장: 물질파 심화

More About Matter Waves

이번 장에서 배울 내용

38장에서 전자가 물질파(matter wave) 로 행동한다는 것을 배웠다. 이번 장에서는 물질파를 좁은 공간에 가두면 무슨 일이 일어나는지 살펴본다.

  • 전자를 1차원 우물에 가두면 → 에너지가 양자화(quantization) 된다
  • 갇힌 전자의 파동함수(wave function) 와 발견 확률
  • 현실적인 유한 우물(finite well), 2차원·3차원 트랩
  • 자연이 만든 전자 트랩: 수소 원자(hydrogen atom)

20세기 초의 가장 큰 수수께끼 — "원자는 왜 무너지지 않고, 왜 특정한 색의 빛만 내는가?" — 를 이번 장에서 풀게 된다.

실생활 속 갇힌 전자: QLED TV

QLED TV의 'Q'는 양자점(quantum dot) 이다. 지름 수 나노미터짜리 반도체 알갱이 속에 전자가 갇혀 있다.

같은 물질인데도 알갱이의 크기만 바꾸면 색이 바뀐다. 자외선을 비추면 작은 알갱이는 파란빛, 큰 알갱이는 붉은빛을 낸다. 왜 그럴까? 이번 장의 핵심 공식 하나로 설명된다.

이번 장의 핵심 아이디어

구속 원리(confinement principle) :

파동을 유한한 영역에 가두면 양자화 된다 — 즉, 불연속적인 상태들만 허용되고 각 상태는 정해진 에너지를 갖는다.

  • 끈에 묶인 파동이든, 전자의 물질파든 모든 파동 에 적용된다
  • 갇힌 전자는 아무 에너지나 가질 수 없고, 에너지 준위(energy level) 위에만 있을 수 있다
  • 준위 사이를 오갈 때 빛(광자)을 흡수하거나 방출한다

39.1 갇힌 전자의 에너지

끈의 정상파 복습 (16장)

무한히 긴 끈에는 어떤 진동수의 진행파(traveling wave) 든 만들 수 있다. 그러나 길이 LLL인 끈의 양 끝을 고정하면 정상파(standing wave) 만 가능하다.

양 끝이 마디(node) 가 되어야 하므로, 반파장이 정수 개 들어가야 한다:

L=nλ2,n=1,2,3,…L = n\frac{\lambda}{2}, \qquad n = 1, 2, 3, \dotsL=n2λ​,n=1,2,3,…

양자수

허용된 각 정상파 상태의 변위는

yn(x)=Asin⁡ ⁣(nπLx),n=1,2,3,…y_n(x) = A \sin\!\left(\frac{n\pi}{L}x\right), \qquad n = 1, 2, 3, \dotsyn​(x)=Asin(Lnπ​x),n=1,2,3,…

  • 정수 nnn이 상태를 구분한다 → nnn을 양자수(quantum number) 라 부른다
  • 파동을 가두는 순간, 연속적이던 진동수가 불연속적 으로 바뀐다

물질파도 파동이다. 따라서 전자를 가두면 전자의 에너지도 양자화 되어야 한다. 이것이 이번 장 전체를 관통하는 논리이다.

1차원 전자 트랩: 무한 퍼텐셜 우물

전자를 xxx축 위 길이 LLL 구간에 가두는 가장 단순한 모형:

  • 0<x<L0 < x < L0<x<L에서 퍼텐셜 에너지 U=0U = 0U=0
  • x<0x < 0x<0, x>Lx > Lx>L에서 U→∞U \to \inftyU→∞ (절대 넘을 수 없는 벽)

이를 무한 퍼텐셜 우물(infinite potential well) 이라 한다. 이상화된 모형이지만, 실제로 실험실에서는 전자 하나를 트랩에 가둬 몇 달씩 보관하며 정밀 측정을 하기도 한다.

갇힌 전자의 드브로이 파장

우물 벽에서 전자의 물질파는 마디 가 되어야 한다. 끈의 정상파와 똑같이:

λ=2Ln,n=1,2,3,…\lambda = \frac{2L}{n}, \qquad n = 1, 2, 3, \dotsλ=n2L​,n=1,2,3,…

이 λ\lambdaλ를 드브로이 파장(de Broglie wavelength) 으로 해석한다. 비상대론적 전자는 K=p2/2mK = p^2/2mK=p2/2m이고, 우물 안에서 U=0U=0U=0이므로 전체 에너지는 E=KE = KE=K:

λ=hp=h2mE\lambda = \frac{h}{p} = \frac{h}{\sqrt{2mE}}λ=ph​=2mE​h​

이 두 식을 결합하면 허용되는 에너지가 나온다.

에너지 준위 유도

정상파 조건에서 운동량이 양자화된다:

p=hλ=h2L/n=nh2Lp = \frac{h}{\lambda} = \frac{h}{2L/n} = \frac{nh}{2L}p=λh​=2L/nh​=2Lnh​

이를 E=p2/2mE = p^2/2mE=p2/2m에 대입하면:

E=12m(nh2L)2=n2h28mL2E = \frac{1}{2m}\left(\frac{nh}{2L}\right)^2 = \frac{n^2 h^2}{8mL^2}E=2m1​(2Lnh​)2=8mL2n2h2​

En=(h28mL2)n2,n=1,2,3,…\boxed{E_n = \left(\frac{h^2}{8mL^2}\right)n^2, \qquad n = 1, 2, 3, \dots}En​=(8mL2h2​)n2,n=1,2,3,…​

전자는 이 값들 사이의 에너지는 절대 가질 수 없다. n=1n=1n=1과 n=2n=2n=2의 중간쯤 되는 에너지는 허용되지 않는다.

에너지 준위 다이어그램

L=100 pmL = 100\ \mathrm{pm}L=100 pm (원자 크기 정도)인 우물의 허용 에너지:

  • n=1n=1n=1: 바닥상태(ground state) — 전자가 가장 선호하는 상태
  • n≥2n \ge 2n≥2: 들뜬상태(excited state) — n=2n=2n=2가 첫째 들뜬상태
  • 에너지가 n2n^2n2에 비례하므로 위로 갈수록 준위 간격이 벌어진다

에너지 변화: 양자 도약

전자는 준위에서 준위로만 이동할 수 있다. 이를 양자 도약(quantum jump) 또는 전이(transition)라 한다.

ΔE=Ehigh−Elow\Delta E = E_{\text{high}} - E_{\text{low}}ΔE=Ehigh​−Elow​

  • 올라가려면 외부에서 정확히 ΔE\Delta EΔE만큼 에너지를 받아야 한다
  • 들뜬 전자는 오래 머물지 않고 곧 탈들뜸(de-excite) 하여 내려온다
  • 내려오는 경로는 여러 가지 — 한 번에 점프하거나, 중간 준위를 거친다

광자의 흡수와 방출

전자가 빛으로 에너지를 주고받을 때, 광자(photon) 한 개의 에너지가 정확히 준위 차와 같아야 한다:

hf=hcλ=ΔE=Ehigh−Elow\boxed{hf = \frac{hc}{\lambda} = \Delta E = E_{\text{high}} - E_{\text{low}}}hf=λhc​=ΔE=Ehigh​−Elow​​

  • 흡수(absorption) : 광자를 삼키고 위 준위로 점프
  • 방출(emission) : 광자를 내놓고 아래 준위로 점프
  • 광자 에너지가 어떤 ΔE\Delta EΔE와도 맞지 않으면 흡수 자체가 불가능

따라서 갇힌 전자가 주고받는 빛은 특정 파장들만 가능하다. 이것이 스펙트럼선의 기원이다.

39.2 갇힌 전자의 파동함수

파동함수

슈뢰딩거 방정식을 무한 우물에 대해 풀고, 벽에서 파동함수가 0이어야 한다는 경계 조건을 적용하면:

ψn(x)=Asin⁡ ⁣(nπLx),n=1,2,3,…(0≤x≤L)\psi_n(x) = A \sin\!\left(\frac{n\pi}{L}x\right), \qquad n = 1, 2, 3, \dots \quad (0 \le x \le L)ψn​(x)=Asin(Lnπ​x),n=1,2,3,…(0≤x≤L)

39.3 유한 우물 속 전자

현실적인 우물: 깊이가 유한하다

무한히 깊은 우물은 이상화이다. 실제 우물은 깊이가 유한한 값 U0U_0U0​이다. 이를 유한 퍼텐셜 우물(finite potential well) 이라 한다.

이제는 끈의 정상파 유비가 통하지 않는다 — 벽에서 파동함수가 꼭 0이 된다는 보장이 없기 때문이다. 슈뢰딩거 방정식(Schrödinger's equation) 을 직접 풀어야 한다:

d2ψdx2+8π2mh2[E−U(x)]ψ=0\frac{d^2\psi}{dx^2} + \frac{8\pi^2 m}{h^2}\left[E - U(x)\right]\psi = 0dx2d2ψ​+h28π2m​[E−U(x)]ψ=0

벽 속으로 스며드는 파동함수

U0=450U_0 = 450U0​=450 eV, L=100L = 100L=100 pm인 유한 우물을 풀면:

  • 파동함수가 벽 안으로 침투(penetration) 하여 지수적으로 감소한다
  • 고전물리로는 절대 못 가는 영역에서 전자가 발견될 수 있다 (38장의 터널링과 같은 현상)
  • nnn이 클수록(에너지가 높을수록) 더 깊이 스며든다

유한 우물의 에너지 준위

파동이 벽으로 새어 나가면 그만큼 파장 λ\lambdaλ가 길어진다. λ=h/2mE\lambda = h/\sqrt{2mE}λ=h/2mE​이므로 에너지는 낮아진다.

39.4 2차원·3차원 전자 트랩

나노결정: 크기가 색을 결정한다

반도체를 나노미터 크기 알갱이(나노결정, nanocrystallite)로 만들면, 각 알갱이가 전자를 가두는 퍼텐셜 우물이 된다.

En=(h2/8mL2)n2E_n = (h^2/8mL^2)n^2En​=(h2/8mL2)n2에서 우물 폭 LLL이 작아지면 준위 간격이 커진다. 광자를 흡수하려면 문턱 에너지 EtE_tEt​ 이상이 필요하므로, 문턱 파장은

λt=chEt\lambda_t = \frac{ch}{E_t}λt​=Et​ch​

  • 알갱이가 작을수록 → EtE_tEt​ 증가 → λt\lambda_tλt​ 감소
  • 문턱보다 긴 파장은 흡수되지 않고 산란 되어 우리 눈에 보인다
  • 같은 CdSe 가루라도: 큰 알갱이는 빨강, 작은 알갱이는 노랑 으로 보인다

양자점: 인공 원자

양자점(quantum dot) 은 반도체 공정으로 만든 인공 전자 트랩이다. 원자처럼 불연속 에너지 준위를 갖기에 "인공 원자"라 불린다.

  • 반도체 박막을 절연층 사이에 끼운 샌드위치 구조 — 가운데 층이 우물이 된다
  • 전압으로 전자를 한 개씩 넣고 뺄 수 있다 — 갇힌 전자 수를 제어
  • QLED 디스플레이 : 양자점 크기로 발광색을 정밀 조절 (작은 점 = 파랑, 큰 점 = 빨강)
  • STM 탐침으로 금속 표면에 원자들을 원형으로 배열한 양자 울타리(quantum corral) 안에서도 전자 물질파의 물결무늬가 실제로 관측되었다

2차원 우물: 직사각 코랄

전자가 xyxyxy평면의 직사각형 영역(Lx×LyL_x \times L_yLx​×Ly​)에 갇히면, 물질파가 두 방향 각각 에 대해 정상파 조건을 만족해야 한다. 양자수가 두 개(nxn_xnx​, nyn_yny​) 필요하다:

ψnx,ny=2Lxsin⁡ ⁣(nxπLxx)2Lysin⁡ ⁣(nyπLyy)\psi_{n_x,n_y} = \sqrt{\frac{2}{L_x}}\sin\!\left(\frac{n_x\pi}{L_x}x\right)\sqrt{\frac{2}{L_y}}\sin\!\left(\frac{n_y\pi}{L_y}y\right)ψnx​,ny​​=Lx​2​​sin(Lx​nx​π​x)Ly​2​​sin(Ly​ny​π​y)

에너지는 각 방향에 따로 갇혔을 때 에너지의 합 이다:

Enx,ny=h28m(nx2Lx2+ny2Ly2)\boxed{E_{n_x,n_y} = \frac{h^2}{8m}\left(\frac{n_x^2}{L_x^2} + \frac{n_y^2}{L_y^2}\right)}Enx​,ny​​=8mh2​(Lx2​nx2​​+Ly2​ny2​​)​

nxn_xnx​, nyn_yny​는 각각 독립적으로 1,2,3,…1, 2, 3, \dots1,2,3,… 값을 가진다.

정사각 우물과 축퇴

Lx=Ly=LL_x = L_y = LLx​=Ly​=L인 정사각 우물에서는

Enx,ny=h28mL2(nx2+ny2)E_{n_x,n_y} = \frac{h^2}{8mL^2}\left(n_x^2 + n_y^2\right)Enx​,ny​​=8mL2h2​(nx2​+ny2​)

(1,2)(1,2)(1,2)와 (2,1)(2,1)(2,1)은 서로 다른 상태 이지만 에너지는 같다. 이런 상태들을 축퇴(degenerate) 되었다고 한다. 뜻밖에도 (1,4)(1,4)(1,4) 상태(17)가 (3,3)(3,3)(3,3) 상태(18)보다 에너지가 낮다.

3차원 상자

3차원 직육면체 상자(Lx×Ly×LzL_x \times L_y \times L_zLx​×Ly​×Lz​)에 가두면 양자수가 세 개:

Enx,ny,nz=h28m(nx2Lx2+ny2Ly2+nz2Lz2)E_{n_x,n_y,n_z} = \frac{h^2}{8m}\left(\frac{n_x^2}{L_x^2} + \frac{n_y^2}{L_y^2} + \frac{n_z^2}{L_z^2}\right)Enx​,ny​,nz​​=8mh2​(Lx2​nx2​​+Ly2​ny2​​+Lz2​nz2​​)

  • 차원마다 정상파 조건 하나씩 → 양자수 하나씩
  • 정육면체(Lx=Ly=LzL_x = L_y = L_zLx​=Ly​=Lz​)에서는 축퇴가 더 풍부해진다
  • 광자 흡수·방출 규칙은 1차원과 동일: hf=ΔEhf = \Delta Ehf=ΔE

39.5 수소 원자

수소 원자는 자연이 만든 전자 트랩

지금까지는 인공 트랩이었다. 이제 자연의 트랩 — 수소 원자 를 보자. 전자는 양성자의 쿨롱 인력에 의해 갇혀 있다:

U(r)=−e24πε0rU(r) = -\frac{e^2}{4\pi\varepsilon_0 r}U(r)=−4πε0​re2​

  • 3차원이고, 깊이가 유한하고, 벽이 rrr에 따라 서서히 변하는 트랩
  • 20세기 초의 수수께끼: 수소는 가시광에서 딱 네 가지 파장 (656, 486, 434, 410 nm)만 방출한다. 왜?
  • 그리고 전자는 왜 양성자로 끌려 들어가 붕괴하지 않는가?

보어 모형 (1913)

닐스 보어는 두 가지 (당시로선 근거 없는) 대담한 가정을 세웠다.

  1. 전자는 양성자 주위를 원운동 한다 (행성 모형)
  2. 각운동량이 양자화된다:

L=nℏ,n=1,2,3,…(ℏ=h2π)L = n\hbar, \qquad n = 1, 2, 3, \dots \qquad \left(\hbar = \frac{h}{2\pi}\right)L=nℏ,n=1,2,3,…(ℏ=2πh​)

이 모형은 수소의 에너지 준위는 정확히 맞혔지만, 그 외에는 거의 다 틀렸다. 그래도 역사적 출발점으로 따라가 볼 가치가 있다.

보어 반지름 유도 1: 뉴턴 제2법칙

원운동하는 전자에 작용하는 구심력은 쿨롱 힘이다. 반지름 방향으로 뉴턴 제2법칙을 쓰면:

14πε0e2r2=mv2r\frac{1}{4\pi\varepsilon_0}\frac{e^2}{r^2} = m\frac{v^2}{r}4πε0​1​r2e2​=mrv2​

각운동량 양자화 조건 L=mvr=nℏL = mvr = n\hbarL=mvr=nℏ에서:

v=nℏmrv = \frac{n\hbar}{mr}v=mrnℏ​

이제 vvv를 뉴턴 제2법칙 식에 대입하면 rrr만 남는다.

보어 반지름 유도 2: 궤도 반지름의 양자화

e24πε0r2=mr(nℏmr)2=n2ℏ2mr3\frac{e^2}{4\pi\varepsilon_0 r^2} = \frac{m}{r}\left(\frac{n\hbar}{mr}\right)^2 = \frac{n^2\hbar^2}{mr^3}4πε0​r2e2​=rm​(mrnℏ​)2=mr3n2ℏ2​

양변에 r3r^3r3을 곱하고 정리하면 (ℏ=h/2π\hbar = h/2\piℏ=h/2π):

r=4πε0n2ℏ2me2=h2ε0πme2 n2=a n2r = \frac{4\pi\varepsilon_0 n^2 \hbar^2}{me^2} = \frac{h^2\varepsilon_0}{\pi m e^2}\,n^2 = a\,n^2r=me24πε0​n2ℏ2​=πme2h2ε0​​n2=an2

a=h2ε0πme2=5.29×10−11 m≈52.9 pm\boxed{a = \frac{h^2\varepsilon_0}{\pi m e^2} = 5.29 \times 10^{-11}\ \mathrm{m} \approx 52.9\ \mathrm{pm}}a=πme2h2ε0​​=5.29×10−11 m≈52.9 pm​

aaa를 보어 반지름(Bohr radius) 이라 한다. 전자는 이보다 안쪽 궤도를 가질 수 없다 — 원자가 붕괴하지 않는 이유(보어의 답).

에너지 양자화 유도

궤도의 역학적 에너지는 E=K+UE = K + UE=K+U:

E=12mv2−e24πε0rE = \frac{1}{2}mv^2 - \frac{e^2}{4\pi\varepsilon_0 r}E=21​mv2−4πε0​re2​

뉴턴 제2법칙 식에서 mv2=e2/4πε0rmv^2 = e^2/4\pi\varepsilon_0 rmv2=e2/4πε0​r이므로 K=e2/8πε0rK = e^2/8\pi\varepsilon_0 rK=e2/8πε0​r:

E=e28πε0r−e24πε0r=−e28πε0rE = \frac{e^2}{8\pi\varepsilon_0 r} - \frac{e^2}{4\pi\varepsilon_0 r} = -\frac{e^2}{8\pi\varepsilon_0 r}E=8πε0​re2​−4πε0​re2​=−8πε0​re2​

여기에 r=an2=(h2ε0/πme2)n2r = an^2 = (h^2\varepsilon_0/\pi me^2)n^2r=an2=(h2ε0​/πme2)n2을 대입하면:

En=−me48ε02h2 1n2,n=1,2,3,…\boxed{E_n = -\frac{me^4}{8\varepsilon_0^2 h^2}\,\frac{1}{n^2}, \qquad n = 1, 2, 3, \dots}En​=−8ε02​h2me4​n21​,n=1,2,3,…​

  • 에너지가 음수 : 속박 상태라는 뜻. E≥0E \ge 0E≥0이면 전자가 풀려나 이온화(ionization) 된다
  • 놀랍게도 슈뢰딩거 방정식을 제대로 풀어도 같은 EnE_nEn​ 이 나온다 — 보어의 행운

수소 스펙트럼: 리드버그 공식

준위 사이 전이에서 hf=ΔEhf = \Delta Ehf=ΔE이므로, f=c/λf = c/\lambdaf=c/λ와 EnE_nEn​ 공식을 결합하면:

hcλ=Ehigh−Elow=me48ε02h2(1nlow2−1nhigh2)\frac{hc}{\lambda} = E_{\text{high}} - E_{\text{low}} = \frac{me^4}{8\varepsilon_0^2 h^2}\left(\frac{1}{n_{\text{low}}^2} - \frac{1}{n_{\text{high}}^2}\right)λhc​=Ehigh​−Elow​=8ε02​h2me4​(nlow2​1​−nhigh2​1​)

양변을 hchchc로 나누면:

RRR는 리드버그 상수(Rydberg constant) 이다. 수소가 내고 삼키는 모든 빛의 파장이 이 한 줄에 담겨 있다.
