Electric Fields

지난 시간 복습: 쿨롱 법칙

두 점전하 사이의 힘은 쿨롱 법칙으로 계산할 수 있었다.

F=14πε0∣q1∣∣q2∣r2F = \frac{1}{4\pi\varepsilon_0}\frac{|q_1||q_2|}{r^2}F=4πε0​1​r2∣q1​∣∣q2​∣​

그런데 여기에는 찜찜한 질문이 하나 남아 있다.

두 전하는 서로 접촉하지 않는다. 그런데 전하 1은 전하 2가 저기 있다는 걸 어떻게 "알고" 힘을 받을까?

이런 원격 작용(action at a distance) 의 수수께끼가 이번 장의 출발점이다.

답: 공간 자체가 변한다

이 질문에 대한 물리학의 답은 다음과 같다.

  • 전하 2는 자기 주위의 모든 공간 (진공이라도!)에 전기장(electric field) 을 만든다
  • 전하 1은 전하 2를 직접 "느끼는" 것이 아니라, 자기가 있는 자리의 전기장 에 반응한다
  • 즉, 힘은 두 단계로 전달된다: 전하 → 장 → 다른 전하

컵을 손으로 밀면 접촉으로 힘이 전달되지만, 전하는 자신이 만든 장을 통해 밀고 당긴다.

이번 장의 세 가지 목표

  1. 전기장의 정의 : 전기장이 무엇인지 정확히 정의한다 E⃗=F⃗q0\vec{E} = \frac{\vec{F}}{q_0}E=q0​F​
  2. 전기장 계산 : 점전하, 쌍극자, 선전하, 원판 등 여러 전하 배치가 만드는 장을 계산한다
  3. 전기장의 효과 : 전기장 속에 놓인 전하와 쌍극자가 어떤 힘과 토크를 받는지 알아본다

22.1 전기장

장(field)이란 무엇인가

장(field) 은 공간의 각 점마다 물리량이 하나씩 배정된 것이다.

  • 온도장(temperature field) : 강의실의 각 점마다 온도가 있다 — 크기만 있으므로 스칼라장(scalar field)
  • 압력장(pressure field) : 수영장의 각 점마다 압력이 있다 — 역시 스칼라장

반면 전기장(electric field) 은 각 점마다 크기와 방향 을 가진 벡터가 배정된 벡터장(vector field) 이다. 힘의 정보를 전달해야 하기 때문이다.

전기장의 정의

어떤 점 PPP의 전기장은 이렇게 측정한다. 작은 양전하 q0q_0q0​ — 시험 전하(test charge) — 를 PPP에 놓고, 그 전하가 받는 정전기력 F⃗\vec{F}F를 잰다.

E⃗=F⃗q0\boxed{\vec{E} = \frac{\vec{F}}{q_0}}E=q0​F​​

q0>0q_0 > 0q0​>0이므로 E⃗\vec{E}E의 방향은 F⃗\vec{F}F의 방향과 같다. SI 단위는 뉴턴 매 쿨롬(N/C) 이다.

정의에서 주의할 점

  • 시험 전하는 충분히 작아야 한다 — 원래 대전체의 전하 분포를 흐트러뜨리지 않기 위해
  • 전기장은 시험 전하와 무관하게 원래부터 그 자리에 존재 한다. 시험 전하는 그것을 재는 도구일 뿐
  • 전기장은 대전체가 만든다. 시험 전하를 치워도 장은 남는다
  • 힘(force)과 장(field)을 혼동하지 말 것! 힘은 전하가 받는 것(N\mathrm{N}N), 장은 공간의 성질(N/C\mathrm{N/C}N/C)

측정점을 옮겨 가며 재면 공간 전체의 전기장 분포를 알 수 있다.

전기력선

19세기의 마이클 패러데이(Michael Faraday) 는 눈에 보이지 않는 전기장을 선으로 시각화하는 방법을 고안했다. 이를 전기력선(electric field lines) 이라 한다.

  • 규칙 1: 각 점에서 전기장 벡터 E⃗\vec{E}E는 그 점을 지나는 전기력선의 접선 방향
  • 규칙 2: 선이 빽빽한 곳일수록 장이 강하다 (선의 밀도 ∝ 장의 세기)

전기력선의 출발점과 끝점

전기력선은 양전하에서 나와서(originate) 음전하에서 끝난다(terminate).

  • 양의 점전하: 사방으로 뻗어 나가는 방사형 — 끝은 (그림에 없는) 먼 음전하
  • 쌍극자: 양전하에서 나와 굽어져 음전하로 들어간다
  • 크고 균일하게 대전된 평행판 사이: 선들이 평행하고 등간격 — 어디서나 크기와 방향이 같은 균일한 전기장(uniform field)

같은 부호의 두 전하 사이에는 선이 서로 피해 가며, 중간 지점의 장은 약해진다. 아래 시뮬레이션에서 직접 확인해 보자.

22.2 점전하의 전기장

쿨롱 법칙에서 전기장으로

점전하 qqq에서 거리 rrr 떨어진 곳에 시험 전하 q0q_0q0​를 놓으면, 쿨롱 법칙에 의해

F⃗=14πε0q q0r2r^\vec{F} = \frac{1}{4\pi\varepsilon_0}\frac{q\,q_0}{r^2}\hat{r}F=4πε0​1​r2qq0​​r^

전기장의 정의에 따라 q0q_0q0​로 나누면:

E⃗=F⃗q0=14πε0qr2r^,E=14πε0∣q∣r2\boxed{\vec{E} = \frac{\vec{F}}{q_0} = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}\hat{r}, \qquad E = \frac{1}{4\pi\varepsilon_0}\frac{|q|}{r^2}}E=q0​F​=4πε0​1​r2q​r^,E=4πε0​1​r2∣q∣​​

크기를 쓸 때 ∣q∣|q|∣q∣로 절댓값을 취하는 이유: 부호는 방향 으로 따로 생각하기 위해서다.

방향 정하기

  • q>0q > 0q>0: 장은 전하에서 멀어지는 방향 (양의 시험 전하가 밀려나는 방향)
  • q<0q < 0q<0: 장은 전하를 향하는 방향
  • 벡터의 꼬리 를 측정점에 붙여서 그린다 — 화살표를 아무 데나 그리면 틀리기 쉽다!

E≈5.1×1011 N/C\boxed{E \approx 5.1 \times 10^{11}\ \mathrm{N/C}}E≈5.1×1011 N/C​

공기의 절연 파괴 한계(3×1063 \times 10^63×106 N/C)의 십만 배가 넘는다. 원자 내부는 인간이 만드는 어떤 장치보다도 강한 전기장의 세계다.

중첩 원리

전하가 여러 개면? 시험 전하 q0q_0q0​가 받는 알짜힘은 힘의 중첩 원리에 따라 F⃗0=F⃗01+F⃗02+⋯+F⃗0n\vec{F}_0 = \vec{F}_{01} + \vec{F}_{02} + \cdots + \vec{F}_{0n}F0​=F01​+F02​+⋯+F0n​. 양변을 q0q_0q0​로 나누면:

E⃗=F⃗0q0=F⃗01q0+F⃗02q0+⋯+F⃗0nq0\vec{E} = \frac{\vec{F}_0}{q_0} = \frac{\vec{F}_{01}}{q_0} + \frac{\vec{F}_{02}}{q_0} + \cdots + \frac{\vec{F}_{0n}}{q_0}E=q0​F0​​=q0​F01​​+q0​F02​​+⋯+q0​F0n​​

E⃗=E⃗1+E⃗2+⋯+E⃗n\boxed{\vec{E} = \vec{E}_1 + \vec{E}_2 + \cdots + \vec{E}_n}E=E1​+E2​+⋯+En​​

전기장도 중첩 원리(superposition principle) 를 따른다.

주의: 이것도 벡터 합 이다. 각 전하가 만드는 장의 크기를 그냥 더하면 안 된다!

예제: 전기장이 0이 되는 지점

전하 q1=+qq_1 = +qq1​=+q가 원점에, q2=+4qq_2 = +4qq2​=+4q가 x=Lx = Lx=L에 고정되어 있다. 두 전하 사이에서 알짜 전기장이 0이 되는 지점은?

두 전하 사이의 점 xxx에서 E⃗1\vec{E}_1E1​은 +x+x+x 방향, E⃗2\vec{E}_2E2​는 −x-x−x 방향이므로 크기가 같으면 상쇄된다:

kqx2=k4q(L−x)2k\frac{q}{x^2} = k\frac{4q}{(L-x)^2}kx2q​=k(L−x)24q​

양변을 정리하면 (L−x)2=4x2(L-x)^2 = 4x^2(L−x)2=4x2, 양의 제곱근을 취하면 L−x=2xL - x = 2xL−x=2x:

x=L3\boxed{x = \frac{L}{3}}x=3L​​

작은 전하 쪽에 더 가까운 곳에서 균형이 맞는다. (두 전하 바깥에서는 두 장의 방향이 같아서 절대 0이 될 수 없다.)

22.3 전기 쌍극자의 전기장

전기 쌍극자란

크기는 같고 부호가 반대인 두 전하 +q+q+q, −q-q−q가 짧은 거리 ddd만큼 떨어져 있는 배치를 전기 쌍극자(electric dipole) 라 한다.

  • 두 전하를 잇는 축을 쌍극자 축(dipole axis) 이라 한다
  • 물 분자, HCl 분자 등 수많은 분자가 전기적으로는 쌍극자처럼 행동한다
  • 안테나에서 전파를 만드는 것도 진동하는 쌍극자다

멀리서 보면 +q+q+q와 −q-q−q가 거의 겹쳐 보여서 장이 거의 상쇄된다. "거의"가 핵심이다 — 완전히 상쇄되지는 않는다.

축 위의 전기장: 설정

쌍극자 축을 zzz축으로 잡고, 중심에서 거리 zzz인 축 위의 점 PPP에서 장을 구하자.

PPP가 +q+q+q 쪽에 있으면 +q+q+q까지의 거리는 r+=z−d2r_+ = z - \tfrac{d}{2}r+​=z−2d​, −q-q−q까지는 r−=z+d2r_- = z + \tfrac{d}{2}r−​=z+2d​.

유도 (1): 두 장의 차

E⃗+\vec{E}_+E+​는 +z+z+z 방향, E⃗−\vec{E}_-E−​는 −z-z−z 방향이므로 알짜 장의 크기는 두 크기의 차:

E=E+−E−=14πε0qr+2−14πε0qr−2E = E_+ - E_- = \frac{1}{4\pi\varepsilon_0}\frac{q}{r_+^2} - \frac{1}{4\pi\varepsilon_0}\frac{q}{r_-^2}E=E+​−E−​=4πε0​1​r+2​q​−4πε0​1​r−2​q​

E=q4πε0(z−d2)2−q4πε0(z+d2)2E = \frac{q}{4\pi\varepsilon_0 \left(z - \frac{d}{2}\right)^2} - \frac{q}{4\pi\varepsilon_0 \left(z + \frac{d}{2}\right)^2}E=4πε0​(z−2d​)2q​−4πε0​(z+2d​)2q​

z2z^2z2을 밖으로 빼내면:

E=q4πε0z2[(1−d2z)−2−(1+d2z)−2]E = \frac{q}{4\pi\varepsilon_0 z^2}\left[\left(1 - \frac{d}{2z}\right)^{-2} - \left(1 + \frac{d}{2z}\right)^{-2}\right]E=4πε0​z2q​[(1−2zd​)−2−(1+2zd​)−2]

유도 (2): 통분하기

대괄호 안을 통분하자. 분자는 제곱 차 공식으로 전개된다:

(1+d2z)2−(1−d2z)2=(1+dz+d24z2)−(1−dz+d24z2)=2dz\left(1 + \frac{d}{2z}\right)^2 - \left(1 - \frac{d}{2z}\right)^2 = \left(1 + \frac{d}{z} + \frac{d^2}{4z^2}\right) - \left(1 - \frac{d}{z} + \frac{d^2}{4z^2}\right) = \frac{2d}{z}(1+2zd​)2−(1−2zd​)2=(1+zd​+4z2d2​)−(1−zd​+4z2d2​)=z2d​

분모는 (1−d2z)2(1+d2z)2=[1−(d2z)2]2\left(1 - \frac{d}{2z}\right)^2\left(1 + \frac{d}{2z}\right)^2 = \left[1 - \left(\frac{d}{2z}\right)^2\right]^2(1−2zd​)2(1+2zd​)2=[1−(2zd​)2]2. 따라서:

E=q4πε0z2⋅2d/z[1−(d2z)2]2=qd2πε0z3⋅1[1−(d2z)2]2E = \frac{q}{4\pi\varepsilon_0 z^2}\cdot\frac{2d/z}{\left[1 - \left(\frac{d}{2z}\right)^2\right]^2} = \frac{qd}{2\pi\varepsilon_0 z^3}\cdot\frac{1}{\left[1 - \left(\frac{d}{2z}\right)^2\right]^2}E=4πε0​z2q​⋅[1−(2zd​)2]22d/z​=2πε0​z3qd​⋅[1−(2zd​)2]21​

여기까지는 정확한 식이다. 근사는 아직 쓰지 않았다.

원거리 근사와 쌍극자 모멘트

보통 관심 있는 것은 쌍극자 크기보다 훨씬 먼 곳의 장이다: z≫dz \gg dz≫d, 즉 d2z≪1\frac{d}{2z} \ll 12zd​≪1. 그러면 분모의 (d2z)2\left(\frac{d}{2z}\right)^2(2zd​)2을 무시할 수 있다:

E=12πε0qdz3=12πε0pz3\boxed{E = \frac{1}{2\pi\varepsilon_0}\frac{qd}{z^3} = \frac{1}{2\pi\varepsilon_0}\frac{p}{z^3}}E=2πε0​1​z3qd​=2πε0​1​z3p​​

여기서 곱 qdqdqd를 전기 쌍극자 모멘트(electric dipole moment) 의 크기 ppp로 정의한다.

  • p⃗\vec{p}p​의 방향: −q-q−q에서 +q+q+q 쪽으로 (단위: C·m)
  • 축 위 먼 곳에서 E⃗\vec{E}E의 방향은 p⃗\vec{p}p​의 방향과 같다 (위쪽이든 아래쪽이든!)

1/z31/z^31/z3이 말해주는 것

  • 점전하의 장은 1/r21/r^21/r2, 쌍극자의 장은 1/z31/z^31/z3 — 쌍극자의 장이 훨씬 빨리 약해진다
  • 이유: 멀리서 보면 +q+q+q와 −q-q−q가 거의 겹쳐 보여 두 장이 거의 상쇄 되기 때문
  • 거리를 2배로 늘리면 점전하의 장은 14\frac{1}{4}41​, 쌍극자의 장은 18\frac{1}{8}81​로 줄어든다
  • 먼 곳의 장은 qqq와 ddd에 따로 의존하지 않고 오직 곱 p=qdp = qdp=qd에만 의존한다 — qqq를 2배로, ddd를 절반으로 해도 장은 똑같다

사실 축 위가 아닌 모든 먼 지점에서 쌍극자의 장은 1/r31/r^31/r3으로 감소한다.

예제 ①: 뇌우 위의 붉은 섬광, 스프라이트

스프라이트(sprite) 는 거대한 뇌우 위 고도 수십 km에서 번쩍이는 붉은 방전 현상이다. 강력한 번개가 구름과 지면 사이에 큰 전하 이동을 일으킨 직후, 그 위 하늘에 나타난다. 이 현상을 쌍극자 모형으로 설명해 보자.

22.4 선전하의 전기장

연속 전하 분포

지금까지는 낱개의 점전하였다. 이제 막대나 고리처럼 연속적으로 퍼진 전하(continuous charge distribution) 가 만드는 장을 구하자. 전하가 어떻게 퍼져 있느냐에 따라 전하 밀도 를 정의한다.

이름 기호 SI 단위
전하 qqq C

표면전하 밀도 (surface charge density) σ\sigmaσ C/m²
부피전하 밀도 (volume charge density) ρ\rhoρ C/m³

전략: 쪼개고, 상쇄시키고, 적분한다

점전하 공식 E=kq/r2E = kq/r^2E=kq/r2은 고리 전체에는 적용할 수 없다. 그래서 3단계 전략을 쓴다.

  1. 쪼개기 : 전하 분포를 미소 전하 요소 dqdqdq로 나눈다 — 각 요소는 점전하처럼 취급 가능
  2. 대칭으로 상쇄 : 각 요소가 만드는 dE⃗d\vec{E}dE를 성분으로 나누고, 대칭인 짝끼리 상쇄되는 성분을 찾아 버린다
  3. 적분 : 남은 성분(모두 같은 방향)을 스칼라처럼 적분해 더한다

교재가 "이 책에서 가장 어려운 모듈"이라 부르는 부분이지만, 절차 만 익히면 어떤 모양이 나와도 똑같이 풀 수 있다.

22.6 전기장 속의 점전하

두 번째 임무: 장이 전하에 힘을 준다

지금까지는 "전하 → 장"이었다. 이제 반대로, 주어진 전기장 속에 전하 qqq를 놓으면 어떻게 되는가?

F⃗=qE⃗\boxed{\vec{F} = q\vec{E}}F=qE​

  • q>0q > 0q>0: 힘은 E⃗\vec{E}E와 같은 방향
  • q<0q < 0q<0: 힘은 E⃗\vec{E}E와 반대 방향 (음수 부호가 벡터를 뒤집는다)
  • 여기서 E⃗\vec{E}E는 다른 전하들 이 그 자리에 만든 외부 장(external field) 이다 — 입자 자신이 만든 장은 자신에게 힘을 주지 않는다

밀리컨의 기름방울 실험

미국의 물리학자 밀리컨(R. A. Millikan) 은 1910~1913년, F⃗=qE⃗\vec{F} = q\vec{E}F=qE를 이용해 기본 전하 eee를 측정했다.

분무된 기름방울은 마찰로 대전된다. 평행판 사이의 전기장을 켜고 끄면서 방울의 낙하·상승을 관찰하면 방울의 전하 qqq를 잴 수 있는데, 측정값은 언제나 q=neq = neq=ne (n=0,±1,±2,…n = 0, \pm 1, \pm 2, \dotsn=0,±1,±2,…)였다. 전하의 양자화 를 확인한 이 업적으로 밀리컨은 1923년 노벨상을 받았다.

잉크젯 프린터

잉크젯 프린터는 F⃗=qE⃗\vec{F} = q\vec{E}F=qE를 글자 그대로 응용한 장치다.

  • 노즐에서 나온 잉크 방울에 대전 장치가 신호에 따라 전하 −Q-Q−Q를 실어 준다

  • 전하량이 클수록 많이 휘어 종이의 다른 위치에 찍힌다 — 전하가 곧 "주소"인 셈

전기 방전과 스파크

공기 중의 전기장이 임계값 Ec≈3×106E_c \approx 3 \times 10^6Ec​≈3×106 N/C을 넘으면 절연 파괴(electrical breakdown) 가 일어난다.

  • 강한 장이 공기 분자에서 전자를 떼어낸다 (이온화)
  • 풀려난 전자들이 F⃗=qE⃗\vec{F} = q\vec{E}F=qE로 가속되어 다른 분자와 충돌 → 연쇄적으로 전자가 불어난다
  • 충돌당한 분자들이 빛을 내며 우리 눈에 스파크(spark) 로 보인다

겨울철 문손잡이의 찌릿한 불꽃, 번개, 고압선 주변의 방전이 모두 같은 현상이다. 스프라이트도 희박한 상층 대기에서 일어나는 절연 파괴였다.

22.7 전기장 속의 쌍극자

물 분자는 영구 쌍극자다

물 분자에서 전자 10개는 산소 원자핵 쪽에 몰려 있다. 그래서 산소 쪽은 약간 음(−), 수소 쪽은 약간 양(+)이 되어, 분자 전체가 쌍극자 모멘트 p=6.2×10−30p = 6.2 \times 10^{-30}p=6.2×10−30 C·m를 가진다. 이런 분자를 극성 분자(polar molecule) 라 한다.

전체 전하는 0인데, 전기장 속에 넣으면 무슨 일이 벌어질까?

쌍극자에 작용하는 토크

전하 크기 qqq, 간격 ddd인 쌍극자가 균일한 장 E⃗\vec{E}E와 각 θ\thetaθ를 이루고 있다.

  • 두 힘은 F=qEF = qEF=qE로 크기가 같고 방향이 반대 → 알짜힘은 0, 질량중심은 움직이지 않는다
  • 그러나 두 힘의 작용선이 다르므로 토크(torque) 가 남는다

토크 계산

질량중심에서 +q+q+q까지 거리를 xxx, −q-q−q까지를 d−xd - xd−x라 하자. 토크의 크기는 τ=rFsin⁡ϕ\tau = rF\sin\phiτ=rFsinϕ (10장)이므로 두 힘의 토크는 같은 회전 방향으로 더해진다:

τ=Fxsin⁡θ+F(d−x)sin⁡θ=Fdsin⁡θ\tau = Fx\sin\theta + F(d - x)\sin\theta = Fd\sin\thetaτ=Fxsinθ+F(d−x)sinθ=Fdsinθ

F=qEF = qEF=qE와 d=p/qd = p/qd=p/q를 대입하면:

τ=(qE)(pq)sin⁡θ=pEsin⁡θ\tau = (qE)\left(\frac{p}{q}\right)\sin\theta = pE\sin\thetaτ=(qE)(qp​)sinθ=pEsinθ

벡터로 일반화하면:

τ⃗=p⃗×E⃗\boxed{\vec{\tau} = \vec{p} \times \vec{E}}τ=p​×E​

토크는 p⃗\vec{p}p​를 E⃗\vec{E}E 방향으로 정렬시키려는 쪽으로 작용한다 (복원 토크: τ=−pEsin⁡θ\tau = -pE\sin\thetaτ=−pEsinθ).

쌍극자의 퍼텐셜 에너지

토크를 받으며 도는 계이므로 방향에 따른 퍼텐셜 에너지(potential energy) 를 정의할 수 있다. 관례상 θ=90°\theta = 90°θ=90°에서 U=0U = 0U=0으로 잡으면, U=−WU = -WU=−W와 W=∫τ dθW = \int \tau\, d\thetaW=∫τdθ (복원 토크 τ=−pEsin⁡θ\tau = -pE\sin\thetaτ=−pEsinθ)에서:

U=−W=−∫90°θ(−pEsin⁡θ′) dθ′=pE[−cos⁡θ′]90°θU = -W = -\int_{90°}^{\theta} (-pE\sin\theta')\, d\theta' = pE\left[-\cos\theta'\right]_{90°}^{\theta}U=−W=−∫90°θ​(−pEsinθ′)dθ′=pE[−cosθ′]90°θ​

cos⁡90°=0\cos 90° = 0cos90°=0이므로:

U=−pEcos⁡θ⇒U=−p⃗⋅E⃗U = -pE\cos\theta \quad\Rightarrow\quad \boxed{U = -\vec{p}\cdot\vec{E}}U=−pEcosθ⇒U=−p​⋅E​

토크는 벡터곱, 에너지는 스칼라곱 — 짝으로 기억하자.

전자레인지는 쌍극자를 돌린다

전자레인지 속에서는 약 2.45 GHz로 방향이 진동하는 전기장 이 만들어진다.

  • 장의 방향이 바뀔 때마다 물 분자들은 τ⃗=p⃗×E⃗\vec{\tau} = \vec{p} \times \vec{E}τ=p​×E로 끊임없이 다시 정렬 된다
  • 액체 속 물 분자들은 이웃과 약하게 결합해 있는데, 회전이 이 결합을 계속 끊는다
  • 끊어진 분자들이 다시 결합하며 그 에너지가 무질서한 열운동 으로 넘어간다 → 온도 상승

물이 극성 분자가 아니었다면 전자레인지는 무용지물이었을 것이다. 물기 없는 마른 접시가 잘 데워지지 않는 이유다.

Review & Summary

핵심 개념

  • 전기장 : 대전체는 주위 공간에 벡터장 E⃗=F⃗/q0\vec{E} = \vec{F}/q_0E=F/q0​를 만든다 — 힘은 "전하 → 장 → 전하"로 전달된다
  • 전기력선 : 접선 = 장의 방향, 밀도 = 장의 세기. 양전하에서 나와 음전하에서 끝난다
  • 중첩 원리 : 여러 전하의 장은 각 장의 벡터 합
  • 연속 분포 : 쪼개기(dqdqdq) → 대칭으로 상쇄 → 적분 — 고리와 원판이 대표 예
  • 장 속의 전하 : F⃗=qE⃗\vec{F} = q\vec{E}F=qE (양전하는 장 방향, 음전하는 반대 방향)
  • 장 속의 쌍극자 : 알짜힘 0, 토크가 p⃗\vec{p}p​를 E⃗\vec{E}E에 정렬시킨다
