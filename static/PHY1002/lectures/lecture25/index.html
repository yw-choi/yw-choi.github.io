25장: 전기용량

Capacitance

이번 장에서 배울 내용

지금까지 전하가 만드는 전기장(electric field) 과 전위(electric potential) 를 배웠다. 이번 장에서는 이 도구들을 처음으로 실용적인 장치 에 적용한다. 바로 축전기(capacitor) 다.

  • 축전기는 전하와 전기 에너지를 저장하는 장치 다
  • 전기용량이란 무엇이고, 어떻게 계산하는가 (가우스 법칙 + 전위 적분)
  • 축전기 여러 개를 연결하면? (병렬·직렬)
  • 저장된 에너지는 어디에 있는가 → 전기장 자체가 에너지를 담는다
  • 판 사이에 절연 물질(유전체)을 넣으면 무슨 일이 생기는가

축전기는 어디에나 있다

  • 카메라 플래시 : 배터리가 못 내는 순간적인 큰 출력을 축전기가 대신 낸다
  • 심장 제세동기(defibrillator) : 축전기에 저장한 에너지로 심장에 전기 충격
  • 스마트폰 터치스크린 : 손가락이 닿으면 그 지점의 전기용량이 변한다
  • DRAM 메모리 : 비트 하나하나가 아주 작은 축전기 — 전하가 있으면 1, 없으면 0

다양한 크기와 모양의 축전기들. 모두 같은 원리로 작동한다.

이번 장의 세 가지 핵심 결론

  1. 전기용량(capacitance) : 축전기의 전하와 전위차는 비례한다 q=CVq = CVq=CV
  2. 전기용량은 기하학이 결정한다 : 판의 모양·크기·간격만으로 정해진다 C=ε0Ad    (평행판)C = \frac{\varepsilon_0 A}{d} \;\;(\text{평행판})C=dε0​A​(평행판)
  3. 에너지는 전기장에 저장된다 : 단위 부피당 에너지는 u=12ε0E2u = \tfrac{1}{2}\varepsilon_0 E^2u=21​ε0​E2

25.1 전기용량

축전기란 무엇인가

축전기(capacitor) 는 서로 절연된 두 도체 로 이루어진 장치다. 두 도체를 판(plate) 이라 부른다.

  • 충전되면 두 판은 크기가 같고 부호가 반대인 전하 +q+q+q, −q-q−q를 갖는다
  • 판의 모양은 아무래도 좋다 — 평평하지 않아도 두 도체면 축전기다

"축전기의 전하가 qqq"라는 말은 한 판에 있는 전하의 크기 를 뜻한다. 두 판을 합친 알짜 전하는 0이다.

전하와 전위차는 비례한다

판은 도체이므로 각 판 전체가 등전위면(equipotential surface) 이다. 두 판 사이에는 전위차가 있고, 이를 (24장의 ΔV\Delta VΔV 대신) 관례적으로 VVV로 쓴다.

축전기의 전하 qqq와 전위차 VVV는 서로 비례한다:

q=CV\boxed{q = CV}q=CV​

  • 비례 상수 CCC가 전기용량(capacitance) 이다
  • CCC는 판의 기하학적 구조 (모양, 크기, 간격)에만 의존하고, qqq나 VVV에는 의존하지 않는다
  • 같은 전위차 VVV에서 CCC가 클수록 더 많은 전하를 저장한다 — "전하를 담는 그릇의 크기"

전기용량의 단위: 패럿

1 패럿(farad)=1 F=1 C/V1\ \text{패럿(farad)} = 1\ \mathrm{F} = 1\ \mathrm{C/V}1 패럿(farad)=1 F=1 C/V

전자기 연구의 선구자 마이클 패러데이(Michael Faraday)의 이름을 땄다.

  • 1 F는 엄청나게 큰 단위다. 실제 회로에서는 보조 단위를 쓴다:
    • 마이크로패럿 1 μF=10−61\ \mu\mathrm{F} = 10^{-6}1 μF=10−6 F
    • 피코패럿 1 pF=10−121\ \mathrm{pF} = 10^{-12}1 pF=10−12 F
  • 전자회로 기판의 축전기는 대부분 pF ~ μF 수준
  • 예외적으로 슈퍼커패시터(supercapacitor) 는 수천 F까지 가능 (단, 낮은 전압에서만)

축전기의 충전

축전기를 충전하는 가장 간단한 방법: 배터리 가 있는 회로에 넣는 것.

  • 배터리는 내부 화학 반응으로 두 단자 사이의 전위차 VVV를 유지하는 장치
  • 스위치를 닫으면 배터리가 도선에 만드는 전기장이 전도 전자를 민다
  • hhh판의 전자는 +++단자 쪽으로 빠져나가고 (hhh판은 +q+q+q), −-−단자에서 나온 전자는 lll판에 쌓인다 (−q-q−q)

충전은 언제 멈추는가

전하가 쌓일수록 판 사이의 전위차가 커진다.

  • 처음: 판이 중성, 판 사이 전위차 0
  • 충전 중: 판의 전하 ±q\pm q±q 증가 → 전위차 증가
  • 판의 전위차가 배터리의 전위차 VVV와 같아지면 → 도선에 알짜 전기장이 사라져 전자 이동이 멈춘다

이 상태를 완전히 충전(fully charged) 되었다고 하며, 이때 q=CVq = CVq=CV가 성립한다.

스위치를 다시 열어도 전하는 갈 곳이 없으므로 (이상적으로는) 계속 저장된다. 축전기를 전하 저장 장치라 부르는 이유다.

25.2 전기용량 계산하기

계산 전략: 네 단계

어떤 모양의 축전기든 전기용량은 똑같은 순서로 구한다.

  1. 판에 전하 ±q\pm q±q가 있다고 가정 한다
  2. 가우스 법칙 으로 판 사이의 전기장 E⃗\vec{E}E를 구한다
  3. E⃗\vec{E}E를 경로 적분하여 판 사이의 전위차 VVV를 구한다
  4. C=q/VC = q/VC=q/V로 전기용량을 얻는다

마지막에 CCC는 반드시 qqq가 약분되어 사라지고 기하학적 양들만 남는다. 그래야 "전기용량은 기하가 결정한다"는 말과 맞는다.

두 가지 도구

도구 1 — 가우스 법칙 (23장) : 양(+)판의 전하를 둘러싸는 가우스면을 잡는다. 플럭스가 통과하는 면에서 E⃗\vec{E}E가 균일하고 면에 수직이 되도록 잡으면:

도구 2 — 전위차 (24장) : Vf−Vi=−∫ifE⃗⋅ds⃗V_f - V_i = -\int_i^f \vec{E}\cdot d\vec{s}Vf​−Vi​=−∫if​E⋅ds. 경로를 음(−)판에서 양(+)판으로, 전기력선을 거슬러 가도록 잡으면 E⃗⋅ds⃗=−E ds\vec{E}\cdot d\vec{s} = -E\,dsE⋅ds=−Eds가 되어:

V≡V+−V−=∫−+E dsV \equiv V_+ - V_- = \int_-^+ E\, dsV≡V+​−V−​=∫−+​Eds

적분 기호의 −-−, +++는 경로의 시작(음판)과 끝(양판)을 뜻한다.

평행판 축전기

가장 기본적인 축전기: 면적 AAA인 두 판이 간격 ddd로 마주 본다.

판이 충분히 크고 서로 가깝다면 (d≪Ad \ll \sqrt{A}d≪A​), 가장자리에서 장이 휘는 가장자리 효과(fringing) 를 무시할 수 있다. 그러면 판 사이의 E⃗\vec{E}E는 어디서나 균일하다.

평행판: 전기장 구하기

윗판(+q+q+q)을 둘러싸는 납작한 상자 모양 가우스면을 잡는다.

  • 전기장은 판 사이 영역에만 있고, 가우스면의 아랫면 만 통과한다

원통형 축전기

길이 LLL, 반지름 aaa인 안쪽 도체(+q+q+q)와 반지름 bbb인 바깥 원통(−q-q−q)이 동축으로 놓여 있다. L≫bL \gg bL≫b이면 끝부분의 fringing을 무시할 수 있다. 동축 케이블이 바로 이 구조다.

  2. 원통형의 안쪽 반지름 aaa를 키우면 ? → ln⁡(b/a)\ln(b/a)ln(b/a) 감소 → CCC 증가 → qqq 증가
  3. 구형의 바깥 반지름 bbb를 키우면 ? → abb−a=a1−a/b\dfrac{ab}{b-a} = \dfrac{a}{1-a/b}b−aab​=1−a/ba​ 감소 → CCC 감소 → qqq 감소

간격이 좁아질수록, 두 판이 가까워질수록 전기용량은 커진다.

25.3 병렬 연결과 직렬 연결

등가 축전기

회로에 축전기가 여러 개 있으면, 조합 전체를 등가 축전기(equivalent capacitor) 하나로 바꿔 생각할 수 있다.

  • 등가 축전기: 실제 조합과 같은 전하 qqq와 같은 전위차 VVV 를 갖는 가상의 축전기 하나
  • 복잡한 회로를 단계적으로 단순화하는 강력한 도구

기본 조합은 두 가지뿐이다: 병렬(parallel) 과 직렬(series). 이 둘만 정확히 구분하면 대부분의 회로를 풀 수 있다.

병렬 연결: 같은 V

병렬 : 한쪽 판들끼리 직접 연결되고, 반대쪽 판들끼리도 직접 연결된 상태. 그 양단에 전위차 VVV를 걸면 각 축전기에 똑같은 VVV 가 걸린다. (기억법: "par-V")

병렬: 등가용량 유도

각 축전기의 전하는 q=CVq = CVq=CV에서:

q1=C1V,q2=C2V,q3=C3Vq_1 = C_1 V, \qquad q_2 = C_2 V, \qquad q_3 = C_3 Vq1​=C1​V,q2​=C2​V,q3​=C3​V

조합 전체에 저장된 총 전하:

q=q1+q2+q3=(C1+C2+C3)Vq = q_1 + q_2 + q_3 = (C_1 + C_2 + C_3)Vq=q1​+q2​+q3​=(C1​+C2​+C3​)V

같은 qqq, VVV를 갖는 등가 축전기의 전기용량은:

Ceq=qV=C1+C2+C3⇒Ceq=∑j=1nCjC_{\text{eq}} = \frac{q}{V} = C_1 + C_2 + C_3 \quad\Rightarrow\quad \boxed{C_{\text{eq}} = \sum_{j=1}^{n} C_j}Ceq​=Vq​=C1​+C2​+C3​⇒Ceq​=j=1∑n​Cj​​

병렬 연결은 사실상 판 면적을 합치는 것 이다. CeqC_{\text{eq}}Ceq​는 항상 가장 큰 CjC_jCj​보다 크다.

직렬 연결: 같은 q

직렬 : 축전기들이 한 줄로 이어져 있고, 그 줄의 양 끝에 전위차 VVV가 걸린 상태. 이때 각 축전기에 똑같은 전하 qqq 가 저장된다. (기억법: "seri-q")

직렬: 왜 전하가 모두 같은가

배터리가 직접 대전시키는 것은 줄의 양 끝 판 두 장뿐 이다.

  • 배터리가 맨 아래 판에 −q-q−q를 놓으면, 그 판이 같은 축전기의 반대 판 전자를 밀어내 +q+q+q로 만든다
  • 밀려난 전자는 도선을 타고 이웃 축전기의 판으로 가 −q-q−q를 만든다 → 연쇄 반응
  • 중간의 "판 두 장 + 도선" 구간은 전기적으로 고립 되어 있어 알짜 전하가 0으로 유지된다: 한쪽이 +q+q+q면 반대쪽은 정확히 −q-q−q

주의: 전하가 이동할 경로가 하나뿐 이어야 직렬이다. 중간에 갈림길이 있으면 직렬이 아니다.

직렬: 등가용량 유도

각 축전기의 전위차는 V=q/CV = q/CV=q/C에서:

V1=qC1,V2=qC2,V3=qC3V_1 = \frac{q}{C_1}, \qquad V_2 = \frac{q}{C_2}, \qquad V_3 = \frac{q}{C_3}V1​=C1​q​,V2​=C2​q​,V3​=C3​q​

전체 전위차는 각 전위차의 합:

V=V1+V2+V3=q(1C1+1C2+1C3)V = V_1 + V_2 + V_3 = q\left(\frac{1}{C_1} + \frac{1}{C_2} + \frac{1}{C_3}\right)V=V1​+V2​+V3​=q(C1​1​+C2​1​+C3​1​)

Ceq=qV=11/C1+1/C2+1/C3⇒1Ceq=∑j=1n1CjC_{\text{eq}} = \frac{q}{V} = \frac{1}{1/C_1 + 1/C_2 + 1/C_3} \quad\Rightarrow\quad \boxed{\frac{1}{C_{\text{eq}}} = \sum_{j=1}^{n}\frac{1}{C_j}}Ceq​=Vq​=1/C1​+1/C2​+1/C3​1​⇒Ceq​1​=j=1∑n​Cj​1​​

직렬의 CeqC_{\text{eq}}Ceq​는 항상 가장 작은 CjC_jCj​보다도 작다.

25.4 전기장에 저장된 에너지

축전기를 충전하려면 일이 필요하다

전하를 한 판에서 다른 판으로 옮기는 과정을 상상하자.

  • 처음에는 판이 중성이라 전하를 옮기는 데 일이 들지 않는다
  • 전하가 쌓일수록, 이미 쌓인 전하가 새로 오는 전하를 밀어낸다
  • 전하가 많아질수록 옮기는 데 점점 더 큰 일이 필요하다

실제로는 배터리가 화학 에너지를 소모하며 이 일을 해 준다. 그 일은 어디로 갔을까? — 축전기에 전기 퍼텐셜 에너지 UUU 로 저장되고, 방전시키면 되찾을 수 있다.

유도: U=q2/2CU = q^2/2CU=q2/2C

충전 도중 어느 순간, 이미 옮겨진 전하가 q′q'q′이라 하자. 그 순간 판 사이 전위차는 V′=q′/CV' = q'/CV′=q′/C이다.

여기서 전하 dq′dq'dq′을 추가로 옮기는 데 필요한 일은 (24장: dW=V dqdW = V\,dqdW=Vdq):

dW=V′ dq′=q′C dq′dW = V'\, dq' = \frac{q'}{C}\, dq'dW=V′dq′=Cq′​dq′

전하 0에서 최종 전하 qqq까지 쌓는 전체 일:

W=∫dW=1C∫0qq′ dq′=q22CW = \int dW = \frac{1}{C}\int_0^q q'\, dq' = \frac{q^2}{2C}W=∫dW=C1​∫0q​q′dq′=2Cq2​

이 일이 퍼텐셜 에너지로 저장된다. q=CVq = CVq=CV를 대입한 형태와 함께:

U=q22C=12CV2\boxed{U = \frac{q^2}{2C} = \tfrac{1}{2}CV^2}U=2Cq2​=21​CV2​

축전기의 모양과 무관하게 성립한다.

에너지는 어디에 있는가

사고 실험: 같은 전하 qqq를 가진 두 평행판 축전기, 단 하나는 간격이 2배.

  • 간격 2배 → 판 사이 부피 2배, CCC는 절반 → U=q2/2CU = q^2/2CU=q2/2C는 2배
  • 그런데 전기장은 E=q/ε0AE = q/\varepsilon_0 AE=q/ε0​A로 둘이 똑같다
  • 장은 같은데 장이 차지하는 부피가 2배인 쪽이 에너지도 2배

→ 에너지가 전기장이 차지하는 공간 에 비례해 저장된다고 보는 것이 자연스럽다.

평행판으로 유도했지만 이 결과는 모든 전기장에 대해 일반적으로 성립한다. 전기장이 있는 곳이라면 어디든, 그 공간 자체가 에너지를 담고 있다.

25.5 유전체가 든 축전기

패러데이의 발견

판 사이의 빈 공간을 유전체(dielectric) — 광물성 기름, 플라스틱 같은 절연 물질 — 로 채우면 어떻게 될까?

1837년 패러데이가 실험으로 답했다:

C=κ Cair\boxed{C = \kappa\, C_{\text{air}}}C=κCair​​

  • 전기용량이 κ\kappaκ배로 증가 한다
  • κ\kappaκ는 유전 상수(dielectric constant) : 물질마다 정해진 1보다 큰 수
  • 실제 축전기의 판 사이에 절연지·세라믹·산화막이 들어 있는 이유: CCC를 키우고, 판 간격을 좁게 유지하면서도 판끼리 닿지 않게 한다

25.6 유전체와 가우스 법칙

유도 전하를 넣어 다시 쓰는 가우스 법칙

유전체가 없을 때 : 가우스면은 +q+q+q만 둘러싼다.

ε0∮E⃗⋅dA⃗=ε0E0A=q⇒E0=qε0A\varepsilon_0\oint\vec{E}\cdot d\vec{A} = \varepsilon_0 E_0 A = q \quad\Rightarrow\quad E_0 = \frac{q}{\varepsilon_0 A}ε0​∮E⋅dA=ε0​E0​A=q⇒E0​=ε0​Aq​

유전체를 채웠을 때 : 같은 가우스면이 판의 자유 전하(free charge) +q+q+q와 유전체 표면의 유도 전하(induced charge) −q′-q'−q′을 함께 둘러싼다.

ε0∮E⃗⋅dA⃗=ε0EA=q−q′⇒E=q−q′ε0A\varepsilon_0\oint\vec{E}\cdot d\vec{A} = \varepsilon_0 EA = q - q' \quad\Rightarrow\quad E = \frac{q-q'}{\varepsilon_0 A}ε0​∮E⋅dA=ε0​EA=q−q′⇒E=ε0​Aq−q′​

유도 전하의 크기

유전체의 효과는 장을 κ\kappaκ분의 1로 줄이는 것이었다:

E=E0κ=qκε0AE = \frac{E_0}{\kappa} = \frac{q}{\kappa\varepsilon_0 A}E=κE0​​=κε0​Aq​

두 표현을 비교하면:

q−q′ε0A=qκε0A⇒q−q′=qκ⇒q′=q(1−1κ)\frac{q - q'}{\varepsilon_0 A} = \frac{q}{\kappa\varepsilon_0 A} \quad\Rightarrow\quad q - q' = \frac{q}{\kappa} \quad\Rightarrow\quad \boxed{q' = q\left(1 - \frac{1}{\kappa}\right)}ε0​Aq−q′​=κε0​Aq​⇒q−q′=κq​⇒q′=q(1−κ1​)​

  • 유도 전하는 항상 자유 전하보다 작다 (q′<qq' < qq′<q)
  • κ=1\kappa = 1κ=1(진공)이면 q′=0q' = 0q′=0 — 유도 전하 없음
  • κ\kappaκ가 클수록 q′q'q′이 qqq에 가까워진다 (도체는 κ→∞\kappa \to \inftyκ→∞인 극한처럼 행동)

q−q′=q/κq - q' = q/\kappaq−q′=q/κ를 가우스 법칙에 넣으면 유도 전하를 명시적으로 쓸 필요가 없어진다:

세 가지 주의점:

  1. 플럭스 적분에 E⃗\vec{E}E가 아니라 κE⃗\kappa\vec{E}κE가 들어간다 (ε0κE⃗\varepsilon_0\kappa\vec{E}ε0​κE를 전기 변위(electric displacement) D⃗\vec{D}D라 부르기도 한다)
  2. 우변의 qqq는 자유 전하만 센다 — 유도 전하는 좌변의 κ\kappaκ가 자동으로 처리한다
  3. κ\kappaκ는 위치에 따라 다를 수 있으므로 적분 안에 둔다. 진공은 κ=1\kappa = 1κ=1인 특수한 경우
