23장: 가우스 법칙

Gauss' Law

지금까지의 방법은 힘들었다

22장에서 전하 분포가 만드는 전기장을 구할 때 우리는:

  1. 전하 분포를 잘게 쪼개 전하 요소 dqdqdq를 잡고
  2. 각 요소가 만드는 장 dE⃗d\vec{E}dE를 쓰고
  3. 성분으로 분해한 뒤
  4. 전체에 대해 적분했다

고리, 막대, 원판마다 매번 새로 적분... 꽤 고된 작업이었다.

물리학의 중요한 목표 중 하나는 어려운 문제를 쉽게 푸는 방법 을 찾는 것이다. 그 핵심 도구가 바로 대칭(symmetry) 이다.

가우스 법칙: 대칭이 좋으면 몇 줄로 끝

독일의 수학자이자 물리학자 가우스(Carl Friedrich Gauss, 1777–1855) 가 만든 법칙:

닫힌 곡면을 통과하는 전기장의 양(플럭스)은 그 곡면이 감싸고 있는 알짜 전하 로 결정된다.

ε0Φ=qenc\boxed{\varepsilon_0 \Phi = q_{\text{enc}}}ε0​Φ=qenc​​

  • 상자를 열지 않고 포장지만 보고 내용물을 아는 것 과 같다
  • 전하 분포에 좋은 대칭이 있으면, 적분 없이 몇 줄 만에 전기장을 구할 수 있다

미리 보기: 점전하를 감싼 상상의 구면

점전하 +Q+Q+Q를 중심에 두고 상상의 구면을 그려 보자. 이 상상의 닫힌 곡면을 가우스면(Gaussian surface) 이라 부른다.

  • 전기장 벡터(필드라인)가 구면을 밖으로 뚫고 나간다
  • 전하를 +2Q+2Q+2Q로 바꾸면 → 뚫고 나가는 정도(밀도)가 정확히 두 배
  • 전하가 −Q-Q−Q면 → 필드라인이 안으로 뚫고 들어온다

곡면을 뚫는 전기장의 양만 보고도 내부 전하의 크기와 부호를 알 수 있다. 이것이 가우스 법칙의 전부다.

이번 장의 로드맵

  1. 전기 플럭스(electric flux) Φ\PhiΦ — "곡면을 뚫는 전기장의 양"을 정량화
  2. 가우스 법칙 — ε0Φ=qenc\varepsilon_0 \Phi = q_{\text{enc}}ε0​Φ=qenc​
  3. 가우스 법칙 ↔ 쿨롱 법칙 의 동등성
  4. 응용 ① — 대전된 고립 도체 (잉여 전하는 표면에)
  5. 응용 ② — 세 가지 대칭: 원통(선전하), 평면(면전하), 구(껍질 정리 증명)

23.1 전기 플럭스

균일한 장, 평평한 면

균일한 전기장 E⃗\vec{E}E 속에 넓이 AAA인 평평한 면을 놓자. 면을 실제로 뚫고 지나가는 것은 면에 수직인 성분 Ecos⁡θE\cos\thetaEcosθ뿐이다. 면을 따라 스치는 성분은 뚫는 데 기여하지 않는다.

면을 뚫는 전기장의 양을 전기 플럭스(electric flux) 라 정의한다:

Φ=(Ecos⁡θ) A\Phi = (E\cos\theta)\,AΦ=(Ecosθ)A

θ\thetaθ는 전기장과 면의 수직 방향 사이의 각도이다.

면적 벡터

각도를 자동으로 처리하는 영리한 표기법: 면에 수직이고 크기가 면적과 같은 면적 벡터(area vector) A⃗\vec{A}A를 정의한다.

Φ=EAcos⁡θ=E⃗⋅A⃗\Phi = E A\cos\theta = \vec{E}\cdot\vec{A}Φ=EAcosθ=E⋅A

내적이 알아서 "뚫는 성분"만 골라낸다.

  • θ=0\theta = 0θ=0: E⃗∥A⃗\vec{E} \parallel \vec{A}E∥A → Φ=EA\Phi = EAΦ=EA (최대)
  • θ=90∘\theta = 90^\circθ=90∘: 장이 면을 스침 → Φ=0\Phi = 0Φ=0
  • 작은 조각(patch)에 대해서는 dΦ=E⃗⋅dA⃗d\Phi = \vec{E}\cdot d\vec{A}dΦ=E⋅dA

임의의 곡면: 적분으로

휘어진 곡면이나 위치에 따라 변하는 장은 어떻게 할까? 곡면을 아주 작은 면 요소(area element) dA⃗d\vec{A}dA들로 쪼갠다. 각 조각은 충분히 작아서 평평하고, 그 위에서 장은 균일하다고 볼 수 있다.

각 조각의 플럭스를 모두 더하면(적분):

Φ=∫E⃗⋅dA⃗(총 플럭스)\boxed{\Phi = \int \vec{E}\cdot d\vec{A}} \quad \text{(총 플럭스)}Φ=∫E⋅dA​(총 플럭스)

  • 플럭스는 스칼라 다 (내적의 결과)
  • SI 단위: N⋅m2/C\mathrm{N\cdot m^2/C}N⋅m2/C
  • 균일한 장 + 평평한 면이면 적분 없이 Φ=EAcos⁡θ\Phi = EA\cos\thetaΦ=EAcosθ

예제 1: 기울어진 평면의 플럭스

크기 E=2.0×103E = 2.0 \times 10^3E=2.0×103 N/C의 균일한 전기장 속에 넓이 A=0.30 m2A = 0.30\ \mathrm{m^2}A=0.30 m2인 평면이 있다. 면의 수직 방향이 장과 60∘60^\circ60∘를 이룰 때 플럭스를 구하라.

균일한 장, 평평한 면이므로:

Φ=EAcos⁡θ=(2.0×103)(0.30)cos⁡60∘\Phi = EA\cos\theta = (2.0\times 10^3)(0.30)\cos 60^\circΦ=EAcosθ=(2.0×103)(0.30)cos60∘

cos⁡60∘=0.5\cos 60^\circ = 0.5cos60∘=0.5이므로:

Φ=3.0×102 N⋅m2/C\boxed{\Phi = 3.0 \times 10^2\ \mathrm{N\cdot m^2/C}}Φ=3.0×102 N⋅m2/C​

만약 면을 장에 수직으로 세우면(θ=0\theta = 0θ=0) Φ=600 N⋅m2/C\Phi = 600\ \mathrm{N\cdot m^2/C}Φ=600 N⋅m2/C로 최대가 되고, 면을 장과 나란히 눕히면(θ=90∘\theta = 90^\circθ=90∘) 플럭스는 0이다.

닫힌 곡면: 방향의 약속

가우스 법칙에는 닫힌 곡면(closed surface) 이 필요하다. 닫힌 곡면에서는 면적 벡터 dA⃗d\vec{A}dA의 방향을 항상 바깥쪽 으로 잡기로 약속한다.

  • 장이 밖으로 나감: θ<90∘\theta < 90^\circθ<90∘, cos⁡θ>0\cos\theta > 0cosθ>0 → 플럭스 기여 양(+)
  • 장이 안으로 들어옴: θ>90∘\theta > 90^\circθ>90∘, cos⁡θ<0\cos\theta < 0cosθ<0 → 플럭스 기여 음(−)
  • 장이 면을 스침: θ=90∘\theta = 90^\circθ=90∘ → 기여 0

알짜 플럭스

닫힌 곡면 전체에 대한 적분은 적분 기호에 동그라미를 붙여 표시한다:

Φ=∮E⃗⋅dA⃗(알짜 플럭스)\boxed{\Phi = \oint \vec{E}\cdot d\vec{A}} \quad \text{(알짜 플럭스)}Φ=∮E⋅dA​(알짜 플럭스)

  • 곡면 전체 에 대해 부호를 포함하여 더한다
  • 한쪽으로 들어온 장이 반대쪽으로 그대로 나가면, 음의 기여와 양의 기여가 상쇄되어 알짜 플럭스는 0이 된다

들어온 만큼 나간다면 Φ=0\Phi = 0Φ=0 — 이 직관이 다음 예제에서 그대로 확인된다.

예제: 균일한 장 속의 닫힌 원통

반지름 RRR인 닫힌 원통이 균일한 장 E⃗\vec{E}E 속에 있고, 원통의 축이 장과 나란하다. 알짜 플럭스는?

곡면을 세 부분으로 나눈다: 왼쪽 뚜껑 aaa, 옆면 bbb, 오른쪽 뚜껑 ccc.

Φ=∮E⃗⋅dA⃗=∫aE⃗⋅dA⃗+∫bE⃗⋅dA⃗+∫cE⃗⋅dA⃗\Phi = \oint \vec{E}\cdot d\vec{A} = \int_a \vec{E}\cdot d\vec{A} + \int_b \vec{E}\cdot d\vec{A} + \int_c \vec{E}\cdot d\vec{A}Φ=∮E⋅dA=∫a​E⋅dA+∫b​E⋅dA+∫c​E⋅dA

왼쪽 뚜껑 aaa : dA⃗d\vec{A}dA는 바깥쪽(왼쪽), E⃗\vec{E}E는 오른쪽 → θ=180∘\theta = 180^\circθ=180∘

∫aE⃗⋅dA⃗=∫E(cos⁡180∘) dA=−EA\int_a \vec{E}\cdot d\vec{A} = \int E(\cos 180^\circ)\,dA = -EA∫a​E⋅dA=∫E(cos180∘)dA=−EA

예제: 닫힌 원통 (계속)

옆면 bbb : 장이 옆면을 스치며 지나간다 → θ=90∘\theta = 90^\circθ=90∘

∫bE⃗⋅dA⃗=∫E(cos⁡90∘) dA=0\int_b \vec{E}\cdot d\vec{A} = \int E(\cos 90^\circ)\,dA = 0∫b​E⋅dA=∫E(cos90∘)dA=0

오른쪽 뚜껑 ccc : dA⃗d\vec{A}dA와 E⃗\vec{E}E가 같은 방향 → θ=0\theta = 0θ=0

∫cE⃗⋅dA⃗=∫E(cos⁡0) dA=+EA\int_c \vec{E}\cdot d\vec{A} = \int E(\cos 0)\,dA = +EA∫c​E⋅dA=∫E(cos0)dA=+EA

셋을 더하면:

Φ=−EA+0+EA=0\Phi = -EA + 0 + EA = \boxed{0}Φ=−EA+0+EA=0​

장이 왼쪽으로 들어와 오른쪽으로 모두 빠져나가므로 알짜 플럭스는 0이다. 내부에 전하가 없으니 당연한 결과 — 가우스 법칙의 예고편이다.

생각해보기: 균일한 장 속의 정육면체

한 변의 넓이가 AAA인 정육면체가 균일한 장 E⃗\vec{E}E 속에 있다. 장은 +z+z+z 방향이다.

  • 장이 나가는 윗면(+z+z+z 쪽): Φ=+EA\Phi = +EAΦ=+EA
  • 장이 들어오는 아랫면(−z-z−z 쪽): Φ=−EA\Phi = -EAΦ=−EA
  • 나머지 네 옆면: 장이 스침 → Φ=0\Phi = 0Φ=0

전체 : +EA−EA+0=0+EA - EA + 0 = 0+EA−EA+0=0

균일한 장 속의 어떤 닫힌 곡면이든, 전하를 품지 않았다면 알짜 플럭스는 항상 0이다.

23.2 가우스 법칙

가우스 법칙

가우스 법칙(Gauss' law) 은 닫힌 곡면(가우스면)을 통과하는 알짜 플럭스 Φ\PhiΦ와 곡면이 둘러싼 알짜 전하 qencq_{\text{enc}}qenc​를 연결한다:

ε0Φ=qenc\boxed{\varepsilon_0 \Phi = q_{\text{enc}}}ε0​Φ=qenc​​

플럭스의 정의를 대입하면:

ε0∮E⃗⋅dA⃗=qenc\boxed{\varepsilon_0 \oint \vec{E}\cdot d\vec{A} = q_{\text{enc}}}ε0​∮E⋅dA=qenc​​

  • ε0=8.85×10−12 C2/(N⋅m2)\varepsilon_0 = 8.85\times 10^{-12}\ \mathrm{C^2/(N\cdot m^2)}ε0​=8.85×10−12 C2/(N⋅m2): 자유 공간의 유전율
  • 이 형태는 전하가 진공(또는 공기) 속에 있을 때 성립한다

부호가 알려주는 것

qencq_{\text{enc}}qenc​는 곡면 내부 의 모든 양전하와 음전하를 부호까지 살려 더한 대수합 이다.

  • qenc>0q_{\text{enc}} > 0qenc​>0 → 알짜 플럭스는 바깥쪽 (장이 전체적으로 나감)
  • qenc<0q_{\text{enc}} < 0qenc​<0 → 알짜 플럭스는 안쪽 (장이 전체적으로 들어옴)
  • qenc=0q_{\text{enc}} = 0qenc​=0 → 알짜 플럭스 0

내부 전하의 위치나 배치는 전혀 상관없다. 오직 알짜량 만이 플럭스를 결정한다.

바깥 전하는 왜 상관없나?

곡면 바깥 의 전하는 아무리 크고 가까워도 qencq_{\text{enc}}qenc​에 넣지 않는다.

  • 바깥 전하가 만드는 필드라인은 곡면의 한쪽으로 들어와서 반대쪽으로 나간다
  • 들어온 만큼(−) 나가므로(+) 알짜 기여는 정확히 0

주의할 점: 적분 속의 E⃗\vec{E}E는 안팎 모든 전하 가 만드는 전체 전기장이다. 그런데도 알짜 플럭스에는 내부 전하만 남는다 — 바깥 전하의 기여가 자동으로 상쇄되기 때문이다.

네 개의 가우스면

크기가 같고 부호가 반대인 두 전하 주위에 가우스면 네 개를 그려 보자.

  • S1S_1S1​ (양전하만 포함): 장이 모든 점에서 밖으로 → Φ>0\Phi > 0Φ>0, qenc=+qq_{\text{enc}} = +qqenc​=+q
  • S2S_2S2​ (음전하만 포함): 장이 모든 점에서 안으로 → Φ<0\Phi < 0Φ<0, qenc=−qq_{\text{enc}} = -qqenc​=−q
  • S3S_3S3​ (전하 없음): 위로 들어와 아래로 나감 → Φ=0\Phi = 0Φ=0, qenc=0q_{\text{enc}} = 0qenc​=0
  • S4S_4S4​ (둘 다 포함): 알짜 전하 +q+(−q)=0+q + (-q) = 0+q+(−q)=0 → Φ=0\Phi = 0Φ=0

여기에 거대한 전하 QQQ를 근처에 가져와도 네 곡면의 알짜 플럭스는 하나도 변하지 않는다. QQQ는 모든 곡면의 바깥에 있기 때문이다.

가우스 법칙 — 전하를 드래그하며 가우스면의 플럭스 관찰

가우스 법칙 → 쿨롱 법칙

가우스 법칙이 정말 옳다면, 점전하의 전기장(쿨롱 법칙)을 유도할 수 있어야 한다.

점전하 qqq의 장은 구 대칭(spherical symmetry) — 크기는 거리 rrr에만 의존하고 방향은 지름 방향이다. 대칭을 살려 전하를 중심에 둔 반지름 rrr의 가우스 구면 을 잡자.

구면 위 어느 점에서나 (1) EEE의 크기가 같고, (2) E⃗\vec{E}E와 dA⃗d\vec{A}dA가 나란하다(θ=0\theta = 0θ=0).

유도: 적분이 사라진다

가우스 법칙에서 시작한다:

ε0∮E⃗⋅dA⃗=ε0∮Ecos⁡0 dA=ε0∮E dA=qenc\varepsilon_0 \oint \vec{E}\cdot d\vec{A} = \varepsilon_0 \oint E\cos 0\, dA = \varepsilon_0 \oint E\, dA = q_{\text{enc}}ε0​∮E⋅dA=ε0​∮Ecos0dA=ε0​∮EdA=qenc​

EEE는 구면 위에서 상수이므로 적분 밖으로 나온다. 남은 ∮dA\oint dA∮dA는 그냥 구의 겉넓이 4πr24\pi r^24πr2:

ε0E∮dA=ε0E(4πr2)=q\varepsilon_0 E \oint dA = \varepsilon_0 E (4\pi r^2) = qε0​E∮dA=ε0​E(4πr2)=q

EEE에 대해 풀면:

E=14πε0qr2\boxed{E = \frac{1}{4\pi\varepsilon_0}\frac{q}{r^2}}E=4πε0​1​r2q​​

22장에서 쿨롱 법칙으로 구한 점전하의 전기장과 정확히 같다. 가우스 법칙과 쿨롱 법칙은 동등하다.

예제 2: 껍질 속의 입자 (b)

같은 상황에서 껍질 바깥, 반지름 r2=12.0r_2 = 12.0r2​=12.0 cm인 지점의 전기장은?

23.3 대전된 고립 도체

잉여 전하는 모두 표면으로 간다

가우스 법칙으로 도체에 관한 중요한 정리를 증명할 수 있다:

고립된 도체에 잉여 전하를 올려놓으면, 그 전하는 전부 도체의 표면 으로 이동한다. 도체 내부에는 잉여 전하가 전혀 없다.

직관적으로도 그럴듯하다: 같은 부호의 전하는 서로 밀어내므로, 서로 최대한 멀어지려면 표면까지 가야 한다.

가우스 법칙은 이것을 엄밀하게 증명해 준다. 열쇠는 도체 내부의 전기장이 0 이라는 사실이다.

증명: 내부 E = 0 이면 내부 전하도 0

1단계 — 정전 평형 상태의 도체 내부에서는 E⃗=0\vec{E} = 0E=0이다. 만약 내부에 장이 있다면 전도 전자들이 힘을 받아 계속 움직일 것이다(전류 발생). 고립 도체에 그런 영구 전류는 없으므로 내부 장은 0이어야 한다.

2단계 — 도체 표면 바로 안쪽 에 가우스면을 그린다.

3단계 — 가우스면 위 모든 점에서 E⃗=0\vec{E} = 0E=0이므로 플럭스도 0. 가우스 법칙에 의해 qenc=0q_{\text{enc}} = 0qenc​=0. 잉여 전하는 가우스면 안에 있을 수 없다 → 남은 곳은 표면 뿐이다.

공동이 있는 도체

도체 속을 파내어 빈 공동(cavity) 을 만들면 어떻게 될까?

  • 공동을 둘러싸는 가우스면을 도체 살 속에 그린다
  • 도체 내부이므로 가우스면 위에서 E⃗=0\vec{E} = 0E=0 → 플럭스 0 → qenc=0q_{\text{enc}} = 0qenc​=0
  • 따라서 공동 벽에는 전하가 없다

전하 분포도, 외부 전기장도 공동을 파내기 전과 완전히 똑같다. 전기장은 도체가 아니라 전하 가 만드는 것이고, 도체는 전하가 자리 잡는 길을 제공할 뿐이다.

패러데이 상자: 도체 속은 안전하다

도체로 둘러싸인 공간은 외부 전기장으로부터 차폐된다. 이를 패러데이 상자(Faraday cage) 라 한다.

테슬라 코일의 강력한 방전이 금속 그물을 직접 때려도, 안에 있는 사람은 안전하다. 전하가 도체 표면에서 재배치되어 내부 장을 0으로 만들기 때문이다. 자동차가 벼락에 강한 이유, 엘리베이터 안에서 휴대전화가 잘 안 터지는 이유도 같은 원리다.

도체 표면 바로 밖의 전기장

도체 표면의 전하 밀도 σ\sigmaσ는 일반적으로 위치마다 다르다(구가 아니면 균일하지 않다). 하지만 표면 바로 밖 의 장은 가우스 법칙으로 쉽게 구할 수 있다.

정전 평형에서 표면 밖의 E⃗\vec{E}E는 표면에 수직 이다. 나란한 성분이 있다면 표면 전하가 힘을 받아 움직일 테니까.

작은 원통(필박스)을 표면에 수직으로 꽂는다: 한쪽 캡은 도체 안, 다른 캡은 도체 밖.

E = σ/ε₀ 유도

필박스를 통과하는 플럭스를 부분별로 따져 보자:

  • 안쪽 캡: 도체 내부라 E=0E = 0E=0 → 플럭스 0
  • 옆면: 안쪽은 장이 없고, 바깥쪽은 장이 옆면을 스침 → 플럭스 0
  • 바깥쪽 캡(면적 AAA): 장이 수직으로 통과 → 플럭스 EAEAEA

갇힌 전하는 표면 조각의 σA\sigma AσA. 가우스 법칙:

ε0EA=σA⇒E=σε0(도체 표면)\varepsilon_0 E A = \sigma A \quad\Rightarrow\quad \boxed{E = \frac{\sigma}{\varepsilon_0}} \quad \text{(도체 표면)}ε0​EA=σA⇒E=ε0​σ​​(도체 표면)

간단 확인 — 복사기 드럼 표면 바로 밖의 장이 2.0×1052.0\times 10^52.0×105 N/C라면: σ=ε0E=(8.85×10−12)(2.0×105)≈1.8 μC/m2\sigma = \varepsilon_0 E = (8.85\times 10^{-12})(2.0\times 10^5) \approx 1.8\ \mu\mathrm{C/m^2}σ=ε0​E=(8.85×10−12)(2.0×105)≈1.8 μC/m2

개념 예제: 중성 금속 껍질 속의 전하

전기적으로 중성인 금속 구 껍질 안, 중심에서 벗어난 곳에 전하 −5.0 μC-5.0\ \mu\mathrm{C}−5.0 μC 입자가 있다. 껍질의 안팎 벽에는 어떤 전하가 유도될까?

  • 껍질 살 속에 가우스면을 그리면 그 위에서 E=0E = 0E=0 → qenc=0q_{\text{enc}} = 0qenc​=0
  • 따라서 안쪽 벽 에 +5.0 μC+5.0\ \mu\mathrm{C}+5.0 μC가 유도되어야 한다 (입자가 치우쳐 있으므로 분포는 비균일 — 입자와 가까운 쪽에 몰린다)
  • 껍질은 중성이므로 바깥 벽 에는 −5.0 μC-5.0\ \mu\mathrm{C}−5.0 μC가 남는다
  • 바깥 벽의 전하는 균일하게 분포한다: 안쪽 사정은 도체 살(E=0)에 가로막혀 바깥에 전달되지 않기 때문

껍질 밖의 필드라인은 입자가 중심에 있는 것처럼 대칭적이다.

23.4 가우스 법칙 적용: 원통 대칭

무한 선전하의 전기장

균일한 선전하 밀도 λ\lambdaλ (C/m)를 가진 무한히 긴 직선 전하를 생각하자. 축에서 거리 rrr인 곳의 전기장은?

대칭 분석: 선이 무한히 길고 균일하므로, 장은 어느 지점에서나 지름 방향 (λ>0\lambda > 0λ>0이면 바깥쪽)이고 크기는 rrr에만 의존한다 — 원통 대칭(cylindrical symmetry) 이다.

대칭에 맞는 가우스면: 선을 축으로 하는 반지름 rrr, 높이 hhh의 동축 원통.

유도: E = λ/(2πε₀r)

플럭스를 부분별로 계산한다:

  • 위·아래 캡: 장이 지름 방향이라 캡 면을 스침 → 플럭스 0
  • 옆면: 모든 점에서 E⃗∥dA⃗\vec{E} \parallel d\vec{A}E∥dA, 크기 일정 → Φ=E×(옆넓이)=E(2πrh)\Phi = E \times (\text{옆넓이}) = E(2\pi r h)Φ=E×(옆넓이)=E(2πrh)

원통이 가둔 전하는 길이 hhh만큼의 선전하, 즉 qenc=λhq_{\text{enc}} = \lambda hqenc​=λh. 가우스 법칙:

ε0E(2πrh)=λh\varepsilon_0 E (2\pi r h) = \lambda hε0​E(2πrh)=λh

hhh가 약분되고:

E=λ2πε0r(무한 선전하)\boxed{E = \frac{\lambda}{2\pi\varepsilon_0 r}} \quad \text{(무한 선전하)}E=2πε0​rλ​​(무한 선전하)

1/r21/r^21/r2이 아니라 1/r1/r1/r로 감소한다! 유한한 막대도 끝에서 멀리 떨어진 지점에서는 이 식이 좋은 근사가 된다.

번개가 번쩍이기 전, 구름에서 땅으로 전자 기둥이 먼저 내려온다. 기둥의 선전하 밀도는 대략 λ=−1×10−3\lambda = -1\times 10^{-3}λ=−1×10−3 C/m. 공기는 전기장이 3×1063\times 10^63×106 N/C을 넘으면 이온화(절연 파괴)된다. 이온화가 일어나는 기둥의 반지름은?

23.5 가우스 법칙 적용: 평면 대칭

무한 부도체 판

균일한 면전하 밀도 σ\sigmaσ (C/m²)를 가진 얇은 무한 부도체 판. 판에서 거리 rrr인 곳의 장은?

대칭 분석: 판이 무한하고 균일하므로 E⃗\vec{E}E는 판에 수직 이고, 양쪽으로 똑같은 크기로 뻗는다 (σ>0\sigma > 0σ>0이면 판에서 멀어지는 방향).

가우스면: 판을 수직으로 관통하는 원통(필박스). 양쪽 캡(각각 면적 AAA)이 판에서 같은 거리에 있게 잡는다.

유도: E = σ/2ε₀

  • 양쪽 캡: 장이 수직으로 나감, E⃗∥dA⃗\vec{E} \parallel d\vec{A}E∥dA → 각각 +EA+EA+EA
  • 옆면: 장이 스침 → 0

원통이 가둔 전하는 판 조각의 σA\sigma AσA. 가우스 법칙:

ε0(EA+EA)=σA\varepsilon_0(EA + EA) = \sigma Aε0​(EA+EA)=σA

E=σ2ε0(무한 부도체 판)\boxed{E = \frac{\sigma}{2\varepsilon_0}} \quad \text{(무한 부도체 판)}E=2ε0​σ​​(무한 부도체 판)

놀라운 점: 거리에 무관 하다! 판이 무한하면 아무리 멀어져도 장이 약해지지 않는다. 실제 유한한 판도, 가장자리에 비해 판에 가까운 지점에서는 이 식이 잘 맞는다.

도체 판 하나, 그리고 둘

도체 판 하나: 잉여 전하는 표면으로 가고, 얇고 넓은 판이면 양쪽 면에 절반씩, 밀도 σ1\sigma_1σ1​로 퍼진다. 판 밖의 장은 도체 표면 공식 그대로 E=σ1/ε0E = \sigma_1/\varepsilon_0E=σ1​/ε0​.

양(+)판과 음(−)판을 가까이 평행하게 놓으면 상황이 변한다:

  • 서로 끌어당겨 모든 잉여 전하가 마주 보는 안쪽 면 으로 이동한다
  • 안쪽 면의 밀도는 두 배가 되어 σ=2σ1\sigma = 2\sigma_1σ=2σ1​
  • 판 사이: E=σ/ε0E = \sigma/\varepsilon_0E=σ/ε0​ (균일), 판 바깥: E=0E = 0E=0

이것이 다음 장들에서 만날 축전기(capacitor) 의 원형이다.

23.6 가우스 법칙 적용: 구 대칭

껍질 정리, 이번에는 증명한다

21장에서 증명 없이 사용했던 두 껍질 정리(shell theorem) :

  1. 균일하게 대전된 구 껍질은 바깥 의 전하에게, 껍질의 전하가 모두 중심에 모인 점전하 처럼 작용한다
  2. 균일하게 대전된 구 껍질 안 의 전하는 껍질로부터 알짜 정전기력을 받지 않는다

쿨롱 법칙으로 증명하려면 힘든 적분이 필요하지만, 가우스 법칙을 쓰면 몇 줄 로 끝난다.

껍질 밖과 안

총 전하 qqq, 반지름 RRR인 얇은 구 껍질에 동심 가우스 구면 두 개를 잡는다.

S2S_2S2​ (r≥Rr \ge Rr≥R) : 점전하 유도와 똑같이 ε0E(4πr2)=q\varepsilon_0 E(4\pi r^2) = qε0​E(4πr2)=q:

임의의 구 대칭 분포: 양파 껍질 논리

전하 밀도 ρ\rhoρ가 중심 거리 rrr에만 의존하는 분포는 얇은 동심 껍질들을 겹겹이 쌓은 것으로 볼 수 있다 (양파처럼).

반지름 rrr인 지점의 장을 구할 때, 두 껍질 정리를 적용하면:

  • 가우스면 밖 의 껍질들: 내부에 장을 만들지 않음 → 기여 0
  • 가우스면 안 의 껍질들: 모두 중심의 점전하처럼 작용

따라서 안쪽 전하를 q′q'q′라 하면:
