2장: 직선 운동

Motion Along a Straight Line

이번 장에서 배울 내용

  • 위치(position) 와 변위(displacement): 물체가 어디에 있고, 얼마나 이동했는가
  • 평균 속도(average velocity) 와 순간 속도(instantaneous velocity)
  • 가속도(acceleration): 속도가 변하는 비율
  • 등가속도 운동 의 5가지 공식 — 완전 유도
  • 자유 낙하(free fall): a=−ga = -ga=−g인 특수한 등가속도 운동
  • 그래프로 이해하는 운동: xxx-ttt, vvv-ttt, aaa-ttt 그래프

운동학이란?

운동학(kinematics) 은 물체의 운동을 기술하는 학문이다.

이 장에서는 가장 단순한 경우부터 시작한다:

  • 물체를 입자(particle) 로 취급 (크기 무시)
  • 직선 위 에서만 운동 (1차원)
  • "왜 움직이는가?"는 묻지 않는다 → 그건 힘과 뉴턴 법칙(4장)의 영역

예: KTX가 서울에서 부산까지 달리는 상황에서, KTX의 길이(약 388 m)는 서울-부산 거리(약 400 km)에 비해 무시할 수 있으므로 입자로 취급한다.

2.1 위치와 변위

위치(Position)

1차원 운동을 기술하려면 먼저 좌표축 을 정해야 한다.

  • 원점(origin) OOO를 정하고
  • 양의 방향 을 정한다 (보통 오른쪽)
  • 물체의 위치 xxx는 원점에서 물체까지의 거리(부호 포함)

변위(Displacement)

물체가 위치 x1x_1x1​에서 x2x_2x2​로 이동했을 때, 변위 :

Δx=x2−x1\Delta x = x_2 - x_1Δx=x2​−x1​

  • Δx>0\Delta x > 0Δx>0: 양의 방향으로 이동
  • Δx<0\Delta x < 0Δx<0: 음의 방향으로 이동
  • 변위는 벡터 적 개념 — 크기와 방향이 있다

변위 ≠ 이동 거리(distance)

서울 지하철 2호선을 한 바퀴 타면 이동 거리는 약 48 km이지만, 변위는 0이다!

2.2 평균 속도와 평균 속력

평균 속도(Average Velocity)

시간 Δt=t2−t1\Delta t = t_2 - t_1Δt=t2​−t1​ 동안 변위 Δx\Delta xΔx를 이동했을 때:

vavg=ΔxΔt=x2−x1t2−t1v_\text{avg} = \frac{\Delta x}{\Delta t} = \frac{x_2 - x_1}{t_2 - t_1}vavg​=ΔtΔx​=t2​−t1​x2​−x1​​

xxx-ttt 그래프에서 평균 속도는 두 점을 잇는 할선(secant line) 의 기울기다.

평균 속력(Average Speed)

savg=총 이동 거리Δts_\text{avg} = \frac{\text{총 이동 거리}}{\Delta t}savg​=Δt총 이동 거리​

  • 평균 속력은 스칼라 이다 (항상 ≥ 0)
  • 평균 속도와 일반적으로 다르다!

예시: KTX가 서울 → 부산(400 km)을 2시간 20분에 주파하면

savg=400 km2.33 h≈172 km/hs_\text{avg} = \frac{400 \text{ km}}{2.33 \text{ h}} \approx 172 \text{ km/h}savg​=2.33 h400 km​≈172 km/h

만약 되돌아왔다면 평균 속도는 0이지만, 평균 속력은 172 km/h이다.

2.3 순간 속도

순간 속도(Instantaneous Velocity)

Δt\Delta tΔt를 점점 줄여 0에 가깝게 하면:

v=lim⁡Δt→0ΔxΔt=dxdtv = \lim_{\Delta t \to 0} \frac{\Delta x}{\Delta t} = \frac{dx}{dt}v=Δt→0lim​ΔtΔx​=dtdx​

순간 속도는 위치의 시간 미분 이다.

xxx-ttt 그래프에서 순간 속도는 해당 점에서의 접선(tangent line) 의 기울기다.

순간 속력(Instantaneous Speed)

순간 속력(speed) 은 순간 속도의 크기:

speed=∣v∣\text{speed} = |v|speed=∣v∣

속도가 양이면 양의 방향, 음이면 음의 방향으로 운동 중이다.

2.4 가속도

평균 가속도(Average Acceleration)

속도가 변하면 물체는 가속 한다.

시간 Δt\Delta tΔt 동안 속도가 v1v_1v1​에서 v2v_2v2​로 변할 때:

aavg=ΔvΔt=v2−v1t2−t1a_\text{avg} = \frac{\Delta v}{\Delta t} = \frac{v_2 - v_1}{t_2 - t_1}aavg​=ΔtΔv​=t2​−t1​v2​−v1​​

순간 가속도(Instantaneous Acceleration)

a=dvdt=d2xdt2a = \frac{dv}{dt} = \frac{d^2 x}{dt^2}a=dtdv​=dt2d2x​

가속도는 속도의 시간 미분 이고, 위치의 이계 미분 이다.

vvv-ttt 그래프에서 가속도는 접선의 기울기 다.

  • a>0a > 0a>0: 속도가 양의 방향으로 증가
  • a<0a < 0a<0: 속도가 음의 방향으로 증가 (양의 방향으로 감소)

주의: "감속"이라고 해서 a<0a < 0a<0인 것은 아니다. 감속은 ∣v∣|v|∣v∣가 줄어드는 것이므로, vvv와 aaa의 부호가 반대일 때 감속이다.

2.5 등가속도 운동

가속도가 일정한 경우: a=consta = \text{const}a=const

이 특수한 경우에 5개의 기본 공식이 존재한다. 하나씩 유도해 보자.

공식 1: 속도-시간 관계

가속도의 정의에서 출발:

a=dvdt=consta = \frac{dv}{dt} = \text{const}a=dtdv​=const

t=0t = 0t=0일 때 v=v0v = v_0v=v0​으로 적분하면:

∫v0vdv′=∫0ta dt′\int_{v_0}^{v} dv' = \int_0^t a\, dt'∫v0​v​dv′=∫0t​adt′

v−v0=atv - v_0 = atv−v0​=at

v=v0+at⋯(1)\boxed{v = v_0 + at} \quad \cdots (1)v=v0​+at​⋯(1)

속도는 시간에 대해 선형 으로 변한다.

공식 2: 위치-시간 관계

속도의 정의에서:

v=dxdtv = \frac{dx}{dt}v=dtdx​

공식 (1)을 대입하고, t=0t = 0t=0일 때 x=x0x = x_0x=x0​으로 적분:

∫x0xdx′=∫0t(v0+at′) dt′\int_{x_0}^{x} dx' = \int_0^t (v_0 + at')\, dt'∫x0​x​dx′=∫0t​(v0​+at′)dt′

x−x0=v0t+12at2x - x_0 = v_0 t + \frac{1}{2}at^2x−x0​=v0​t+21​at2

x=x0+v0t+12at2⋯(2)\boxed{x = x_0 + v_0 t + \frac{1}{2}at^2} \quad \cdots (2)x=x0​+v0​t+21​at2​⋯(2)

위치는 시간에 대한 이차함수(포물선) 이다.

공식 3: 속도-위치 관계 (시간 소거)

공식 (1)에서 t=v−v0at = \frac{v - v_0}{a}t=av−v0​​를 공식 (2)에 대입:

x−x0=v0⋅v−v0a+12a(v−v0a)2x - x_0 = v_0 \cdot \frac{v - v_0}{a} + \frac{1}{2}a \left(\frac{v - v_0}{a}\right)^2x−x0​=v0​⋅av−v0​​+21​a(av−v0​​)2

x−x0=v0v−v02a+(v−v0)22ax - x_0 = \frac{v_0 v - v_0^2}{a} + \frac{(v - v_0)^2}{2a}x−x0​=av0​v−v02​​+2a(v−v0​)2​

2a(x−x0)=2v0v−2v02+v2−2v0v+v022a(x - x_0) = 2v_0 v - 2v_0^2 + v^2 - 2v_0 v + v_0^22a(x−x0​)=2v0​v−2v02​+v2−2v0​v+v02​

2a(x−x0)=v2−v022a(x - x_0) = v^2 - v_0^22a(x−x0​)=v2−v02​

v2=v02+2a(x−x0)⋯(3)\boxed{v^2 = v_0^2 + 2a(x - x_0)} \quad \cdots (3)v2=v02​+2a(x−x0​)​⋯(3)

시간 ttt가 등장하지 않으므로, ttt를 모를 때 유용하다.

공식 4, 5: 평균 속도 활용

등가속도 운동에서 평균 속도 :

vavg=v0+v2⋯(4)\boxed{v_\text{avg} = \frac{v_0 + v}{2}} \quad \cdots (4)vavg​=2v0​+v​​⋯(4)

변위를 평균 속도로 표현:

x−x0=v0+v2⋅t⋯(5)\boxed{x - x_0 = \frac{v_0 + v}{2} \cdot t} \quad \cdots (5)x−x0​=2v0​+v​⋅t​⋯(5)

등가속도 운동 5대 공식 정리

번호 공식 포함하지 않는 변수
(1) v=v0+atv = v_0 + atv=v0​+at xxx
(2) x=x0+v0t+12at2x = x_0 + v_0 t + \frac{1}{2}at^2x=x0​+v0​t+21​at2 vvv
(3) v2=v02+2a(x−x0)v^2 = v_0^2 + 2a(x - x_0)v2=v02​+2a(x−x0​) ttt
(4) vavg=v0+v2v_\text{avg} = \frac{v_0 + v}{2}vavg​=2v0​+v​ x,tx, tx,t
(5) x−x0=v0+v2⋅tx - x_0 = \frac{v_0 + v}{2} \cdot tx−x0​=2v0​+v​⋅t aaa

5개의 변수 (xxx, vvv, aaa, ttt, v0v_0v0​) 중 3개 를 알면 나머지 2개를 구할 수 있다.

2.6 자유 낙하

자유 낙하(Free Fall)란?

자유 낙하 란 중력만 작용하는 운동이다.

  • 공기 저항을 무시하면, 모든 물체는 질량에 관계없이 같은 가속도 로 낙하한다
  • 이 가속도를 중력가속도 라 부르고 ggg로 표기한다

g=9.8 m/s2≈10 m/s2g = 9.8 \text{ m/s}^2 \approx 10 \text{ m/s}^2g=9.8 m/s2≈10 m/s2

자유 낙하에서의 좌표계

yyy축을 위쪽을 양의 방향 으로 잡으면:

a=−g=−9.8 m/s2a = -g = -9.8 \text{ m/s}^2a=−g=−9.8 m/s2

등가속도 공식에서 x→yx \to yx→y, a→−ga \to -ga→−g로 바꾸면:

v=v0−gtv = v_0 - gtv=v0​−gt

y=y0+v0t−12gt2y = y_0 + v_0 t - \frac{1}{2}gt^2y=y0​+v0​t−21​gt2

v2=v02−2g(y−y0)v^2 = v_0^2 - 2g(y - y_0)v2=v02​−2g(y−y0​)

위로 던진 물체

초기 속도 v0>0v_0 > 0v0​>0 (위쪽)으로 공을 던지면:

  1. 상승 구간: 속도 감소, v>0v > 0v>0
  2. 최고점: v=0v = 0v=0 → tpeak=v0gt_\text{peak} = \frac{v_0}{g}tpeak​=gv0​​
  3. 하강 구간: 속도 증가 (아래로), v<0v < 0v<0

최고점 높이:

ymax=y0+v022gy_\text{max} = y_0 + \frac{v_0^2}{2g}ymax​=y0​+2gv02​​

63빌딩 옥상(높이 약 250 m)에서 공을 가만히 놓으면 지면에 닿을 때 속력은?

v2=0+2(9.8)(250)=4900v^2 = 0 + 2(9.8)(250) = 4900v2=0+2(9.8)(250)=4900

v=70v = 70v=70 m/s ≈252\approx 252≈252 km/h

위로 던진 물체의 그래프

  • yyy-ttt: 아래로 볼록한 포물선 (최고점에서 v=0v = 0v=0)
  • vvv-ttt: 기울기 −g-g−g인 직선 (음의 기울기)
  • 상승/하강 시 가속도는 항상 −g-g−g (변하지 않는다!)

2.7 그래프로 이해하는 적분

v-t 그래프의 넓이 = 변위

속도의 정의 v=dx/dtv = dx/dtv=dx/dt에서:

dx=v dtdx = v\, dtdx=vdt

양변을 t1t_1t1​에서 t2t_2t2​까지 적분:

Δx=x2−x1=∫t1t2v(t) dt\Delta x = x_2 - x_1 = \int_{t_1}^{t_2} v(t)\, dtΔx=x2​−x1​=∫t1​t2​​v(t)dt

vvv-ttt 그래프에서 곡선과 시간축 사이의 넓이 가 변위다.

a-t 그래프의 넓이 = 속도 변화

마찬가지로 a=dv/dta = dv/dta=dv/dt에서:

Δv=v2−v1=∫t1t2a(t) dt\Delta v = v_2 - v_1 = \int_{t_1}^{t_2} a(t)\, dtΔv=v2​−v1​=∫t1​t2​​a(t)dt

aaa-ttt 그래프에서 곡선과 시간축 사이의 넓이 가 속도의 변화량이다.

그래프 해석 정리

그래프 기울기의 의미 넓이의 의미
xxx-ttt 순간 속도 vvv —
vvv-ttt 순간 가속도 aaa 변위 Δx\Delta xΔx

이 관계를 잘 기억하면 그래프만 보고도 운동을 분석할 수 있다!
