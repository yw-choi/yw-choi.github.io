Oscillations

이번 장에서 배울 내용

  • 단순조화운동(simple harmonic motion, SHM) : 자연에서 가장 기본적인 주기 운동
  • 변위, 속도, 가속도 의 시간 함수: x(t)x(t)x(t), v(t)v(t)v(t), a(t)a(t)a(t)
  • 에너지 보존 : 운동에너지와 퍼텐셜에너지의 교환

  • 감쇠진동(damped oscillation) 과 강제진동(forced oscillation)
  • 공명(resonance) : 왜 특정 진동수에서 진폭이 폭발적으로 커지는가

진동은 어디에나 있다

우리 주변은 진동으로 가득하다.

  • 스마트폰의 진동 모터, 시계의 진자
  • 지진파에 의한 건물의 흔들림

모든 진동 시스템에는 "탄성" (복원력을 제공)과 "관성" (운동을 유지)이라는 두 요소가 존재한다. 이 장에서는 가장 기본적인 진동인 단순조화운동 을 깊이 이해한다.

15.1 단순조화운동

주기 운동의 기본 개념

주기적으로 반복되는 운동을 주기 운동(periodic motion) 이라 한다.

  • 진동수(frequency) fff: 단위 시간당 진동 횟수. 단위는 Hz (1  Hz=1  s−11\;\text{Hz} = 1\;\text{s}^{-1}1Hz=1s−1)
  • 주기(period) TTT: 한 번의 완전한 진동에 걸리는 시간

T=1fT = \frac{1}{f}T=f1​

주기 운동 중에서 사인 함수(또는 코사인 함수) 로 기술되는 운동을 단순조화운동(SHM) 이라 한다.

SHM의 변위 함수

SHM을 하는 입자의 위치:

x(t)=xmcos⁡(ωt+ϕ)x(t) = x_m \cos(\omega t + \phi)x(t)=xm​cos(ωt+ϕ)

  • xmx_mxm​: 진폭(amplitude). 평형 위치에서 최대 변위까지의 거리 (항상 양수)
  • ω\omegaω: 각진동수(angular frequency). 단위 rad/s
  • ϕ\phiϕ: 위상 상수(phase constant). 초기 조건에 의해 결정
  • ωt+ϕ\omega t + \phiωt+ϕ: 위상(phase)

각진동수, 주기, 진동수의 관계

한 주기 TTT 동안 위상이 2π2\pi2π 변하므로:

ωT=2π\omega T = 2\piωT=2π

ω=2πT=2πf\omega = \frac{2\pi}{T} = 2\pi fω=T2π​=2πf

물리량 기호 단위 관계
주기 TTT s T=1/f=2π/ωT = 1/f = 2\pi/\omegaT=1/f=2π/ω

SHM의 속도

x(t)x(t)x(t)를 시간에 대해 미분하면:

v(t)=dxdt=−ωxmsin⁡(ωt+ϕ)v(t) = \frac{dx}{dt} = -\omega x_m \sin(\omega t + \phi)v(t)=dtdx​=−ωxm​sin(ωt+ϕ)

  • 속도 진폭(velocity amplitude) : vm=ωxmv_m = \omega x_mvm​=ωxm​
  • x=0x = 0x=0 (평형점)에서 속력이 최대: ∣v∣=ωxm|v| = \omega x_m∣v∣=ωxm​
  • x=±xmx = \pm x_mx=±xm​ (양 끝)에서 속력이 0

SHM의 가속도

v(t)v(t)v(t)를 다시 미분하면:

a(t)=dvdt=−ω2xmcos⁡(ωt+ϕ)a(t) = \frac{dv}{dt} = -\omega^2 x_m \cos(\omega t + \phi)a(t)=dtdv​=−ω2xm​cos(ωt+ϕ)

  • 가속도 진폭(acceleration amplitude) : am=ω2xma_m = \omega^2 x_mam​=ω2xm​

이것이 SHM의 핵심 특징 이다: 가속도가 변위에 비례하고 방향이 반대!

ω=km\boxed{\omega = \sqrt{\frac{k}{m}}}ω=mk​​​

  • kkk가 크면 (빳빳한 용수철) → TTT 감소 → 빠른 진동
  • mmm이 크면 (무거운 물체) → TTT 증가 → 느린 진동
  • 진폭 xmx_mxm​에 무관. 진폭이 커져도 주기는 같다! (SHM의 등시성)

모든 진동계에는 "탄성" 요소 (에너지를 저장하는 용수철 역할)와 "관성" 요소 (운동에너지를 저장하는 질량 역할)가 있다.

15.2 단순조화운동의 에너지

에너지의 교환

운동에너지와 퍼텐셜에너지

퍼텐셜에너지(elastic potential energy) :

U(t)=12kx2=12kxm2cos⁡2(ωt+ϕ)U(t) = \frac{1}{2}kx^2 = \frac{1}{2}kx_m^2\cos^2(\omega t + \phi)U(t)=21​kx2=21​kxm2​cos2(ωt+ϕ)

운동에너지(kinetic energy) :

K(t)=12mv2=12mω2xm2sin⁡2(ωt+ϕ)=12kxm2sin⁡2(ωt+ϕ)K(t) = \frac{1}{2}mv^2 = \frac{1}{2}m\omega^2 x_m^2\sin^2(\omega t + \phi) = \frac{1}{2}kx_m^2\sin^2(\omega t + \phi)K(t)=21​mv2=21​mω2xm2​sin2(ωt+ϕ)=21​kxm2​sin2(ωt+ϕ)

(여기서 mω2=km\omega^2 = kmω2=k를 사용했다.)

역학적 에너지 보존

E=K+U=12kxm2sin⁡2(ωt+ϕ)+12kxm2cos⁡2(ωt+ϕ)E = K + U = \frac{1}{2}kx_m^2\sin^2(\omega t + \phi) + \frac{1}{2}kx_m^2\cos^2(\omega t + \phi)E=K+U=21​kxm2​sin2(ωt+ϕ)+21​kxm2​cos2(ωt+ϕ)

=12kxm2[sin⁡2(ωt+ϕ)+cos⁡2(ωt+ϕ)]= \frac{1}{2}kx_m^2[\sin^2(\omega t + \phi) + \cos^2(\omega t + \phi)]=21​kxm2​[sin2(ωt+ϕ)+cos2(ωt+ϕ)]

E=12kxm2=일정\boxed{E = \frac{1}{2}kx_m^2 = \text{일정}}E=21​kxm2​=일정​

  • x=0x = 0x=0에서: K=EK = EK=E (모두 운동에너지), U=0U = 0U=0
  • x=±xmx = \pm x_mx=±xm​에서: U=EU = EU=E (모두 퍼텐셜에너지), K=0K = 0K=0

에너지가 운동에너지와 퍼텐셜에너지 사이를 끊임없이 교환하지만, 전체 역학적 에너지는 보존 된다.

속력과 변위의 관계

에너지 보존 12mv2+12kx2=12kxm2\frac{1}{2}mv^2 + \frac{1}{2}kx^2 = \frac{1}{2}kx_m^221​mv2+21​kx2=21​kxm2​에서:

v=±ωxm2−x2v = \pm\omega\sqrt{x_m^2 - x^2}v=±ωxm2​−x2​

이 관계를 사용하면 임의의 위치 xxx에서의 속력을 바로 구할 수 있다.

15.3 각 단순조화진동자

비틀림 진자

비틀림 진자(torsion pendulum) : 와이어에 매달린 원판이 비틀림으로 진동

복원 돌림힘:

τ=−κθ\tau = -\kappa\thetaτ=−κθ

여기서 κ\kappaκ는 비틀림 상수(torsion constant) 이다.

훅 법칙 F=−kxF = -kxF=−kx와 같은 구조! (x→θx \to \thetax→θ, k→κk \to \kappak→κ, m→Im \to Im→I)

T=2πIκ\boxed{T = 2\pi\sqrt{\frac{I}{\kappa}}}T=2πκI​​​

III는 회전축에 대한 관성 모멘트이다.

15.4 진자

단진자

단진자의 주기 유도

길이 LLL, 질량 mmm인 단진자. 피벗에 대한 복원 돌림힘:

τ=−L(mgsin⁡θ)\tau = -L(mg\sin\theta)τ=−L(mgsinθ)

회전의 뉴턴 제2법칙 τ=Iα\tau = I\alphaτ=Iα에서 (I=mL2I = mL^2I=mL2):

−mgLsin⁡θ=mL2α  ⟹  α=−gLsin⁡θ-mgL\sin\theta = mL^2\alpha \implies \alpha = -\frac{g}{L}\sin\theta−mgLsinθ=mL2α⟹α=−Lg​sinθ

작은 각도 근사 (sin⁡θ≈θ\sin\theta \approx \thetasinθ≈θ, θ\thetaθ는 rad 단위):

α≈−gLθ\alpha \approx -\frac{g}{L}\thetaα≈−Lg​θ

이것은 a=−ω2xa = -\omega^2 xa=−ω2x 형태! 따라서 SHM이며:

ω=gL,T=2πLg\omega = \sqrt{\frac{g}{L}}, \quad \boxed{T = 2\pi\sqrt{\frac{L}{g}}}ω=Lg​​,T=2πgL​​​

단진자의 핵심 특징

T=2πLgT = 2\pi\sqrt{\frac{L}{g}}T=2πgL​​

  • 주기는 줄의 길이 LLL 에만 의존
  • 질량 mmm에 무관. 무거운 추나 가벼운 추나 같은 주기!
  • 진폭에 무관 (작은 각도 범위에서)
  • ggg를 정밀하게 측정하는 데 사용 가능: g=4π2L/T2g = 4\pi^2 L / T^2g=4π2L/T2

15.6 감쇠 단순조화운동

감쇠력

현실의 진동은 마찰이나 공기 저항 때문에 점차 줄어든다. 이를 감쇠진동(damped oscillation) 이라 한다.

감쇠력이 속도에 비례한다고 가정하면:

Fd=−bvF_d = -bvFd​=−bv

여기서 bbb는 감쇠 상수(damping constant) 이다.

감쇠진동의 운동 방정식

뉴턴 제2법칙: −kx−bv=ma-kx - bv = ma−kx−bv=ma

md2xdt2+bdxdt+kx=0m\frac{d^2x}{dt^2} + b\frac{dx}{dt} + kx = 0mdt2d2x​+bdtdx​+kx=0

이 미분방정식의 해 (b<2kmb < 2\sqrt{km}b<2km​인 약감쇠 의 경우):

x(t)=xme−bt/2mcos⁡(ω′t+ϕ)\boxed{x(t) = x_m e^{-bt/2m}\cos(\omega' t + \phi)}x(t)=xm​e−bt/2mcos(ω′t+ϕ)​

감쇠진동의 각진동수와 에너지

감쇠 진동의 각진동수:

ω′=km−b24m2\omega' = \sqrt{\frac{k}{m} - \frac{b^2}{4m^2}}ω′=mk​−4m2b2​​

  • b=0b = 0b=0이면 ω′=ω0=k/m\omega' = \omega_0 = \sqrt{k/m}ω′=ω0​=k/m​ (비감쇠)
  • bbb가 커지면 ω′\omega'ω′이 감소 (진동이 느려짐)
  • b=2kmb = 2\sqrt{km}b=2km​이면 임계 감쇠(critical damping). 진동 없이 평형으로 복귀

감쇠가 작을 때 (b≪kmb \ll \sqrt{km}b≪km​) 역학적 에너지:

E(t)≈12kxm2e−bt/m\boxed{E(t) \approx \frac{1}{2}kx_m^2 e^{-bt/m}}E(t)≈21​kxm2​e−bt/m​

에너지가 지수적으로 감소한다.

여기서 ωd\omega_dωd​는 구동 각진동수(driving angular frequency) 이다.

충분한 시간이 지나면 계는 구동 진동수 로 진동한다 (고유 진동수가 아니라!):

x(t)=Acos⁡(ωdt+ϕ′)x(t) = A\cos(\omega_d t + \phi')x(t)=Acos(ωd​t+ϕ′)

공명

진폭 AAA는 ωd\omega_dωd​에 의존한다. ωd\omega_dωd​가 계의 고유 진동수 ω0=k/m\omega_0 = \sqrt{k/m}ω0​=k/m​에 가까워지면 진폭이 급격히 증가한다.

ωd≈ω0⇒진폭 최대!\omega_d \approx \omega_0 \quad \Rightarrow \quad \text{진폭 최대!}ωd​≈ω0​⇒진폭 최대!

이것이 공명(resonance) 이다.

감쇠가 작을수록:

  • 공명 peak가 더 높고 날카로워진다
  • 공명 진동수에서의 진폭이 매우 커질 수 있다

공명의 실생활 예시

  • 다리의 공명 : 1940년 타코마 내로우즈 다리(Tacoma Narrows Bridge)가 바람에 의한 공명으로 붕괴
  • 건물의 내진 설계 : 지진파의 진동수가 건물의 고유 진동수와 일치하지 않도록 설계. 1985년 멕시코시티 지진에서 중층 건물이 공명으로 집중 붕괴
  • 악기 : 현의 고유 진동수에서 공명하여 소리 증폭
  • MRI : 자기장에서 수소 원자핵의 공명 진동을 이용
  • 전자레인지 : 물 분자의 고유 진동수(~2.45 GHz)에 맞춘 마이크로파
