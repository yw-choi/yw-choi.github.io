왜 벡터가 필요한가?

자동차 내비게이션이 "서울역에서 37 km 이동하세요"라고만 안내한다면?

방향 없이 거리만으로는 목적지에 도달할 수 없다.

물리에서도 마찬가지다:

  • 변위(displacement): 어디로 얼마나 이동했는가
  • 속도(velocity): 어느 방향으로 얼마나 빠른가
  • 힘(force): 어느 방향으로 얼마나 세게 미는가

이 양들은 모두 크기 와 방향 을 동시에 가진다 → 벡터

방향이 있는 물리량

속도와 변위처럼 방향이 중요한 물리량은 크기만으로는 운동을 결정할 수 없다.

3.1 벡터와 그 성분

스칼라 vs 벡터

스칼라 (scalar) 벡터 (vector)
정의 크기만 있는 양 크기 + 방향

연산 보통의 대수 벡터 대수 (이 장에서 배움)

벡터의 크기(magnitude)는 항상 ≥0\geq 0≥0이며, ∣a⃗∣|\vec{a}|∣a∣ 또는 aaa로 쓴다.

변위 벡터

변위(displacement) 는 가장 직관적인 벡터다.

  • 거리(distance): 실제로 이동한 경로의 총 길이 (스칼라)
  • 변위(displacement): 출발점에서 도착점으로의 직선 화살표 (벡터)

같은 경로를 걸어도, 변위는 시작점과 끝점만으로 결정된다.

벡터 덧셈: 머리-꼬리 방법

두 변위 a⃗\vec{a}a와 b⃗\vec{b}b를 연속으로 수행하면?

머리-꼬리(head-to-tail) 방법:

  1. a⃗\vec{a}a를 그린다
  2. a⃗\vec{a}a의 머리(끝점)에 b⃗\vec{b}b의 꼬리(시작점)를 붙인다
  3. a⃗\vec{a}a의 꼬리에서 b⃗\vec{b}b의 머리까지 → 합 벡터 s⃗=a⃗+b⃗\vec{s} = \vec{a} + \vec{b}s=a+b

벡터 덧셈의 법칙

교환법칙 (commutative law):

a⃗+b⃗=b⃗+a⃗\vec{a} + \vec{b} = \vec{b} + \vec{a}a+b=b+a

순서를 바꿔도 결과는 같다. 평행사변형 방법으로 확인할 수 있다.

결합법칙 (associative law):

(a⃗+b⃗)+c⃗=a⃗+(b⃗+c⃗)(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})(a+b)+c=a+(b+c)

세 벡터를 더할 때, 어떤 두 개를 먼저 더해도 결과가 같다.

벡터 뺄셈

벡터 뺄셈 d⃗=a⃗−b⃗\vec{d} = \vec{a} - \vec{b}d=a−b는 음의 벡터 를 더하는 것이다:

d⃗=a⃗−b⃗=a⃗+(−b⃗)\vec{d} = \vec{a} - \vec{b} = \vec{a} + (-\vec{b})d=a−b=a+(−b)

−b⃗-\vec{b}−b는 b⃗\vec{b}b와 크기가 같고 방향이 반대 인 벡터다.

벡터의 성분 분해

벡터를 직교 좌표축을 따라 분해하면 계산이 편리하다.

벡터 a⃗\vec{a}a가 xxx축과 각도 θ\thetaθ를 이루면:

ax=acos⁡θ,ay=asin⁡θa_x = a\cos\theta, \quad a_y = a\sin\thetaax​=acosθ,ay​=asinθ

벡터를 성분으로 나누기

한 벡터를 서로 수직인 성분으로 분해하면 2차원 문제를 두 개의 1차원 문제처럼 다룰 수 있다.

성분에서 벡터로 (역변환)

성분 axa_xax​, aya_yay​를 알면 크기와 방향을 구할 수 있다:

a=ax2+ay2a = \sqrt{a_x^2 + a_y^2}a=ax2​+ay2​​

tan⁡θ=ayax\tan\theta = \frac{a_y}{a_x}tanθ=ax​ay​​

θ=tan⁡−1ayax\theta = \tan^{-1}\frac{a_y}{a_x}θ=tan−1ax​ay​​

주의: tan⁡−1\tan^{-1}tan−1은 두 개의 해를 줄 수 있다. 벡터가 어느 사분면에 있는지 반드시 확인해야 한다.

서울역에서 수원역까지 직선거리 약 34 km. 방향은 남쪽에서 서쪽으로 15°15°15° (남남서).

3.2 단위벡터

단위벡터란?

단위벡터(unit vector) 는 크기가 1이고 특정 방향을 가리키는 벡터다.

직교 좌표계의 단위벡터:

  • i^\hat{i}i^: 양의 xxx 방향, ∣i^∣=1|\hat{i}| = 1∣i^∣=1
  • j^\hat{j}j^​: 양의 yyy 방향, ∣j^∣=1|\hat{j}| = 1∣j^​∣=1
  • k^\hat{k}k^: 양의 zzz 방향, ∣k^∣=1|\hat{k}| = 1∣k^∣=1

단위벡터를 이용한 벡터 표현

임의의 벡터 a⃗\vec{a}a를 단위벡터로 표현:

a⃗=axi^+ayj^+azk^\vec{a} = a_x\hat{i} + a_y\hat{j} + a_z\hat{k}a=ax​i^+ay​j^​+az​k^

예: a⃗=3i^−2j^+5k^\vec{a} = 3\hat{i} - 2\hat{j} + 5\hat{k}a=3i^−2j^​+5k^이면

  • ax=3a_x = 3ax​=3, ay=−2a_y = -2ay​=−2, az=5a_z = 5az​=5
  • a=32+(−2)2+52=38≈6.16a = \sqrt{3^2 + (-2)^2 + 5^2} = \sqrt{38} \approx 6.16a=32+(−2)2+52​=38​≈6.16

성분별 벡터 덧셈

a⃗=axi^+ayj^+azk^\vec{a} = a_x\hat{i} + a_y\hat{j} + a_z\hat{k}a=ax​i^+ay​j^​+az​k^, b⃗=bxi^+byj^+bzk^\vec{b} = b_x\hat{i} + b_y\hat{j} + b_z\hat{k}b=bx​i^+by​j^​+bz​k^일 때:

r⃗=a⃗+b⃗=(ax+bx)i^+(ay+by)j^+(az+bz)k^\vec{r} = \vec{a} + \vec{b} = (a_x + b_x)\hat{i} + (a_y + b_y)\hat{j} + (a_z + b_z)\hat{k}r=a+b=(ax​+bx​)i^+(ay​+by​)j^​+(az​+bz​)k^

각 성분끼리 더하면 된다! 기하학적 방법보다 훨씬 간단하다.

뺄셈도 마찬가지:

d⃗=a⃗−b⃗=(ax−bx)i^+(ay−by)j^+(az−bz)k^\vec{d} = \vec{a} - \vec{b} = (a_x - b_x)\hat{i} + (a_y - b_y)\hat{j} + (a_z - b_z)\hat{k}d=a−b=(ax​−bx​)i^+(ay​−by​)j^​+(az​−bz​)k^

예제: 세 벡터의 성분별 덧셈

a⃗=4i^−3j^\vec{a} = 4\hat{i} - 3\hat{j}a=4i^−3j^​, b⃗=−2i^+5j^\vec{b} = -2\hat{i} + 5\hat{j}b=−2i^+5j^​, c⃗=i^+2j^\vec{c} = \hat{i} + 2\hat{j}c=i^+2j^​일 때 r⃗=a⃗+b⃗+c⃗\vec{r} = \vec{a} + \vec{b} + \vec{c}r=a+b+c를 구하라.

xxx 성분: rx=4+(−2)+1=3r_x = 4 + (-2) + 1 = 3rx​=4+(−2)+1=3

yyy 성분: ry=(−3)+5+2=4r_y = (-3) + 5 + 2 = 4ry​=(−3)+5+2=4

r⃗=3i^+4j^\vec{r} = 3\hat{i} + 4\hat{j}r=3i^+4j^​

크기: r=32+42=5r = \sqrt{3^2 + 4^2} = 5r=32+42​=5

방향: θ=tan⁡−1(4/3)=53.1°\theta = \tan^{-1}(4/3) = 53.1°θ=tan−1(4/3)=53.1°

좌표계 선택의 자유

좌표축의 방향은 자유롭게 선택할 수 있다.

  • 물리 법칙은 좌표계 선택에 의존하지 않는다
  • 문제에 맞게 편리한 방향 을 선택하면 계산이 간단해진다

예: 빗면 문제 → 빗면을 따라 xxx축, 빗면에 수직으로 yyy축

중요한 것은 한 번 선택한 좌표계를 문제 풀이 내내 일관되게 사용하는 것이다.

3.3 벡터의 곱셈

물리에서 벡터의 곱셈은 두 가지 가 있다:

스칼라곱 (내적) 벡터곱 (외적)
기호 a⃗⋅b⃗\vec{a} \cdot \vec{b}a⋅b a⃗×b⃗\vec{a} \times \vec{b}a×b
결과 스칼라 벡터
물리 응용 일(work) 토크(torque)

각각의 정의와 계산법을 배워보자.

내적과 외적의 물리적 차이

내적은 한 방향으로의 투영을, 외적은 회전 효과와 면에 수직인 방향을 드러낸다.

스칼라곱 (내적, dot product)

두 벡터 a⃗\vec{a}a와 b⃗\vec{b}b 사이의 각도가 ϕ\phiϕ일 때:

a⃗⋅b⃗=abcos⁡ϕ\vec{a} \cdot \vec{b} = ab\cos\phia⋅b=abcosϕ

기하학적 의미: b⃗\vec{b}b를 a⃗\vec{a}a 방향으로 사영(projection) 한 것에 aaa를 곱한 값

내적의 부호

ϕ\phiϕ의 범위에 따라 내적의 부호가 결정된다:

  • 0≤ϕ<90°0 \leq \phi < 90°0≤ϕ<90°: cos⁡ϕ>0\cos\phi > 0cosϕ>0 → a⃗⋅b⃗>0\vec{a} \cdot \vec{b} > 0a⋅b>0
  • ϕ=90°\phi = 90°ϕ=90°: cos⁡ϕ=0\cos\phi = 0cosϕ=0 → a⃗⋅b⃗=0\vec{a} \cdot \vec{b} = 0a⋅b=0 (수직)
  • 90°<ϕ≤180°90° < \phi \leq 180°90°<ϕ≤180°: cos⁡ϕ<0\cos\phi < 0cosϕ<0 → a⃗⋅b⃗<0\vec{a} \cdot \vec{b} < 0a⋅b<0

두 벡터가 수직이면 내적이 0이다 — 매우 중요한 성질!

교환법칙 성립: a⃗⋅b⃗=b⃗⋅a⃗\vec{a} \cdot \vec{b} = \vec{b} \cdot \vec{a}a⋅b=b⋅a

내적의 성분 형태

a⃗=axi^+ayj^+azk^\vec{a} = a_x\hat{i} + a_y\hat{j} + a_z\hat{k}a=ax​i^+ay​j^​+az​k^, b⃗=bxi^+byj^+bzk^\vec{b} = b_x\hat{i} + b_y\hat{j} + b_z\hat{k}b=bx​i^+by​j^​+bz​k^일 때:

단위벡터의 내적: i^⋅i^=j^⋅j^=k^⋅k^=1\hat{i}\cdot\hat{i} = \hat{j}\cdot\hat{j} = \hat{k}\cdot\hat{k} = 1i^⋅i^=j^​⋅j^​=k^⋅k^=1, i^⋅j^=j^⋅k^=k^⋅i^=0\hat{i}\cdot\hat{j} = \hat{j}\cdot\hat{k} = \hat{k}\cdot\hat{i} = 0i^⋅j^​=j^​⋅k^=k^⋅i^=0

따라서:

a⃗⋅b⃗=axbx+ayby+azbz\vec{a} \cdot \vec{b} = a_x b_x + a_y b_y + a_z b_za⋅b=ax​bx​+ay​by​+az​bz​

각 성분끼리 곱해서 더하면 된다!

내적 예제

a⃗=3i^−4j^+2k^\vec{a} = 3\hat{i} - 4\hat{j} + 2\hat{k}a=3i^−4j^​+2k^, b⃗=2i^+3j^−k^\vec{b} = 2\hat{i} + 3\hat{j} - \hat{k}b=2i^+3j^​−k^일 때:

a⃗⋅b⃗=(3)(2)+(−4)(3)+(2)(−1)=6−12−2=−8\vec{a} \cdot \vec{b} = (3)(2) + (-4)(3) + (2)(-1) = 6 - 12 - 2 = -8a⋅b=(3)(2)+(−4)(3)+(2)(−1)=6−12−2=−8

두 벡터 사이의 각도:

a=9+16+4=29,b=4+9+1=14a = \sqrt{9 + 16 + 4} = \sqrt{29}, \quad b = \sqrt{4 + 9 + 1} = \sqrt{14}a=9+16+4​=29​,b=4+9+1​=14​

cos⁡ϕ=a⃗⋅b⃗ab=−829⋅14=−8406≈−0.397\cos\phi = \frac{\vec{a}\cdot\vec{b}}{ab} = \frac{-8}{\sqrt{29}\cdot\sqrt{14}} = \frac{-8}{\sqrt{406}} \approx -0.397cosϕ=aba⋅b​=29​⋅14​−8​=406​−8​≈−0.397

ϕ=cos⁡−1(−0.397)≈113.4°\phi = \cos^{-1}(-0.397) \approx 113.4°ϕ=cos−1(−0.397)≈113.4°

벡터곱 (외적, cross product)

두 벡터 a⃗\vec{a}a와 b⃗\vec{b}b의 외적 c⃗=a⃗×b⃗\vec{c} = \vec{a} \times \vec{b}c=a×b:

크기:

∣a⃗×b⃗∣=absin⁡ϕ|\vec{a} \times \vec{b}| = ab\sin\phi∣a×b∣=absinϕ

방향: 오른손 법칙으로 결정 — a⃗\vec{a}a와 b⃗\vec{b}b가 이루는 평면에 수직

외적의 성질

반교환: a⃗×b⃗=−(b⃗×a⃗)\vec{a} \times \vec{b} = -(\vec{b} \times \vec{a})a×b=−(b×a) (순서를 바꾸면 방향이 반대!)

평행하면 외적이 0: a⃗×b⃗=0⃗\vec{a} \times \vec{b} = \vec{0}a×b=0 (ϕ=0°\phi = 0°ϕ=0° 또는 180°180°180°이면 sin⁡ϕ=0\sin\phi = 0sinϕ=0)

수직이면 외적이 최대: ∣a⃗×b⃗∣=ab|\vec{a} \times \vec{b}| = ab∣a×b∣=ab (ϕ=90°\phi = 90°ϕ=90°이면 sin⁡ϕ=1\sin\phi = 1sinϕ=1)

단위벡터의 외적:

i^×j^=k^,j^×k^=i^,k^×i^=j^\hat{i} \times \hat{j} = \hat{k}, \quad \hat{j} \times \hat{k} = \hat{i}, \quad \hat{k} \times \hat{i} = \hat{j}i^×j^​=k^,j^​×k^=i^,k^×i^=j^​

j^×i^=−k^,k^×j^=−i^,i^×k^=−j^\hat{j} \times \hat{i} = -\hat{k}, \quad \hat{k} \times \hat{j} = -\hat{i}, \quad \hat{i} \times \hat{k} = -\hat{j}j^​×i^=−k^,k^×j^​=−i^,i^×k^=−j^​

외적의 성분 형태

a⃗×b⃗\vec{a} \times \vec{b}a×b를 성분으로 전개하면:

a⃗×b⃗=(aybz−azby)i^+(azbx−axbz)j^+(axby−aybx)k^\vec{a} \times \vec{b} = (a_y b_z - a_z b_y)\hat{i} + (a_z b_x - a_x b_z)\hat{j} + (a_x b_y - a_y b_x)\hat{k}a×b=(ay​bz​−az​by​)i^+(az​bx​−ax​bz​)j^​+(ax​by​−ay​bx​)k^

행렬식으로 쓰면 기억하기 쉽다:

a⃗×b⃗=∣i^j^k^axayazbxbybz∣\vec{a} \times \vec{b} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix}a×b=​i^ax​bx​​j^​ay​by​​k^az​bz​​​

외적 예제
