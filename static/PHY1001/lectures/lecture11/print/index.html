11.1 구름 운동

구름 = 병진 + 회전

자전거 바퀴, 볼링공, 축구공 — 일상에서 흔히 보는 운동이다.

구름 운동(rolling) 은 순수 병진(translation) 과 순수 회전(rotation) 의 결합이다.

굴림은 병진과 회전의 결합

굴러가는 물체는 질량중심의 병진 운동과 자체 회전 운동을 동시에 가진다.

구름 조건

미끄러짐 없는 구름 운동의 핵심 조건:

vcom=ωRv_\text{com} = \omega Rvcom​=ωR

여기서 vcomv_\text{com}vcom​은 질량 중심의 속력, ω\omegaω는 각속력, RRR은 반지름이다.

물리적 의미: 접촉점의 속도가 0이다!

  • 접촉점 (바닥): vcom−ωR=0v_\text{com} - \omega R = 0vcom​−ωR=0
  • 꼭대기: vcom+ωR=2vcomv_\text{com} + \omega R = 2v_\text{com}vcom​+ωR=2vcom​

양변을 시간 미분하면 가속도 관계도 얻는다:

acom=αRa_\text{com} = \alpha Racom​=αR

구름 운동의 운동에너지

구름 운동의 전체 운동에너지:

K=12Icomω2+12Mvcom2K = \frac{1}{2}I_\text{com}\omega^2 + \frac{1}{2}Mv_\text{com}^2K=21​Icom​ω2+21​Mvcom2​

  • 첫째 항: 회전 운동에너지 (질량 중심 둘레의 회전)
  • 둘째 항: 병진 운동에너지 (질량 중심의 이동)

vcom=ωRv_\text{com} = \omega Rvcom​=ωR을 대입하면:

K=12Icomvcom2R2+12Mvcom2=12(IcomR2+M)vcom2K = \frac{1}{2}I_\text{com}\frac{v_\text{com}^2}{R^2} + \frac{1}{2}Mv_\text{com}^2 = \frac{1}{2}\left(\frac{I_\text{com}}{R^2} + M\right)v_\text{com}^2K=21​Icom​R2vcom2​​+21​Mvcom2​=21​(R2Icom​​+M)vcom2​

요요(Yo-yo)

요요는 빗면 위의 구름 운동의 특수한 경우로 이해할 수 있다.

요요에 작용하는 힘: 중력 MgMgMg (아래)와 실의 장력 TTT (위)

핵심: 실이 감긴 축의 반지름 R0R_0R0​ 이 구름 조건에서 RRR 역할을 한다.

11.3 돌림힘 벡터

벡터곱 복습

돌림힘을 벡터로 정의하려면 벡터곱(cross product) 이 필요하다.

c⃗=a⃗×b⃗\vec{c} = \vec{a} \times \vec{b}c=a×b

  • 크기: ∣c⃗∣=absin⁡ϕ|\vec{c}| = ab\sin\phi∣c∣=absinϕ (ϕ\phiϕ는 a⃗\vec{a}a와 b⃗\vec{b}b 사이의 각)
  • 방향: 오른손 법칙 — a⃗\vec{a}a에서 b⃗\vec{b}b로 감아쥐면 엄지 방향

성질:

  • a⃗×b⃗=−b⃗×a⃗\vec{a} \times \vec{b} = -\vec{b} \times \vec{a}a×b=−b×a (교환 불가!)
  • a⃗×a⃗=0⃗\vec{a} \times \vec{a} = \vec{0}a×a=0

돌림힘의 벡터 정의

원점 O에서 힘의 작용점까지의 위치 벡터가 r⃗\vec{r}r이고, 힘이 F⃗\vec{F}F일 때:

τ⃗=r⃗×F⃗\vec{\tau} = \vec{r} \times \vec{F}τ=r×F

크기: ∣τ⃗∣=rFsin⁡ϕ|\vec{\tau}| = rF\sin\phi∣τ∣=rFsinϕ

돌림힘의 의미

τ=rFsin⁡ϕ=r⊥F=rF⊥\tau = rF\sin\phi = r_\perp F = rF_\perpτ=rFsinϕ=r⊥​F=rF⊥​

  • r⊥=rsin⁡ϕr_\perp = r\sin\phir⊥​=rsinϕ: 모멘트 팔(moment arm) — 회전축에서 힘의 작용선까지의 수직 거리
  • F⊥=Fsin⁡ϕF_\perp = F\sin\phiF⊥​=Fsinϕ: 회전을 일으키는 힘의 접선 성분

돌림힘은 회전 운동의 원인 이다 — 힘이 병진 운동의 원인인 것처럼.

11.4 각운동량

입자의 각운동량

원점 O에 대한 입자의 각운동량(angular momentum) :

ℓ⃗=r⃗×p⃗=r⃗×mv⃗\vec{\ell} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}ℓ=r×p​=r×mv

각운동량의 크기

ℓ=rmvsin⁡ϕ=r⊥mv=rmv⊥\ell = rmv\sin\phi = r_\perp mv = rmv_\perpℓ=rmvsinϕ=r⊥​mv=rmv⊥​

  • ϕ\phiϕ는 r⃗\vec{r}r과 v⃗\vec{v}v 사이의 각도
  • r⊥=rsin⁡ϕr_\perp = r\sin\phir⊥​=rsinϕ: 직선 운동 경로까지의 수직 거리

단위: kg⋅m2/s\text{kg}\cdot\text{m}^2/\text{s}kg⋅m2/s

원운동하는 입자의 경우 (ϕ=90°\phi = 90°ϕ=90°):

ℓ=rmv=mr2ω\ell = rmv = mr^2\omegaℓ=rmv=mr2ω

회전의 뉴턴 제2법칙

병진: F⃗net=dp⃗dt\vec{F}_\text{net} = \frac{d\vec{p}}{dt}Fnet​=dtdp​​

이와 유사하게, 회전 에서:

τ⃗net=dℓ⃗dt\vec{\tau}_\text{net} = \frac{d\vec{\ell}}{dt}τnet​=dtdℓ​

입자에 작용하는 알짜 돌림힘 = 각운동량의 시간 변화율

증명: ℓ⃗=r⃗×p⃗\vec{\ell} = \vec{r} \times \vec{p}ℓ=r×p​를 시간 미분하면

dℓ⃗dt=dr⃗dt×p⃗+r⃗×dp⃗dt=v⃗×mv⃗+r⃗×F⃗=0⃗+τ⃗=τ⃗\frac{d\vec{\ell}}{dt} = \frac{d\vec{r}}{dt} \times \vec{p} + \vec{r} \times \frac{d\vec{p}}{dt} = \vec{v} \times m\vec{v} + \vec{r} \times \vec{F} = \vec{0} + \vec{\tau} = \vec{\tau}dtdℓ​=dtdr​×p​+r×dtdp​​=v×mv+r×F=0+τ=τ

강체의 각운동량

고정축을 중심으로 회전하는 강체의 각운동량:

L=∑iℓi=∑imiri2ω=IωL = \sum_i \ell_i = \sum_i m_i r_i^2 \omega = I\omegaL=i∑​ℓi​=i∑​mi​ri2​ω=Iω

L=Iω\boxed{L = I\omega}L=Iω​

이것은 10장에서 배운 τnet=Iα\tau_\text{net} = I\alphaτnet​=Iα와 같다!

11.5 각운동량 보존

보존 법칙

만약 계에 작용하는 알짜 외부 돌림힘이 0 이면:

τnet, ext=dLdt=0\tau_\text{net, ext} = \frac{dL}{dt} = 0τnet, ext​=dtdL​=0

따라서:

L=Iω=일정\boxed{L = I\omega = \text{일정}}L=Iω=일정​

Iiωi=IfωfI_i\omega_i = I_f\omega_fIi​ωi​=If​ωf​

이것은 선운동량 보존 (F⃗net=0⇒p⃗=const\vec{F}_\text{net} = 0 \Rightarrow \vec{p} = \text{const}Fnet​=0⇒p​=const)의 회전 버전이다.

질량 분포가 바뀌면 각속도가 바뀐다

외부 토크가 작으면 관성모멘트와 각속도가 서로 보상되어 각운동량을 보존한다.

피겨 스케이팅: 각운동량 보존의 대표적 예

김연아 선수의 스핀을 떠올려 보자:

  • 팔을 벌린 상태: III 크고 → ω\omegaω 작음 (느린 회전)
  • 팔을 모은 상태: III 작고 → ω\omegaω 큼 (빠른 회전)

외부 돌림힘이 거의 없으므로 L=IωL = I\omegaL=Iω가 보존된다!

다이빙과 체조

다이빙 선수가 공중에서 몸을 웅크리면:

  • 관성 모멘트 III가 감소
  • 각속력 ω\omegaω가 증가 → 빠르게 회전
  • 입수 전에 몸을 펴면 → III 증가, ω\omegaω 감소 → 안정적 입수

핵심: 외부 돌림힘 없이도 자신의 몸 형태를 바꿔서 회전 속도를 조절할 수 있다.

같은 원리가 우주 공간에서 위성의 자세 제어에도 사용된다 (반작용 바퀴, reaction wheel).

11.6 세차운동

자이로스코프의 세차운동

빠르게 회전하는 팽이가 쓰러지지 않고 빙글빙글 도는 현상 — 세차운동(precession) 이다.

회전하지 않는 팽이는 즉시 쓰러진다. 빠르게 회전하면 왜 쓰러지지 않을까?

자이로스코프의 느린 방향 변화

빠르게 자전하는 물체는 중력 토크에 의해 넘어지기보다 각운동량 방향이 천천히 돈다.

1단계: 자전하는 바퀴의 각운동량

바퀴가 각속도 ω\omegaω로 자전하고 있으면:

L⃗=Iω⃗\vec{L} = I\vec{\omega}L=Iω

L⃗\vec{L}L은 회전축 방향(수평)을 가리킨다. 크기는 L=IωL = I\omegaL=Iω.

지지점에서 질량 중심까지의 거리를 rrr이라 하자.

2단계: 중력에 의한 돌림힘

지지점을 기준으로 한 중력의 돌림힘:

τ⃗=r⃗×Mg⃗\vec{\tau} = \vec{r} \times M\vec{g}τ=r×Mg​

  • r⃗\vec{r}r: 수평 방향 (지지점 → 질량 중심)
  • Mg⃗M\vec{g}Mg​: 아래 방향

오른손 법칙 적용:

  • 크기: τ=Mgr\tau = Mgrτ=Mgr
  • 방향: 수평면 위에서 L⃗\vec{L}L에 수직

핵심: τ⃗⊥L⃗\vec{\tau} \perp \vec{L}τ⊥L — 돌림힘과 각운동량이 서로 수직이다!

3단계: 각운동량의 방향 변화

뉴턴 제2법칙의 회전 버전:

dL⃗=τ⃗ dtd\vec{L} = \vec{\tau}\,dtdL=τdt

τ⃗\vec{\tau}τ가 L⃗\vec{L}L에 수직이므로, dL⃗d\vec{L}dL도 L⃗\vec{L}L에 수직이다.

벡터에 수직인 미소 변화를 더하면 → 크기는 변하지 않고 방향만 변한다

이것은 원운동에서 구심 가속도가 속력은 유지하면서 방향만 바꾸는 것과 같은 원리!

결과: L⃗\vec{L}L의 끝이 수평면 위에서 원을 그리며 회전한다 → 이것이 세차운동이다.

4단계: 세차 각속도 유도

시간 dtdtdt 동안 L⃗\vec{L}L이 수평면에서 dϕd\phidϕ만큼 회전했다고 하자.

L⃗\vec{L}L의 끝이 그리는 원호의 길이 (작은 각도 근사):

∣dL⃗∣=L dϕ|d\vec{L}| = L\,d\phi∣dL∣=Ldϕ

한편 ∣dL⃗∣=τ dt=Mgr dt|d\vec{L}| = \tau\,dt = Mgr\,dt∣dL∣=τdt=Mgrdt이므로:

L dϕ=Mgr dtL\,d\phi = Mgr\,dtLdϕ=Mgrdt

세차 각속도 Ω=dϕdt\Omega = \frac{d\phi}{dt}Ω=dtdϕ​를 구하면:

Ω=MgrL=MgrIω\boxed{\Omega = \frac{Mgr}{L} = \frac{Mgr}{I\omega}}Ω=LMgr​=IωMgr​​

세차운동의 의미

Ω=MgrIω\Omega = \frac{Mgr}{I\omega}Ω=IωMgr​

  • ω\omegaω 증가 → Ω\OmegaΩ 감소: 빠르게 돌수록 세차가 느려진다
  • ω\omegaω 감소 → Ω\OmegaΩ 증가: 느려지면 세차가 빨라지다가 결국 쓰러진다
  • MMM 또는 rrr 증가 → 돌림힘 증가 → 세차가 빨라진다

팽이: 마찰로 ω\omegaω가 줄면 Ω\OmegaΩ가 커지다가 결국 쓰러진다

자전거 바퀴: 빠르게 돌 때 세차 효과로 안정적 — 넘어지기 어렵다

주의: 위 공식은 ω≫Ω\omega \gg \Omegaω≫Ω (자전이 세차보다 훨씬 빠를 때)의 근사이다. 이 조건이 깨지면 장동(nutation) 등 더 복잡한 운동이 나타난다.
