7장: 운동에너지와 일

Kinetic Energy and Work

이번 장에서 배울 내용

  • 운동에너지(kinetic energy): 운동 상태와 관련된 에너지
  • 일(work): 힘을 통한 에너지 전달
  • 일-운동에너지 정리: 알짜 일 = 운동에너지 변화
  • 중력 이 하는 일과 용수철 힘 이 하는 일
  • 변하는 힘 이 하는 일 — 적분으로 계산
  • 일률(power): 에너지 전달의 시간 비율

에너지란 무엇인가?

에너지(energy) 는 물체의 상태와 관련된 스칼라 양이다.

  • 에너지는 한 형태에서 다른 형태로 변환 될 수 있다
  • 한 물체에서 다른 물체로 전달 될 수 있다
  • 그러나 전체 에너지의 총량은 항상 보존 된다

에너지를 은행 계좌의 돈에 비유할 수 있다. 계좌 간 이체(전달)는 가능하지만, 총액은 변하지 않는다.

이 장에서는 운동에너지(kinetic energy) 한 종류와, 에너지를 전달하는 방법인 일(work) 하나만 다룬다.

7.1 운동에너지

운동에너지(kinetic energy) KKK는 물체의 운동 상태 와 관련된 에너지다.

질량 mmm, 속력 vvv인 물체의 운동에너지:

K=12mv2K = \frac{1}{2}mv^2K=21​mv2

  • KKK는 스칼라 이다 (방향 없음)
  • 항상 K≥0K \geq 0K≥0 (음수가 될 수 없다)
  • 물체가 정지하면 K=0K = 0K=0
  • 속력이 빠를수록 운동에너지가 크다

운동에너지의 단위

1 J=1 kg⋅m2/s21 \text{ J} = 1 \text{ kg} \cdot \text{m}^2/\text{s}^21 J=1 kg⋅m2/s2

에너지의 SI 단위는 줄(joule, J) 이다.

예시: 질량 3.0 kg인 오리가 2.0 m/s로 날아간다면

K=12(3.0)(2.0)2=6.0 JK = \frac{1}{2}(3.0)(2.0)^2 = 6.0 \text{ J}K=21​(3.0)(2.0)2=6.0 J

7.2 일과 운동에너지

일(work)이란?

일(work) WWW는 힘을 통해 물체에 에너지를 전달(또는 물체에서 에너지를 빼앗)하는 것이다.

  • 물체에 에너지가 전달되면 → 양의 일 (W>0W > 0W>0)
  • 물체에서 에너지가 빠져나가면 → 음의 일 (W<0W < 0W<0)

일상어에서 "일한다"는 것과 물리의 "일"은 다르다. 벽을 아무리 세게 밀어도, 벽이 움직이지 않으면 물리적으로 일은 0이다.

일정한 힘이 하는 일

일정한 힘 F⃗\vec{F}F가 변위 d⃗\vec{d}d만큼 물체를 이동시킬 때, 힘이 한 일:

W=Fdcos⁡ϕ=F⃗⋅d⃗W = Fd\cos\phi = \vec{F} \cdot \vec{d}W=Fdcosϕ=F⋅d

여기서 ϕ\phiϕ는 F⃗\vec{F}F와 d⃗\vec{d}d 사이의 각도이다.

일의 부호

  • ϕ<90°\phi < 90°ϕ<90°: cos⁡ϕ>0\cos\phi > 0cosϕ>0 → 양의 일 (힘이 운동 방향과 같은 쪽)
  • ϕ=90°\phi = 90°ϕ=90°: cos⁡ϕ=0\cos\phi = 0cosϕ=0 → 일 = 0 (힘이 운동에 수직)
  • ϕ>90°\phi > 90°ϕ>90°: cos⁡ϕ<0\cos\phi < 0cosϕ<0 → 음의 일 (힘이 운동 반대쪽)

핵심: 변위 방향의 힘 성분 만이 일을 한다.

수직 성분 Fsin⁡ϕF\sin\phiFsinϕ는 일을 하지 않는다!

알짜 일 (Net Work)

여러 힘이 작용할 때, 알짜 일 은:

  1. 각 힘이 한 일을 더한다: Wnet=W1+W2+⋯W_\text{net} = W_1 + W_2 + \cdotsWnet​=W1​+W2​+⋯
  2. 또는 알짜힘 F⃗net\vec{F}_\text{net}Fnet​으로 직접 계산: Wnet=Fnetdcos⁡ϕW_\text{net} = F_\text{net} d \cos\phiWnet​=Fnet​dcosϕ

일-운동에너지 정리

입자에 한 알짜 일 은 운동에너지의 변화량 과 같다:

ΔK=Kf−Ki=W\Delta K = K_f - K_i = WΔK=Kf​−Ki​=W

즉,

Kf=Ki+WK_f = K_i + WKf​=Ki​+W

  • 알짜 일이 양수 → 운동에너지 증가 (가속)
  • 알짜 일이 음수 → 운동에너지 감소 (감속)
  • 알짜 일이 0 → 운동에너지 변화 없음

일-운동에너지 정리 유도

질량 mmm인 입자에 알짜힘 FxF_xFx​가 작용, 변위 ddd:

Fx=maxF_x = ma_xFx​=max​

등가속도 운동: v2=v02+2axdv^2 = v_0^2 + 2a_x dv2=v02​+2ax​d이므로

ax=v2−v022da_x = \frac{v^2 - v_0^2}{2d}ax​=2dv2−v02​​

따라서

Fxd=m⋅v2−v022d⋅d=12mv2−12mv02F_x d = m \cdot \frac{v^2 - v_0^2}{2d} \cdot d = \frac{1}{2}mv^2 - \frac{1}{2}mv_0^2Fx​d=m⋅2dv2−v02​​⋅d=21​mv2−21​mv02​

W=Kf−Ki=ΔK✓W = K_f - K_i = \Delta K \quad \checkmarkW=Kf​−Ki​=ΔK✓

7.3 중력이 하는 일

올라갈 때 vs. 내려올 때

중력 F⃗g=−mgj^\vec{F}_g = -mg\hat{j}Fg​=−mgj^​가 변위 d⃗\vec{d}d동안 한 일:

Wg=mgdcos⁡ϕW_g = mgd\cos\phiWg​=mgdcosϕ

중력이 하는 일: 정리

올라갈 때 (ϕ=180°\phi = 180°ϕ=180°):

Wg=mgdcos⁡180°=−mgdW_g = mgd\cos 180° = -mgdWg​=mgdcos180°=−mgd

중력은 음의 일 → 운동에너지를 빼앗는다 (감속)

내려올 때 (ϕ=0°\phi = 0°ϕ=0°):

Wg=mgdcos⁡0°=+mgdW_g = mgd\cos 0° = +mgdWg​=mgdcos0°=+mgd

중력은 양의 일 → 운동에너지를 전달한다 (가속)

물체를 들어올릴 때

외력 F⃗a\vec{F}_aFa​로 물체를 들어올리면, 일-운동에너지 정리에서:

ΔK=Kf−Ki=Wa+Wg\Delta K = K_f - K_i = W_a + W_gΔK=Kf​−Ki​=Wa​+Wg​

물체가 처음과 나중에 모두 정지해 있다면 (Kf=KiK_f = K_iKf​=Ki​):

Wa+Wg=0⇒Wa=−WgW_a + W_g = 0 \quad \Rightarrow \quad W_a = -W_gWa​+Wg​=0⇒Wa​=−Wg​

들어올리는 힘이 한 일 = 중력이 한 일의 음수

Wa=−mgdcos⁡ϕW_a = -mgd\cos\phiWa​=−mgdcosϕ

위로 올릴 때: Wa=mgdW_a = mgdWa​=mgd, 아래로 내릴 때: Wa=−mgdW_a = -mgdWa​=−mgd

7.4 용수철 힘이 하는 일

용수철 힘: 훅 법칙 (Hooke's Law)

용수철의 자연 길이에서 변위 d⃗\vec{d}d만큼 늘리거나 줄이면, 복원력:

F⃗s=−kd⃗\vec{F}_s = -k\vec{d}Fs​=−kd

xxx축을 따라:

Fx=−kxF_x = -kxFx​=−kx

  • kkk: 용수철 상수(spring constant) [N/m] — 클수록 뻣뻣한 용수철
  • 부호: 항상 평형 위치를 향한다 (복원력)

용수철이 한 일

용수철 힘은 변하는 힘 이므로, W=Fdcos⁡ϕW = Fd\cos\phiW=Fdcosϕ를 바로 쓸 수 없다.

적분으로 계산:

Ws=∫xixf(−kx) dx=−12k[x2]xixfW_s = \int_{x_i}^{x_f} (-kx)\, dx = -\frac{1}{2}k\left[x^2\right]_{x_i}^{x_f}Ws​=∫xi​xf​​(−kx)dx=−21​k[x2]xi​xf​​

Ws=12kxi2−12kxf2W_s = \frac{1}{2}kx_i^2 - \frac{1}{2}kx_f^2Ws​=21​kxi2​−21​kxf2​

  • ∣xf∣<∣xi∣|x_f| < |x_i|∣xf​∣<∣xi​∣ (평형에 가까워짐) → Ws>0W_s > 0Ws​>0 (양의 일)
  • ∣xf∣>∣xi∣|x_f| > |x_i|∣xf​∣>∣xi​∣ (평형에서 멀어짐) → Ws<0W_s < 0Ws​<0 (음의 일)

외력이 용수철에 한 일

외력으로 블록을 용수철에 연결된 상태로 이동시킬 때:

ΔK=Wa+Ws\Delta K = W_a + W_sΔK=Wa​+Ws​

처음과 나중에 블록이 정지해 있다면:

Wa=−Ws=12kxf2−12kxi2W_a = -W_s = \frac{1}{2}kx_f^2 - \frac{1}{2}kx_i^2Wa​=−Ws​=21​kxf2​−21​kxi2​

7.5 변하는 힘이 하는 일

1차원에서 변하는 힘

힘 F(x)F(x)F(x)가 위치에 따라 변할 때, 일은 적분 으로 구한다:

W=∫xixfF(x) dxW = \int_{x_i}^{x_f} F(x)\, dxW=∫xi​xf​​F(x)dx

기하학적 의미: F(x)F(x)F(x) 그래프와 xxx축 사이의 넓이 가 일이다.

3차원에서 변하는 힘

힘 F⃗=Fxi^+Fyj^+Fzk^\vec{F} = F_x\hat{i} + F_y\hat{j} + F_z\hat{k}F=Fx​i^+Fy​j^​+Fz​k^가 작용할 때:

W=∫xixfFx dx+∫yiyfFy dy+∫zizfFz dzW = \int_{x_i}^{x_f} F_x\, dx + \int_{y_i}^{y_f} F_y\, dy + \int_{z_i}^{z_f} F_z\, dzW=∫xi​xf​​Fx​dx+∫yi​yf​​Fy​dy+∫zi​zf​​Fz​dz

(단, FxF_xFx​는 xxx에만, FyF_yFy​는 yyy에만, FzF_zFz​는 zzz에만 의존한다고 가정)

변하는 힘에 대한 일-운동에너지 정리 유도

뉴턴 제2법칙: F(x)=maF(x) = maF(x)=ma

W=∫xixfF(x) dx=∫xixfma dxW = \int_{x_i}^{x_f} F(x)\, dx = \int_{x_i}^{x_f} ma\, dxW=∫xi​xf​​F(x)dx=∫xi​xf​​madx

a dx=dvdtdx=v dva\, dx = \frac{dv}{dt}dx = v\, dvadx=dtdv​dx=vdv를 이용하면:

W=m∫vivfv dv=12mvf2−12mvi2=ΔKW = m \int_{v_i}^{v_f} v\, dv = \frac{1}{2}mv_f^2 - \frac{1}{2}mv_i^2 = \Delta KW=m∫vi​vf​​vdv=21​mvf2​−21​mvi2​=ΔK

변하는 힘에서도 일-운동에너지 정리 가 성립한다!

7.6 일률

일률(power)이란?

일률(power) PPP는 힘이 일을 하는 시간당 비율 이다.

평균 일률:

Pavg=WΔtP_\text{avg} = \frac{W}{\Delta t}Pavg​=ΔtW​

순간 일률:

P=dWdtP = \frac{dW}{dt}P=dtdW​

일률의 단위

1 W(와트)=1 J/s1 \text{ W(와트)} = 1 \text{ J/s}1 W(와트)=1 J/s

  • James Watt의 이름을 딴 단위
  • 1 마력(horsepower) = 746 W

에너지 단위로도 쓰인다:

1 kW ⁣⋅ ⁣h=(103 W)(3600 s)=3.6×106 J=3.6 MJ1 \text{ kW}\!\cdot\!\text{h} = (10^3 \text{ W})(3600 \text{ s}) = 3.6 \times 10^6 \text{ J} = 3.6 \text{ MJ}1 kW⋅h=(103 W)(3600 s)=3.6×106 J=3.6 MJ

전기 요금 고지서의 kWh가 바로 이 단위!

힘과 속도로 표현한 일률

힘 F⃗\vec{F}F가 속도 v⃗\vec{v}v인 물체에 작용할 때:

P=dWdt=Fcos⁡ϕ⋅dxdt=Fvcos⁡ϕP = \frac{dW}{dt} = \frac{F\cos\phi \cdot dx}{dt} = Fv\cos\phiP=dtdW​=dtFcosϕ⋅dx​=Fvcosϕ

P=F⃗⋅v⃗P = \vec{F} \cdot \vec{v}P=F⋅v

예시: 자동차가 일정 속력 vvv로 달릴 때, 엔진이 발휘하는 힘:

F=PvF = \frac{P}{v}F=vP​

일률이 같다면, 속력이 빠를수록 힘이 작아진다.
