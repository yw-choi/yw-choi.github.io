19.1 아보가드로 수와 이상기체

기체 분자 운동론이란?

기체의 거시적 성질 (압력, 온도, 부피)을 미시적 성질 (분자의 속력, 운동에너지, 충돌)로 설명하는 이론이다.

자동차 엔진의 연소 가스, 제빵 시 발생하는 발효 가스, 잠수부의 감압병(질소 기포). 모두 기체 분자 운동론의 응용이다.

아보가드로 수

몰(mole) 은 SI 기본 단위 중 하나이다. 1몰은 탄소-12의 12 g에 들어 있는 원자 수와 같다.

아보가드로 수(Avogadro's number) :

NA=6.02×1023  mol−1N_A = 6.02 \times 10^{23} \;\text{mol}^{-1}NA​=6.02×1023mol−1

시료의 몰 수 nnn과 분자 수 NNN의 관계:

n=NNA=MsamM=MsammNAn = \frac{N}{N_A} = \frac{M_\text{sam}}{M} = \frac{M_\text{sam}}{mN_A}n=NA​N​=MMsam​​=mNA​Msam​​

  • MsamM_\text{sam}Msam​: 시료의 질량
  • MMM: 몰 질량 (1몰의 질량), mmm: 분자 1개의 질량

이상기체 법칙

충분히 밀도가 낮은 기체는 종류에 관계없이 다음 관계를 만족한다:

pV=nRT\boxed{pV = nRT}pV=nRT​

  • ppp: 압력 (Pa), VVV: 부피 (m3^33), TTT: 절대 온도 (K)
  • nnn: 몰 수
  • R=8.31R = 8.31R=8.31 J/mol⋅\cdot⋅K (기체 상수)

볼츠만 상수(Boltzmann constant) :

k=RNA=1.38×10−23  J/Kk = \frac{R}{N_A} = 1.38 \times 10^{-23} \;\text{J/K}k=NA​R​=1.38×10−23J/K

분자 수 NNN으로 표현하면:

pV=NkT\boxed{pV = NkT}pV=NkT​

주의 : pV=nRTpV = nRTpV=nRT는 몰수 nnn, pV=NkTpV = NkTpV=NkT는 분자 수 NNN을 사용한다. 혼동하지 않도록!

등온 과정에서 기체가 한 일

온도 TTT를 일정하게 유지하면서 부피를 ViV_iVi​에서 VfV_fVf​로 바꾸면:

W=∫ViVfp dV=∫ViVfnRTV dVW = \int_{V_i}^{V_f} p\,dV = \int_{V_i}^{V_f} \frac{nRT}{V}\,dVW=∫Vi​Vf​​pdV=∫Vi​Vf​​VnRT​dV

TTT가 일정하므로:

W=nRTln⁡VfVi(등온 과정)\boxed{W = nRT \ln\frac{V_f}{V_i}} \quad \text{(등온 과정)}W=nRTlnVi​Vf​​​(등온 과정)

  • 팽창 (Vf>ViV_f > V_iVf​>Vi​): W>0W > 0W>0. 기체가 외부에 일을 한다
  • 압축 (Vf<ViV_f < V_iVf​<Vi​): W<0W < 0W<0. 외부가 기체에 일을 한다

등적 과정에서는 W=0W = 0W=0, 등압 과정에서는 W=pΔV=nRΔTW = p\Delta V = nR\Delta TW=pΔV=nRΔT이다.

19.2 압력, 온도, rms 속력

압력의 미시적 기원

기체 분자가 용기 벽에 충돌하며 운동량을 전달 한다. 이것이 압력의 미시적 기원이다.

압력 유도

한 변의 길이가 LLL인 정육면체 용기 안에 NNN개의 분자가 있다. 질량 mmm인 분자 하나가 xxx 방향 속도 vxv_xvx​로 오른쪽 벽에 탄성 충돌하면:

Δpx=(−mvx)−(mvx)=−2mvx\Delta p_x = (-mv_x) - (mv_x) = -2mv_xΔpx​=(−mvx​)−(mvx​)=−2mvx​

벽이 받는 운동량: +2mvx+2mv_x+2mvx​

왕복 시간: Δt=2L/vx\Delta t = 2L/v_xΔt=2L/vx​

단일 분자가 벽에 가하는 평균 힘:

F1=2mvx2L/vx=mvx2LF_1 = \frac{2mv_x}{2L/v_x} = \frac{mv_x^2}{L}F1​=2L/vx​2mvx​​=Lmvx2​​

(vx2)avg=(vy2)avg=(vz2)avg=13(v2)avg(v_x^2)_\text{avg} = (v_y^2)_\text{avg} = (v_z^2)_\text{avg} = \frac{1}{3}(v^2)_\text{avg}(vx2​)avg​=(vy2​)avg​=(vz2​)avg​=31​(v2)avg​

압력 p=F/L2p = F/L^2p=F/L2이고 L3=VL^3 = VL3=V이므로:

19.3 병진 운동에너지

분자의 평균 운동에너지

분자 하나의 평균 병진 운동에너지:

Kavg=12mvrms2K_\text{avg} = \frac{1}{2}m v_\text{rms}^2Kavg​=21​mvrms2​

vrms2=3RT/Mv_\text{rms}^2 = 3RT/Mvrms2​=3RT/M이고 M/m=NAM/m = N_AM/m=NA​, R/NA=kR/N_A = kR/NA​=k이므로 vrms2=3kT/mv_\text{rms}^2 = 3kT/mvrms2​=3kT/m:

Kavg=12m⋅3kTm=32kTK_\text{avg} = \frac{1}{2}m \cdot \frac{3kT}{m} = \frac{3}{2}kTKavg​=21​m⋅m3kT​=23​kT

Kavg=32kT\boxed{K_\text{avg} = \frac{3}{2}kT}Kavg​=23​kT​

놀라운 결과: 같은 온도에서 모든 이상기체 분자는 질량에 관계없이 같은 평균 병진 운동에너지를 갖는다.

온도를 재는 것은 곧 분자의 평균 운동에너지를 재는 것이다!

19.4 평균 자유 경로

분자 사이의 충돌

분자들은 매우 빠르게 움직이지만, 향수병을 열어도 냄새가 방 건너편까지 도달하는 데 시간이 걸린다. 이유는 분자들이 서로 끊임없이 충돌 하기 때문이다.

평균 자유 경로 유도

평균 자유 경로(mean free path) λ\lambdaλ: 분자가 연속 충돌 사이에 이동하는 평균 거리

분자 지름 ddd인 분자가 시간 Δt\Delta tΔt 동안 이동하면, 단면적 πd2\pi d^2πd2, 길이 vΔtv\Delta tvΔt인 원통을 쓸고 지나간다.

이 원통 안의 분자 수 = 충돌 횟수:

충돌 수=NVπd2vΔt\text{충돌 수} = \frac{N}{V}\pi d^2 v\Delta t충돌 수=VN​πd2vΔt

상대 속도를 보정하면 (vrel=2 vavgv_\text{rel} = \sqrt{2}\,v_\text{avg}vrel​=2​vavg​):

λ=12 πd2  N/V\boxed{\lambda = \frac{1}{\sqrt{2}\,\pi d^2 \;N/V}}λ=2​πd2N/V1​​

이상기체 법칙 N/V=p/(kT)N/V = p/(kT)N/V=p/(kT)를 대입하면:

λ=kT2 πd2 p\lambda = \frac{kT}{\sqrt{2}\,\pi d^2\, p}λ=2​πd2pkT​

평균 자유 경로의 의미

해수면(p=1p = 1p=1 atm, T=300T = 300T=300 K)에서 산소 분자(d≈2.9×10−10d \approx 2.9 \times 10^{-10}d≈2.9×10−10 m):

λ≈1.1×10−7  m≈0.1  μm≈380×d\lambda \approx 1.1 \times 10^{-7}\;\text{m} \approx 0.1\;\mu\text{m} \approx 380 \times dλ≈1.1×10−7m≈0.1μm≈380×d

충돌 사이 평균 시간: t=λ/vavg≈0.24t = \lambda/v_\text{avg} \approx 0.24t=λ/vavg​≈0.24 ns

충돌 빈도: f=1/t≈4×109  s−1f = 1/t \approx 4 \times 10^9\;\text{s}^{-1}f=1/t≈4×109s−1. 초당 약 40억 회 충돌!

해발 100 km에서는 λ≈16\lambda \approx 16λ≈16 cm, 300 km에서는 λ≈20\lambda \approx 20λ≈20 km까지 증가한다.

19.5 에너지 등분배 정리

자유도와 에너지

등분배 정리

에너지 등분배 정리(equipartition theorem) :

열평형 상태에서, 에너지의 각 자유도(degree of freedom) 에 평균 12kT\frac{1}{2}kT21​kT의 에너지가 배분된다.

  • 단원자 분자 (He, Ne, Ar): 병진 3개 자유도 → Kavg=32kTK_\text{avg} = \frac{3}{2}kTKavg​=23​kT
  • 이원자 분자 (N2_22​, O2_22​, H2_22​): 병진 3 + 회전 2 = 5개 자유도 → Eavg=52kTE_\text{avg} = \frac{5}{2}kTEavg​=25​kT
  • 선형 다원자 (CO2_22​): 이원자처럼 회전 2개 → 병진 3 + 회전 2 = 5
  • 비선형 다원자 (H2_22​O, NH3_33​): 회전 3개 → 병진 3 + 회전 3 = 6 → Eavg=3kTE_\text{avg} = 3kTEavg​=3kT

이원자(및 선형 다원자) 분자의 회전 자유도가 2인 이유: 결합축 방향 회전은 관성 모멘트가 거의 0이므로 양자역학적으로 여기되지 않는다. (진동 자유도는 상온에서 대부분 동결되어 일반물리에서는 무시.)

자유도의 양자역학적 동결

실제로 이원자 분자의 CVC_VCV​는 온도에 따라 변한다. 수소(H2_22​)의 경우:

  • 극저온 (T<80T < 80T<80 K): 회전 에너지 준위 간격이 kTkTkT보다 크다 → 회전이 여기되지 않음 → f=3f = 3f=3, CV=32RC_V = \frac{3}{2}RCV​=23​R
  • 상온 (80<T<100080 < T < 100080<T<1000 K): 회전은 여기되지만 진동은 아직 동결 → f=5f = 5f=5, CV=52RC_V = \frac{5}{2}RCV​=25​R
  • 고온 (T>1000T > 1000T>1000 K): 진동 자유도(운동에너지 + 위치에너지)도 여기 → f=7f = 7f=7, CV=72RC_V = \frac{7}{2}RCV​=27​R

이것은 고전 물리학으로는 설명할 수 없으며, 에너지가 양자화되어 있기 때문에 나타나는 현상이다.

19.6 이상기체의 몰비열

19.7 이상기체의 단열 팽창

19.8 맥스웰 속력 분포

속력 분포 함수

모든 분자가 같은 속력을 갖지 않는다. 1852년 James Clerk Maxwell이 속력의 분포를 이론적으로 유도했다.

맥스웰 분포의 의미

온도가 높아지면:

  • 분포 곡선이 오른쪽으로 이동 (평균 속력 증가)
  • 곡선이 넓어지고 낮아진다 (속력 분산 증가)
  • 전체 면적은 항상 1 (확률 보존)

질량이 작은 분자일수록 같은 온도에서 더 빠르다.

태양의 대기에서 가벼운 수소가 탈출하는 것, 지구 대기에서 헬륨이 드문 것 모두 맥스웰 분포의 고속 꼬리(high-speed tail) 때문이다.
