8.1 퍼텐셜에너지

퍼텐셜에너지란?

퍼텐셜에너지(potential energy) UUU는 물체의 배치(configuration) 와 관련된 에너지다.

  • 운동에너지 KKK: 물체의 운동 상태 에 의존
  • 퍼텐셜에너지 UUU: 물체의 위치 또는 물체 사이의 배치 에 의존

퍼텐셜에너지는 계(system) 에 속한다. 물체 하나가 아니라, 물체와 그 주변(지구, 용수철 등)을 함께 고려해야 한다.

퍼텐셜에너지의 정의

퍼텐셜에너지의 변화량 은 보존력이 한 일의 음수로 정의한다:

ΔU=−W\Delta U = -WΔU=−W

여기서 WWW는 보존력이 한 일이다.

  • 보존력이 양의 일을 하면 → ΔU<0\Delta U < 0ΔU<0 (퍼텐셜에너지 감소)
  • 보존력이 음의 일을 하면 → ΔU>0\Delta U > 0ΔU>0 (퍼텐셜에너지 증가)

비유: 높은 곳에서 공을 떨어뜨리면, 중력이 양의 일을 하고, 그만큼 퍼텐셜에너지가 줄어든다. 줄어든 에너지는 운동에너지로 변환된다.

8.2 보존력과 비보존력

보존력(conservative force)

어떤 힘이 보존력 이려면, 다음 조건을 만족해야 한다:

  1. 그 힘이 한 일이 경로에 무관 하고, 시작점과 끝점만으로 결정된다
  2. 닫힌 경로를 따라 이동했을 때, 그 힘이 한 알짜 일이 0 이다

W닫힌 경로=∮F⃗⋅ds⃗=0W_\text{닫힌 경로} = \oint \vec{F} \cdot d\vec{s} = 0W닫힌 경로​=∮F⋅ds=0

보존력의 예

보존력:

  • 중력 F⃗g=−mgj^\vec{F}_g = -mg\hat{j}Fg​=−mgj^​
  • 용수철 힘 F⃗s=−kxi^\vec{F}_s = -kx\hat{i}Fs​=−kxi^
  • 만유인력

비보존력(nonconservative force):

  • 마찰력 f⃗k\vec{f}_kf​k​
  • 공기 저항

마찰력이 비보존력인 이유: 마찰력은 항상 운동 방향의 반대로 작용하므로, 왕복하면 일이 상쇄되지 않고 누적된다.

닫힌 경로를 따라 이동하면, 마찰력이 한 일은 항상 음수다: W마찰<0W_\text{마찰} < 0W마찰​<0

8.3 중력 퍼텐셜에너지

정의

물체가 높이 yiy_iyi​에서 yfy_fyf​로 이동할 때, 중력이 한 일:

Wg=−mg(yf−yi)=−mgΔyW_g = -mg(y_f - y_i) = -mg\Delta yWg​=−mg(yf​−yi​)=−mgΔy

퍼텐셜에너지 변화: ΔU=−Wg\Delta U = -W_gΔU=−Wg​이므로

ΔU=mg(yf−yi)=mgΔy\Delta U = mg(y_f - y_i) = mg\Delta yΔU=mg(yf​−yi​)=mgΔy

따라서 중력 퍼텐셜에너지 :

U(y)=mgyU(y) = mgyU(y)=mgy

기준점의 선택

U=mgyU = mgyU=mgy에서 y=0y = 0y=0인 기준점은 자유롭게 선택 할 수 있다.

  • 물리적으로 의미 있는 것은 ΔU=mgΔy\Delta U = mg\Delta yΔU=mgΔy뿐이다
  • 기준점이 바뀌면 UUU의 값은 바뀌지만, ΔU\Delta UΔU는 동일하다

예: 건물 3층 바닥을 기준으로 잡으면, 1층에서의 퍼텐셜에너지는 음수가 된다. 하지만 물리 법칙은 변하지 않는다.

편의상 보통 가장 낮은 위치 를 y=0y = 0y=0으로 선택한다.

8.4 탄성 퍼텐셜에너지

용수철의 퍼텐셜에너지

7장에서 용수철 힘이 한 일:

Ws=12kxi2−12kxf2W_s = \frac{1}{2}kx_i^2 - \frac{1}{2}kx_f^2Ws​=21​kxi2​−21​kxf2​

퍼텐셜에너지 변화: ΔU=−Ws\Delta U = -W_sΔU=−Ws​이므로

ΔU=12kxf2−12kxi2\Delta U = \frac{1}{2}kx_f^2 - \frac{1}{2}kx_i^2ΔU=21​kxf2​−21​kxi2​

따라서 탄성 퍼텐셜에너지 :

U(x)=12kx2U(x) = \frac{1}{2}kx^2U(x)=21​kx2

여기서 x=0x = 0x=0은 용수철의 자연 길이 (평형 위치)이다.

8.5 역학적 에너지 보존

역학적 에너지

역학적 에너지(mechanical energy) 를 다음과 같이 정의한다:

Emec=K+UE_\text{mec} = K + UEmec​=K+U

보존력만 작용하는 계에서, 일-운동에너지 정리 ΔK=W\Delta K = WΔK=W와 퍼텐셜에너지 정의 ΔU=−W\Delta U = -WΔU=−W를 결합하면:

ΔK=−ΔU\Delta K = -\Delta UΔK=−ΔU

ΔK+ΔU=0\Delta K + \Delta U = 0ΔK+ΔU=0

ΔEmec=0\Delta E_\text{mec} = 0ΔEmec​=0

역학적 에너지 보존 법칙

보존력만 작용하는 닫힌 계(고립계)에서:

Ki+Ui=Kf+UfK_i + U_i = K_f + U_fKi​+Ui​=Kf​+Uf​

Emec=K+U=일정E_\text{mec} = K + U = \text{일정}Emec​=K+U=일정

운동에너지와 퍼텐셜에너지는 서로 변환될 수 있지만, 그 합 은 항상 일정하다.

이것이 역학적 에너지 보존 법칙 이다.

예시: 에버랜드 T익스프레스

에버랜드의 T익스프레스는 높이 약 56 m에서 출발한다. 마찰을 무시하면, 최저점에서의 속력은?

mgh=12mv2mgh = \frac{1}{2}mv^2mgh=21​mv2

v=2gh=2×9.8×56≈33 m/s≈119 km/hv = \sqrt{2gh} = \sqrt{2 \times 9.8 \times 56} \approx 33 \text{ m/s} \approx 119 \text{ km/h}v=2gh​=2×9.8×56​≈33 m/s≈119 km/h

(실제 최고 속력은 약 104 km/h — 마찰과 공기 저항 때문에 줄어든다)

위치에너지와 운동에너지의 교환

높은 곳에서는 중력 퍼텐셜에너지가 크고, 낮은 곳에서는 그 에너지가 운동에너지로 바뀐다.

예시: 진자(pendulum)의 에너지 변환

진자의 최고점(A, C)에서는 K=0K = 0K=0, U=mghU = mghU=mgh (모든 에너지가 퍼텐셜)

최저점(B)에서는 U=0U = 0U=0, K=12mvmax2K = \frac{1}{2}mv_\text{max}^2K=21​mvmax2​ (모든 에너지가 운동)

mgh=12mvmax2  ⟹  vmax=2ghmgh = \frac{1}{2}mv_\text{max}^2 \implies v_\text{max} = \sqrt{2gh}mgh=21​mvmax2​⟹vmax​=2gh​

진자에서 보이는 에너지 보존

진자는 양 끝에서 위치에너지가 크고, 가장 낮은 지점에서 운동에너지가 가장 크다.

8.6 퍼텐셜에너지 곡선

U(x) 그래프에서 읽을 수 있는 정보

퍼텐셜에너지 곡선 U(x)U(x)U(x)와 역학적 에너지 EmecE_\text{mec}Emec​ 선을 함께 그리면, 입자의 운동에 대해 많은 것을 알 수 있다.

운동에너지와 반환점

임의의 위치 xxx에서 운동에너지:

K(x)=Emec−U(x)K(x) = E_\text{mec} - U(x)K(x)=Emec​−U(x)

K≥0K \geq 0K≥0이어야 하므로, 입자는 U(x)≤EmecU(x) \leq E_\text{mec}U(x)≤Emec​인 영역에서만 운동할 수 있다.

반환점(turning point): U(x)=EmecU(x) = E_\text{mec}U(x)=Emec​인 점

  • 반환점에서 K=0K = 0K=0 → 입자의 속력이 0이 된다
  • 입자는 반환점에서 방향을 바꾼다

힘과 퍼텐셜에너지의 관계

1차원에서, 보존력과 퍼텐셜에너지의 관계:

F(x)=−dUdxF(x) = -\frac{dU}{dx}F(x)=−dxdU​

  • U(x)U(x)U(x)가 감소 하는 방향 → F>0F > 0F>0 (양의 방향으로 힘)
  • U(x)U(x)U(x)가 증가 하는 방향 → F<0F < 0F<0 (음의 방향으로 힘)
  • U(x)U(x)U(x)의 기울기가 급할수록 → 힘이 크다

입자는 항상 퍼텐셜에너지가 낮아지는 방향 으로 힘을 받는다.

평형점

F(x)=−dU/dx=0F(x) = -dU/dx = 0F(x)=−dU/dx=0인 점, 즉 U(x)U(x)U(x)의 극값에서 평형 이 된다.

안정 평형(stable equilibrium):

  • U(x)U(x)U(x)가 극소 인 점
  • 살짝 벗어나면 원래 위치로 돌아오는 복원력이 작용
  • 예: 그릇 바닥의 구슬

불안정 평형(unstable equilibrium):

  • U(x)U(x)U(x)가 극대 인 점
  • 살짝 벗어나면 더 멀어지는 방향으로 힘이 작용
  • 예: 볼록한 언덕 꼭대기의 구슬

중립 평형(neutral equilibrium):

  • U(x)U(x)U(x)가 일정 한 구간
  • 어디서든 평형, 힘이 0

8.7 외력이 하는 일

보존력 + 외력

외력 F⃗ext\vec{F}_\text{ext}Fext​가 계에 작용할 때, 일-에너지 정리를 확장하면:

ΔEmec=Wext\Delta E_\text{mec} = W_\text{ext}ΔEmec​=Wext​

ΔK+ΔU=Wext\Delta K + \Delta U = W_\text{ext}ΔK+ΔU=Wext​

  • Wext>0W_\text{ext} > 0Wext​>0: 외력이 계에 에너지를 공급
  • Wext<0W_\text{ext} < 0Wext​<0: 외력이 계에서 에너지를 빼앗음

8.8 마찰과 열에너지

마찰이 있을 때의 에너지

마찰력 fkf_kfk​는 비보존력이므로, 퍼텐셜에너지로 다룰 수 없다.

운동마찰력 fkf_kfk​가 거리 ddd에 걸쳐 작용하면:

ΔEth=fkd\Delta E_\text{th} = f_k dΔEth​=fk​d

여기서 EthE_\text{th}Eth​는 열에너지(thermal energy) 로, 물체와 접촉면의 온도를 높이는 에너지다.

마찰이 있는 계에서 에너지 관계:

ΔEmec+ΔEth=Wext\Delta E_\text{mec} + \Delta E_\text{th} = W_\text{ext}ΔEmec​+ΔEth​=Wext​

외력이 없으면 (Wext=0W_\text{ext} = 0Wext​=0):

ΔEmec=−ΔEth=−fkd\Delta E_\text{mec} = -\Delta E_\text{th} = -f_k dΔEmec​=−ΔEth​=−fk​d

사라진 역학적 에너지의 행방

마찰이 있을 때 줄어든 역학적 에너지는 주로 열에너지로 전환된다.

마찰에 의한 역학적 에너지 손실

마찰이 있으면 역학적 에너지가 줄어들고, 그만큼 열에너지가 증가 한다.

Kf+Uf=Ki+Ui−fkdK_f + U_f = K_i + U_i - f_k dKf​+Uf​=Ki​+Ui​−fk​d

  • 빗면을 미끄러져 내려오는 물체: mgh=12mv2+fkdmgh = \frac{1}{2}mv^2 + f_k dmgh=21​mv2+fk​d
  • 바닥의 속력: v=2g(h−μkdcos⁡θ)v = \sqrt{2g(h - \mu_k d \cos\theta)}v=2g(h−μk​dcosθ)​

예시: 번지점프

번지점프에서 뛰어내린 사람(질량 mmm, 높이 hhh)은 떨어지면서:

  1. 처음: Ug=mghU_g = mghUg​=mgh, K=0K = 0K=0, Us=0U_s = 0Us​=0
  2. 줄이 당기기 시작: 중력 퍼텐셜에너지 → 운동에너지 + 탄성 퍼텐셜에너지
  3. 최저점: K=0K = 0K=0, UgU_gUg​ 감소, UsU_sUs​ 최대

mgh=12kxmax2mgh = \frac{1}{2}kx_\text{max}^2mgh=21​kxmax2​

(실제로는 공기 저항과 줄의 에너지 소산이 있어 진동이 감쇄한다)

8.9 에너지 보존 법칙

일반적인 에너지 보존 법칙

고립계(외력이 없는 계)에서, 모든 형태의 에너지 총합 은 일정하다:

ΔEtotal=ΔK+ΔU+ΔEth+ΔEint=0\Delta E_\text{total} = \Delta K + \Delta U + \Delta E_\text{th} + \Delta E_\text{int} = 0ΔEtotal​=ΔK+ΔU+ΔEth​+ΔEint​=0

여기서 EintE_\text{int}Eint​는 계의 내부 에너지(화학 에너지, 핵에너지 등)이다.

에너지는 생성되거나 소멸되지 않는다. 한 형태에서 다른 형태로 변환 될 뿐이다.

이것이 물리학에서 가장 기본적인 법칙 중 하나인 에너지 보존 법칙 이다.

에너지 보존의 전략

에너지 보존 문제를 풀 때:

  1. 계 를 정의한다 (어떤 물체들을 포함할 것인가?)
  2. 계에 작용하는 힘을 보존력 과 비보존력 으로 분류한다
  3. 보존력 → 퍼텐셜에너지로 처리
  4. 비보존력(마찰 등) → 열에너지로 처리
  5. 외력 → 일로 처리
  6. 에너지 방정식을 세운다: Ki+Ui=Kf+Uf+fkd+⋯K_i + U_i = K_f + U_f + f_k d + \cdotsKi​+Ui​=Kf​+Uf​+fk​d+⋯
  7. 알고 싶은 물리량을 구한다
