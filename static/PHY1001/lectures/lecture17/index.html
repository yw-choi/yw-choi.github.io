17.1 음속

음파란?

16장에서 배운 파동은 횡파(transverse wave)가 중심이었다. 이번 장의 주인공은 종파(longitudinal wave) 인 음파(sound wave) 다.

  • 횡파: 매질의 진동 방향이 파동 진행 방향에 수직 (예: 줄의 파동)
  • 종파: 매질의 진동 방향이 파동 진행 방향에 평행 (예: 음파, 지진의 P파)

음파는 공기, 물, 금속 등 매질 이 있어야 전파된다. 진공에서는 소리가 전달되지 않는다. 우주에서는 폭발 소리가 들리지 않는다!

음속 공식

16장에서 횡파의 속력이 v=τ/μv = \sqrt{\tau/\mu}v=τ/μ​ (탄성적 성질/관성적 성질)임을 배웠다. 종파에서도 같은 구조:

v=탄성적 성질관성적 성질=Bρv = \sqrt{\frac{\text{탄성적 성질}}{\text{관성적 성질}}} = \sqrt{\frac{B}{\rho}}v=관성적 성질탄성적 성질​​=ρB​​

  • BBB: 체적 탄성률(bulk modulus). 매질이 압축에 저항하는 정도
  • ρ\rhoρ: 매질의 밀도(density)

B=−ΔpΔV/VB = -\frac{\Delta p}{\Delta V / V}B=−ΔV/VΔp​

압력 변화 Δp\Delta pΔp에 대한 부피 변화의 비율이다. 부호 규약: Δp>0\Delta p > 0Δp>0이면 ΔV<0\Delta V < 0ΔV<0 (압축)이므로 B>0B > 0B>0.

음속의 유도

공기 기둥 속을 진행하는 압축 펄스를 생각하자. 펄스와 함께 움직이는 기준계에서, 공기가 속력 vvv로 펄스를 통과한다.

두께 Δx\Delta xΔx, 단면적 AAA인 공기 요소에 뉴턴 제2법칙을 적용하면:

알짜힘: F=pA−(p+Δp)A=−Δp⋅AF = pA - (p + \Delta p)A = -\Delta p \cdot AF=pA−(p+Δp)A=−Δp⋅A

질량: Δm=ρAΔx=ρAvΔt\Delta m = \rho A \Delta x = \rho A v \Delta tΔm=ρAΔx=ρAvΔt

가속도: a=Δv/Δta = \Delta v / \Delta ta=Δv/Δt

F=maF = maF=ma에서:

−Δp⋅A=(ρAvΔt)ΔvΔt-\Delta p \cdot A = (\rho A v \Delta t) \frac{\Delta v}{\Delta t}−Δp⋅A=(ρAvΔt)ΔtΔv​

ρv2=−ΔpΔv/v\rho v^2 = -\frac{\Delta p}{\Delta v / v}ρv2=−Δv/vΔp​

여기서 ΔV/V=AΔvΔt/(AvΔt)=Δv/v\Delta V / V = A\Delta v\Delta t / (Av\Delta t) = \Delta v / vΔV/V=AΔvΔt/(AvΔt)=Δv/v이므로:

ρv2=−ΔpΔV/V=B\rho v^2 = -\frac{\Delta p}{\Delta V / V} = Bρv2=−ΔV/VΔp​=B

따라서:

v=Bρ\boxed{v = \sqrt{\frac{B}{\rho}}}v=ρB​​​

17.2 진행하는 음파

변위 함수

음파에서 공기 요소의 변위(displacement) 는 평형 위치로부터의 종방향 이동:

s(x,t)=smcos⁡(kx−ωt)s(x, t) = s_m \cos(kx - \omega t)s(x,t)=sm​cos(kx−ωt)

  • sms_msm​: 변위 진폭(displacement amplitude). 평형 위치에서 최대 변위
  • k=2π/λk = 2\pi/\lambdak=2π/λ: 파수(wave number)
  • ω=2πf\omega = 2\pi fω=2πf: 각진동수

횡파의 y(x,t)y(x,t)y(x,t)와 형태가 동일하다. 다만 진동 방향이 xxx축과 같다는 점이 다르다.

압력 변화

음파가 지나가면 공기의 압력도 주기적으로 변한다:

Δp(x,t)=Δpmsin⁡(kx−ωt)\Delta p(x, t) = \Delta p_m \sin(kx - \omega t)Δp(x,t)=Δpm​sin(kx−ωt)

여기서 압력 진폭(pressure amplitude) 은:

Δpm=(vρω)sm\Delta p_m = (v\rho\omega) s_mΔpm​=(vρω)sm​

핵심: 변위와 압력은 90° 위상차가 있다!

  • 변위가 최대인 곳 → 압력 변화 = 0
  • 변위가 0인 곳 → 압력 변화 최대 (압축 또는 팽창)

압력-변위 관계의 유도

변위 sss에 의해 공기 요소의 부피가 변한다. 두께 Δx\Delta xΔx, 단면적 AAA인 요소에서:

원래 부피: V=AΔxV = A\Delta xV=AΔx

부피 변화: ΔV=AΔs\Delta V = A\Delta sΔV=AΔs (Δs\Delta sΔs는 양쪽 면의 변위 차)

미분 극한에서: ΔVV=ΔsΔx→∂s∂x\frac{\Delta V}{V} = \frac{\Delta s}{\Delta x} \to \frac{\partial s}{\partial x}VΔV​=ΔxΔs​→∂x∂s​

체적 탄성률의 정의 Δp=−BΔVV\Delta p = -B \frac{\Delta V}{V}Δp=−BVΔV​에서:

Δp=−B∂s∂x\Delta p = -B \frac{\partial s}{\partial x}Δp=−B∂x∂s​

s=smcos⁡(kx−ωt)s = s_m \cos(kx - \omega t)s=sm​cos(kx−ωt)를 대입하면:

Δp=−B⋅(−ksm)sin⁡(kx−ωt)=Bksmsin⁡(kx−ωt)\Delta p = -B \cdot (-k s_m) \sin(kx - \omega t) = Bk s_m \sin(kx - \omega t)Δp=−B⋅(−ksm​)sin(kx−ωt)=Bksm​sin(kx−ωt)

v=ω/kv = \omega / kv=ω/k와 v2=B/ρv^2 = B/\rhov2=B/ρ를 사용하면 Bk=v2ρk=vρωBk = v^2\rho k = v\rho\omegaBk=v2ρk=vρω이므로:

Δpm=vρωsm\boxed{\Delta p_m = v\rho\omega s_m}Δpm​=vρωsm​​

17.3 간섭

두 음파의 간섭

같은 진동수, 같은 진폭의 두 음파가 같은 방향으로 진행하되 위상차 ϕ\phiϕ가 있는 경우:

s1=smcos⁡(kx−ωt),s2=smcos⁡(kx−ωt+ϕ)s_1 = s_m \cos(kx - \omega t), \quad s_2 = s_m \cos(kx - \omega t + \phi)s1​=sm​cos(kx−ωt),s2​=sm​cos(kx−ωt+ϕ)

중첩 원리에 의한 합성파:

s′=[2smcos⁡ϕ2]cos⁡(kx−ωt+ϕ2)s' = \left[2s_m \cos\frac{\phi}{2}\right] \cos\left(kx - \omega t + \frac{\phi}{2}\right)s′=[2sm​cos2ϕ​]cos(kx−ωt+2ϕ​)

합성파의 진폭:

sm′=∣2smcos⁡ϕ2∣s'_m = \left|2s_m \cos\frac{\phi}{2}\right|sm′​=​2sm​cos2ϕ​​

보강 간섭과 상쇄 간섭

보강 간섭(constructive interference): ϕ=0,2π,4π,…\phi = 0, 2\pi, 4\pi, \ldotsϕ=0,2π,4π,… → sm′=2sms'_m = 2s_msm′​=2sm​ (최대)

상쇄 간섭(destructive interference): ϕ=π,3π,5π,…\phi = \pi, 3\pi, 5\pi, \ldotsϕ=π,3π,5π,… → sm′=0s'_m = 0sm′​=0 (소멸)

위상차 ϕ\phiϕ는 경로차(path length difference) ΔL\Delta LΔL과 관련된다:

ϕ=ΔLλ⋅2π\phi = \frac{\Delta L}{\lambda} \cdot 2\piϕ=λΔL​⋅2π

경로차에 의한 간섭 조건

두 점 음원 S1S_1S1​, S2S_2S2​에서 같은 위상으로 방출된 음파가 점 PPP에 도달할 때, 경로차 ΔL=∣L2−L1∣\Delta L = |L_2 - L_1|ΔL=∣L2​−L1​∣에 따라:

보강 간섭:

ΔLλ=0,1,2,3,…\frac{\Delta L}{\lambda} = 0, 1, 2, 3, \ldotsλΔL​=0,1,2,3,…

상쇄 간섭:

ΔLλ=0.5,1.5,2.5,…\frac{\Delta L}{\lambda} = 0.5, 1.5, 2.5, \ldotsλΔL​=0.5,1.5,2.5,…

17.4 세기와 음압 수준

세기(Intensity)

음파의 세기(intensity) 는 단위 면적당 전달되는 평균 에너지 비율(일률):

I=PAI = \frac{P}{A}I=AP​

변위 진폭 sms_msm​으로 표현하면:

I=12ρvω2sm2I = \frac{1}{2}\rho v \omega^2 s_m^2I=21​ρvω2sm2​

단위: W/m²

역제곱 법칙

등방성 점 음원(isotropic point source)에서 출력 PsP_sPs​로 음파를 방출하면, 거리 rrr에서의 세기:

I=Ps4πr2I = \frac{P_s}{4\pi r^2}I=4πr2Ps​​

구의 표면적 4πr24\pi r^24πr2에 에너지가 균일하게 분배되기 때문이다.

핵심: 세기는 거리의 제곱에 반비례한다.

거리가 2배 → 세기가 1/4로 감소. 거리가 10배 → 세기가 1/100로 감소.

17.5 악기의 음원: 관에서의 정상파

열린관과 닫힌관

관악기(플루트, 클라리넷, 파이프 오르간 등)의 원리는 관 속에서 형성되는 정상파(standing wave) 다.

  • 열린 끝(open end): 배(antinode). 공기가 자유롭게 진동
  • 닫힌 끝(closed end): 마디(node). 공기가 움직이지 못함

이것은 줄의 정상파에서 고정단(마디)과 자유단(배)에 해당한다.

양쪽 열린 관 (Two Open Ends)

양 끝이 배이므로, 가장 단순한 정상파의 파장:

L=λ2⇒λ=2LL = \frac{\lambda}{2} \quad \Rightarrow \quad \lambda = 2LL=2λ​⇒λ=2L

일반적으로, nnn번째 배음(harmonic)의 파장과 진동수:

λ=2Ln,f=vλ=nv2L,n=1,2,3,…\lambda = \frac{2L}{n}, \quad f = \frac{v}{\lambda} = \frac{nv}{2L}, \quad n = 1, 2, 3, \ldotsλ=n2L​,f=λv​=2Lnv​,n=1,2,3,…

모든 정수 배음 이 가능하다. n=1n = 1n=1이 기본 진동(fundamental), n=2n = 2n=2가 2차 배음, ...

한쪽 닫힌 관 (One Open End)

열린 끝은 배, 닫힌 끝은 마디. 가장 단순한 정상파:

L=λ4⇒λ=4LL = \frac{\lambda}{4} \quad \Rightarrow \quad \lambda = 4LL=4λ​⇒λ=4L

일반적으로:

λ=4Ln,f=nv4L,n=1,3,5,…\lambda = \frac{4L}{n}, \quad f = \frac{nv}{4L}, \quad n = 1, 3, 5, \ldotsλ=n4L​,f=4Lnv​,n=1,3,5,…

홀수 배음만 가능하다! n=2,4,6,…n = 2, 4, 6, \ldotsn=2,4,6,…는 존재하지 않는다.

이것이 클라리넷(한쪽 닫힌 관)과 플루트(양쪽 열린 관)의 음색 차이를 만든다.

17.6 맥놀이

맥놀이 현상

진동수가 약간 다른 두 음파가 동시에 들리면, 소리의 세기가 주기적으로 커졌다 작아졌다 한다. 이것이 맥놀이(beats) 다.

예: 440 Hz와 444 Hz 음을 동시에 들으면, 1초에 4번 소리가 커졌다 작아진다.

악기 조율에 활용: 기준 음과 맞추려는 악기를 동시에 울리고, 맥놀이가 사라질 때까지 조율한다.

맥놀이의 수학적 분석

같은 진폭 sms_msm​, 약간 다른 각진동수 ω1\omega_1ω1​, ω2\omega_2ω2​ (ω1>ω2\omega_1 > \omega_2ω1​>ω2​)인 두 파동:

s1=smcos⁡ω1t,s2=smcos⁡ω2ts_1 = s_m \cos \omega_1 t, \quad s_2 = s_m \cos \omega_2 ts1​=sm​cosω1​t,s2​=sm​cosω2​t

중첩: s=s1+s2=sm(cos⁡ω1t+cos⁡ω2t)s = s_1 + s_2 = s_m(\cos\omega_1 t + \cos\omega_2 t)s=s1​+s2​=sm​(cosω1​t+cosω2​t)

ωbeat=2ω′=ω1−ω2\omega_\text{beat} = 2\omega' = \omega_1 - \omega_2ωbeat​=2ω′=ω1​−ω2​

진동수로 표현하면:

fbeat=∣f1−f2∣\boxed{f_\text{beat} = |f_1 - f_2|}fbeat​=∣f1​−f2​∣​

맥놀이 진동수 = 두 진동수의 차이(절댓값).

### 맥놀이 예시 피아노 조율사가 440 Hz 소리굽쇠와 함께 피아노 건반을 쳤더니 1초에 3번 맥놀이가 들렸다. 피아노 건반의 진동수는? $$f_\text{beat} = |f_1 - f_2| = 3 \text{ Hz}$$ 따라서 $f_\text{piano} = 440 \pm 3$ Hz, 즉 437 Hz 또는 443 Hz. 어느 쪽인지 알려면? 건반의 음을 약간 높이면(줄을 조이면): - 맥놀이가 빨라지면 → 440에서 멀어지는 중 → 원래 443 Hz였다 - 맥놀이가 느려지면 → 440에 가까워지는 중 → 원래 437 Hz였다 맥놀이와 간섭 시뮬레이션

17.7 도플러 효과

도플러 효과란?

구급차가 다가올 때 사이렌 소리가 높게 들리고, 멀어질 때 낮게 들린다. 이것이 도플러 효과(Doppler effect) 다.

음원이나 관측자가 움직이면, 관측되는 진동수가 원래 진동수와 달라진다.

도플러 효과 일반 공식

f′=fv±vOv∓vSf' = f \frac{v \pm v_O}{v \mp v_S}f′=fv∓vS​v±vO​​

  • fff: 음원의 고유 진동수
  • f′f'f′: 관측되는 진동수
  • vvv: 음속
  • vOv_OvO​: 관측자의 속력
  • vSv_SvS​: 음원의 속력

부호 규칙: "접근하면 진동수 증가" 방향이 양

  • 분자(v±vOv \pm v_Ov±vO​): 관측자가 음원 쪽으로 이동하면 +
  • 분모(v∓vSv \mp v_Sv∓vS​): 음원이 관측자 쪽으로 이동하면 −

경우 1: 관측자가 움직이는 경우

음원 정지(vS=0v_S = 0vS​=0), 관측자가 속력 vOv_OvO​로 움직이는 경우.

관측자가 음원에 접근하면, 파면을 더 자주 만난다:

f′=fv+vOvf' = f \frac{v + v_O}{v}f′=fvv+vO​​

관측자가 음원에서 멀어지면:

f′=fv−vOvf' = f \frac{v - v_O}{v}f′=fvv−vO​​

물리적 이해: 관측자 기준에서 파동의 상대 속도가 v+vOv + v_Ov+vO​ (접근) 또는 v−vOv - v_Ov−vO​ (멀어짐)로 바뀐다. 파장은 그대로이므로, 진동수가 변한다.

경우 2: 음원이 움직이는 경우

관측자 정지(vO=0v_O = 0vO​=0), 음원이 속력 vSv_SvS​로 움직이는 경우.

음원이 관측자에 접근하면, 파면이 앞쪽으로 압축된다:

λ′=λ−vST=λ(1−vSv)=v−vSf\lambda' = \lambda - v_S T = \lambda\left(1 - \frac{v_S}{v}\right) = \frac{v - v_S}{f}λ′=λ−vS​T=λ(1−vvS​​)=fv−vS​​

f′=vλ′=fvv−vSf' = \frac{v}{\lambda'} = f\frac{v}{v - v_S}f′=λ′v​=fv−vS​v​

음원이 멀어지면:

f′=fvv+vSf' = f\frac{v}{v + v_S}f′=fv+vS​v​

도플러 효과 예제

구급차의 사이렌 진동수: f=1000f = 1000f=1000 Hz. 구급차 속도: vS=30v_S = 30vS​=30 m/s. 음속: v=343v = 343v=343 m/s.

다가올 때:

f′=1000×343343−30=1000×343313=1096 Hzf' = 1000 \times \frac{343}{343 - 30} = 1000 \times \frac{343}{313} = 1096 \text{ Hz}f′=1000×343−30343​=1000×313343​=1096 Hz

멀어질 때:

f′=1000×343343+30=1000×343373=920 Hzf' = 1000 \times \frac{343}{343 + 30} = 1000 \times \frac{343}{373} = 920 \text{ Hz}f′=1000×343+30343​=1000×373343​=920 Hz

진동수 변화: 1096−920=1761096 - 920 = 1761096−920=176 Hz. 이것이 우리가 흔히 듣는 "삐~이이" 소리의 원인이다.

17.8 초음속과 충격파

음원이 음속을 넘으면?

도플러 공식에서 vS>vv_S > vvS​>v이면 분모가 음수. 공식이 더 이상 성립하지 않는다.

음원이 음속보다 빠르면, 음파의 파면을 앞지른다. 이때 발생하는 것이 충격파(shock wave) 다.

마하 원뿔

음원이 vS>vv_S > vvS​>v로 이동하면, 각 순간 방출된 구면파의 공통접선이 원뿔면 을 이룬다.

이 원뿔의 반각 θ\thetaθ:

sin⁡θ=vvS=1Ma\sin\theta = \frac{v}{v_S} = \frac{1}{\text{Ma}}sinθ=vS​v​=Ma1​

여기서 마하 수(Mach number) 는:

Ma=vSv\text{Ma} = \frac{v_S}{v}Ma=vvS​​

  • Ma = 1: 음속 (소닉 붐의 시작)
  • Ma > 1: 초음속(supersonic). 전투기, 총알 등
  • Ma > 5: 극초음속(hypersonic)

### 충격파의 물리 충격파는 매우 큰 압력 변화를 수반한다. 이것이 **소닉 붐** (sonic boom)의 원인이다. - 총알이 지나가면 "탁!" 하는 소리. 이것이 미니 소닉 붐 - 번개의 열 팽창이 충격파를 만들어 천둥 소리가 된다 - 초음속 전투기가 지나가면 원뿔형 충격파가 지면을 쓸고 지나간다 마하 원뿔의 각도를 측정하면 물체의 속도를 알 수 있다: $$v_S = \frac{v}{\sin\theta}$$ 예: 총알의 사진에서 마하 원뿔 각도가 $\theta = 30°$이면: $$\text{Ma} = \frac{1}{\sin 30°} = 2.0$$ 총알은 음속의 2배로 날아간다. 도플러 효과 시뮬레이션
