9장: 질량중심과 선운동량

Center of Mass and Linear Momentum

이번 장에서 배울 내용

  • 질량중심(center of mass): 입자계의 대표 위치
  • 선운동량(linear momentum): p⃗=mv⃗\vec{p} = m\vec{v}p​=mv
  • 충격량(impulse) 과 충격량-운동량 정리
  • 운동량 보존 법칙: 외력이 없으면 p⃗\vec{p}p​ 보존
  • 탄성 충돌 과 비탄성 충돌 (1차원, 2차원)
  • 로켓 추진: 변하는 질량 문제

왜 운동량을 배우나?

지금까지는 하나의 입자 에 대한 운동을 다뤘다.

하지만 현실에서는 여러 물체가 서로 상호작용한다:

  • 당구 에서 공끼리 부딪힐 때
  • 자동차 사고 에서 두 차량이 충돌할 때
  • 누리호 로켓이 연료를 분사하며 가속할 때

이런 문제를 다루려면 운동량(momentum) 이라는 새로운 물리량이 필요하다.

9.1 질량중심

질량중심이란?

여러 입자로 이루어진 계(system)에는 특별한 점이 있다:

입자계 전체의 운동을 대표하는 점 — 질량중심(center of mass, com)

공중에서 회전하며 날아가는 야구 배트를 생각해 보자. 배트의 각 부분은 복잡하게 움직이지만, 질량중심 은 포물선 궤적을 따른다!

두 입자의 질량중심

질량 m1m_1m1​, m2m_2m2​인 두 입자가 x1x_1x1​, x2x_2x2​에 있을 때:

xcom=m1x1+m2x2m1+m2x_\text{com} = \frac{m_1 x_1 + m_2 x_2}{m_1 + m_2}xcom​=m1​+m2​m1​x1​+m2​x2​​

질량이 큰 쪽에 가까운 곳에 질량중심이 위치한다.

nnn개 입자의 질량중심

nnn개 입자로 일반화하면:

xcom=∑i=1nmixi∑i=1nmi=1M∑i=1nmixix_\text{com} = \frac{\sum_{i=1}^{n} m_i x_i}{\sum_{i=1}^{n} m_i} = \frac{1}{M} \sum_{i=1}^{n} m_i x_ixcom​=∑i=1n​mi​∑i=1n​mi​xi​​=M1​i=1∑n​mi​xi​

여기서 M=∑miM = \sum m_iM=∑mi​는 전체 질량이다.

3차원으로 확장하면:

r⃗com=1M∑i=1nmir⃗i\vec{r}_\text{com} = \frac{1}{M} \sum_{i=1}^{n} m_i \vec{r}_ircom​=M1​i=1∑n​mi​ri​

각 성분별로:

xcom=1M∑mixi,ycom=1M∑miyi,zcom=1M∑mizix_\text{com} = \frac{1}{M}\sum m_i x_i, \quad y_\text{com} = \frac{1}{M}\sum m_i y_i, \quad z_\text{com} = \frac{1}{M}\sum m_i z_ixcom​=M1​∑mi​xi​,ycom​=M1​∑mi​yi​,zcom​=M1​∑mi​zi​

연속 물체의 질량중심

질량이 연속적으로 분포한 물체의 경우, 합을 적분으로 바꾼다:

r⃗com=1M∫r⃗ dm\vec{r}_\text{com} = \frac{1}{M} \int \vec{r} \, dmrcom​=M1​∫rdm

각 성분:

xcom=1M∫x dm,ycom=1M∫y dmx_\text{com} = \frac{1}{M}\int x \, dm, \quad y_\text{com} = \frac{1}{M}\int y \, dmxcom​=M1​∫xdm,ycom​=M1​∫ydm

밀도가 균일하면 dm=ρ dVdm = \rho \, dVdm=ρdV로 바꿀 수 있다.

대칭 을 활용하면 계산이 쉬워진다: 대칭축이 있으면 질량중심은 그 축 위에 있다.

9.2 입자계에 대한 뉴턴 제2법칙

질량중심의 운동

질량중심의 위치를 시간으로 미분하면:

Mv⃗com=∑miv⃗iM\vec{v}_\text{com} = \sum m_i \vec{v}_iMvcom​=∑mi​vi​

한 번 더 미분하면:

Ma⃗com=∑mia⃗i=∑F⃗iM\vec{a}_\text{com} = \sum m_i \vec{a}_i = \sum \vec{F}_iMacom​=∑mi​ai​=∑Fi​

내부 힘(작용·반작용)은 서로 상쇄되므로:

F⃗net, ext=Ma⃗com\vec{F}_\text{net, ext} = M\vec{a}_\text{com}Fnet, ext​=Macom​

입자계에 작용하는 알짜 외력 은 전체 질량이 질량중심에 모여 있는 하나의 입자에 작용하는 것과 같다!

질량중심 운동의 의미

복잡한 입자계도 질량중심 에 주목하면 단순해진다:

  • 불꽃놀이 폭죽이 공중에서 터져도, 파편들의 질량중심은 포물선을 유지한다
  • 피겨 스케이팅 선수가 회전해도 질량중심의 궤적은 뉴턴 법칙을 따른다

외력이 0이면:

a⃗com=0⇒v⃗com=일정\vec{a}_\text{com} = 0 \quad \Rightarrow \quad \vec{v}_\text{com} = \text{일정}acom​=0⇒vcom​=일정

9.3 선운동량

선운동량의 정의

질량 mmm, 속도 v⃗\vec{v}v인 입자의 선운동량(linear momentum):

p⃗=mv⃗\vec{p} = m\vec{v}p​=mv

  • 벡터 이다 (방향은 속도와 같다)
  • 단위: kg⋅m/s\text{kg} \cdot \text{m/s}kg⋅m/s
  • 속력이 같더라도 질량이 크면 운동량이 크다

뉴턴 제2법칙과 운동량

뉴턴 제2법칙을 운동량으로 다시 쓰면:

F⃗net=ma⃗=mdv⃗dt=d(mv⃗)dt=dp⃗dt\vec{F}_\text{net} = m\vec{a} = m\frac{d\vec{v}}{dt} = \frac{d(m\vec{v})}{dt} = \frac{d\vec{p}}{dt}Fnet​=ma=mdtdv​=dtd(mv)​=dtdp​​

알짜힘 = 운동량의 시간 변화율

사실 이것이 뉴턴이 원래 표현한 제2법칙의 형태다!

질량이 변하는 문제(로켓 등)에서는 이 형태가 더 일반적이다.

입자계의 선운동량

nnn개 입자로 이루어진 계의 총 운동량:

P⃗=∑i=1nmiv⃗i=Mv⃗com\vec{P} = \sum_{i=1}^{n} m_i \vec{v}_i = M\vec{v}_\text{com}P=i=1∑n​mi​vi​=Mvcom​

이를 미분하면:

dP⃗dt=Ma⃗com=F⃗net, ext\frac{d\vec{P}}{dt} = M\vec{a}_\text{com} = \vec{F}_\text{net, ext}dtdP​=Macom​=Fnet, ext​

외력이 없으면 (F⃗net, ext=0\vec{F}_\text{net, ext} = 0Fnet, ext​=0):

P⃗=일정(운동량 보존)\vec{P} = \text{일정} \quad (\text{운동량 보존})P=일정(운동량 보존)

9.4 충돌과 충격량

충격량(impulse)이란?

야구 방망이로 공을 칠 때, 매우 짧은 시간 동안 매우 큰 힘이 작용한다.

충격량(impulse) J⃗\vec{J}J는 힘의 시간 적분:

J⃗=∫titfF⃗(t) dt\vec{J} = \int_{t_i}^{t_f} \vec{F}(t)\, dtJ=∫ti​tf​​F(t)dt

충격량-운동량 정리

뉴턴 제2법칙 F⃗=dp⃗/dt\vec{F} = d\vec{p}/dtF=dp​/dt를 적분하면:

J⃗=∫titfF⃗ dt=∫pipfdp⃗=p⃗f−p⃗i=Δp⃗\vec{J} = \int_{t_i}^{t_f} \vec{F}\, dt = \int_{p_i}^{p_f} d\vec{p} = \vec{p}_f - \vec{p}_i = \Delta\vec{p}J=∫ti​tf​​Fdt=∫pi​pf​​dp​=p​f​−p​i​=Δp​

충격량 = 운동량의 변화

J⃗=Δp⃗=p⃗f−p⃗i\vec{J} = \Delta\vec{p} = \vec{p}_f - \vec{p}_iJ=Δp​=p​f​−p​i​

이것을 충격량-운동량 정리(impulse-momentum theorem) 라 한다.

평균 힘

충격량은 평균 힘 으로도 표현할 수 있다:

J⃗=F⃗avgΔt\vec{J} = \vec{F}_\text{avg} \Delta tJ=Favg​Δt

여기서 Δt=tf−ti\Delta t = t_f - t_iΔt=tf​−ti​는 충돌 시간이다.

같은 충격량이라도:

  • Δt\Delta tΔt가 짧으면 → FavgF_\text{avg}Favg​가 크다 (딱딱한 바닥)
  • Δt\Delta tΔt가 길면 → FavgF_\text{avg}Favg​가 작다 (에어백, 매트)

자동차 에어백 은 충돌 시간을 늘려서 평균 힘을 줄이는 장치다!

9.5 운동량 보존 법칙

유도

두 입자가 서로 충돌할 때, 외부에서 작용하는 힘이 없다면:

F⃗net, ext=0⇒dP⃗dt=0\vec{F}_\text{net, ext} = 0 \quad \Rightarrow \quad \frac{d\vec{P}}{dt} = 0Fnet, ext​=0⇒dtdP​=0

따라서:

P⃗i=P⃗f\vec{P}_i = \vec{P}_fPi​=Pf​

m1v⃗1i+m2v⃗2i=m1v⃗1f+m2v⃗2fm_1\vec{v}_{1i} + m_2\vec{v}_{2i} = m_1\vec{v}_{1f} + m_2\vec{v}_{2f}m1​v1i​+m2​v2i​=m1​v1f​+m2​v2f​

외력이 없는 계에서, 총 운동량은 보존된다.

이것이 운동량 보존 법칙(conservation of linear momentum) 이다.

운동량 보존의 적용 조건

운동량 보존이 성립하려면:

  1. 계(system)를 잘 정의 해야 한다 — 상호작용하는 물체를 모두 포함
  2. 알짜 외력이 0 이어야 한다
  3. 특정 방향으로만 외력이 0이면, 그 방향의 운동량만 보존 된다

예시: 마찰 없는 수평면에서의 충돌

  • 수직 방향: 수직항력과 중력이 상쇄 → 외력 0
  • 수평 방향: 외력 없음 → 수평 운동량 보존!

9.6 운동량과 운동에너지

충돌의 종류

충돌은 운동에너지 보존 여부에 따라 분류한다:

종류 운동량 운동에너지
탄성 충돌 보존 보존
비탄성 충돌 보존 보존 안 됨
완전 비탄성 충돌 보존 최대 손실 (결합)

모든 충돌에서 운동량은 보존 된다 (외력 없을 때).

운동에너지는 탄성 충돌 에서만 보존된다.

9.7 1차원 탄성 충돌

두 보존법칙

1차원 탄성 충돌에서는 두 가지 보존법칙을 동시에 적용:

운동량 보존:

m1v1i+m2v2i=m1v1f+m2v2fm_1 v_{1i} + m_2 v_{2i} = m_1 v_{1f} + m_2 v_{2f}m1​v1i​+m2​v2i​=m1​v1f​+m2​v2f​

운동에너지 보존:

12m1v1i2+12m2v2i2=12m1v1f2+12m2v2f2\frac{1}{2}m_1 v_{1i}^2 + \frac{1}{2}m_2 v_{2i}^2 = \frac{1}{2}m_1 v_{1f}^2 + \frac{1}{2}m_2 v_{2f}^221​m1​v1i2​+21​m2​v2i2​=21​m1​v1f2​+21​m2​v2f2​

미지수 2개 (v1fv_{1f}v1f​, v2fv_{2f}v2f​), 방정식 2개 → 풀 수 있다!

풀이 결과

v2i=0v_{2i} = 0v2i​=0 (표적이 정지)인 경우, 해는:

v1f=m1−m2m1+m2 v1iv_{1f} = \frac{m_1 - m_2}{m_1 + m_2}\, v_{1i}v1f​=m1​+m2​m1​−m2​​v1i​

v2f=2m1m1+m2 v1iv_{2f} = \frac{2m_1}{m_1 + m_2}\, v_{1i}v2f​=m1​+m2​2m1​​v1i​

특수한 경우들

1. 같은 질량 (m1=m2m_1 = m_2m1​=m2​):

v1f=0,v2f=v1iv_{1f} = 0, \quad v_{2f} = v_{1i}v1f​=0,v2f​=v1i​

입사 입자가 완전히 정지하고, 표적이 같은 속도로 날아간다. 당구공 의 정면 충돌!

2. 무거운 입자가 가벼운 표적에 충돌 (m1≫m2m_1 \gg m_2m1​≫m2​):

v1f≈v1i,v2f≈2v1iv_{1f} \approx v_{1i}, \quad v_{2f} \approx 2v_{1i}v1f​≈v1i​,v2f​≈2v1i​

입사 입자는 거의 그대로, 표적은 2배 속도로 튕겨나간다. 볼링공과 탁구공

3. 가벼운 입자가 무거운 표적에 충돌 (m1≪m2m_1 \ll m_2m1​≪m2​):

v1f≈−v1i,v2f≈0v_{1f} \approx -v_{1i}, \quad v_{2f} \approx 0v1f​≈−v1i​,v2f​≈0

입사 입자가 되튕긴다. 벽에 튀는 공

9.8 1차원 비탄성 충돌

완전 비탄성 충돌

두 물체가 충돌 후 결합 하여 함께 움직이는 경우:

m1v1i+m2v2i=(m1+m2)vfm_1 v_{1i} + m_2 v_{2i} = (m_1 + m_2) v_fm1​v1i​+m2​v2i​=(m1​+m2​)vf​

vf=m1v1i+m2v2im1+m2v_f = \frac{m_1 v_{1i} + m_2 v_{2i}}{m_1 + m_2}vf​=m1​+m2​m1​v1i​+m2​v2i​​

운동에너지 손실

완전 비탄성 충돌에서 잃어버린 운동에너지:

ΔK=Kf−Ki=12(m1+m2)vf2−12m1v1i2−12m2v2i2\Delta K = K_f - K_i = \frac{1}{2}(m_1 + m_2)v_f^2 - \frac{1}{2}m_1 v_{1i}^2 - \frac{1}{2}m_2 v_{2i}^2ΔK=Kf​−Ki​=21​(m1​+m2​)vf2​−21​m1​v1i2​−21​m2​v2i2​

v2i=0v_{2i} = 0v2i​=0인 경우:

ΔK=−12m1m2m1+m2v1i2\Delta K = -\frac{1}{2} \frac{m_1 m_2}{m_1 + m_2} v_{1i}^2ΔK=−21​m1​+m2​m1​m2​​v1i2​

잃어버린 운동에너지는 열, 소리, 변형 등으로 변환된다.

자동차 충돌 사고에서 차가 크게 찌그러질수록 더 많은 에너지가 변형에 흡수되어 탑승자에게 전달되는 충격이 줄어든다. 이것이 크럼플 존(crumple zone) 설계의 원리다.

9.9 2차원 충돌

2차원 탄성 충돌

2차원에서는 운동량의 각 성분 이 보존된다:

xxx성분: m1v1i=m1v1fcos⁡θ1+m2v2fcos⁡θ2m_1 v_{1i} = m_1 v_{1f}\cos\theta_1 + m_2 v_{2f}\cos\theta_2m1​v1i​=m1​v1f​cosθ1​+m2​v2f​cosθ2​

yyy성분: 0=m1v1fsin⁡θ1−m2v2fsin⁡θ20 = m_1 v_{1f}\sin\theta_1 - m_2 v_{2f}\sin\theta_20=m1​v1f​sinθ1​−m2​v2f​sinθ2​

탄성 충돌이면 에너지도 보존:

12m1v1i2=12m1v1f2+12m2v2f2\frac{1}{2}m_1 v_{1i}^2 = \frac{1}{2}m_1 v_{1f}^2 + \frac{1}{2}m_2 v_{2f}^221​m1​v1i2​=21​m1​v1f2​+21​m2​v2f2​

같은 질량의 2차원 탄성 충돌

m1=m2m_1 = m_2m1​=m2​이고 표적이 정지(v2i=0v_{2i} = 0v2i​=0)인 탄성 충돌에서:

θ1+θ2=90°\theta_1 + \theta_2 = 90°θ1​+θ2​=90°

두 물체는 항상 직각 으로 산란된다!

이것은 당구 에서 자주 관찰할 수 있다. 한 공이 다른 정지 공에 비스듬히 맞으면, 두 공의 진행 방향이 항상 90도를 이룬다.

9.10 가변 질량 계: 로켓

로켓의 원리

로켓은 질량이 변하는 계 의 대표적 예이다.

연료를 분사하면 로켓의 질량이 줄어들면서 속도가 증가한다.

로켓 방정식 유도

시각 ttt: 질량 MMM인 로켓이 속도 vvv로 운동

시각 t+dtt + dtt+dt: 질량 dMdMdM의 배기가스를 상대속도 vrelv_\text{rel}vrel​로 분사

운동량 보존 (외력 무시):

Mv=(M−dM)(v+dv)+dM(v−vrel)Mv = (M - dM)(v + dv) + dM(v - v_\text{rel})Mv=(M−dM)(v+dv)+dM(v−vrel​)

정리하면:

  • vrelv_\text{rel}vrel​: 배기가스의 상대 속도 (로켓 기준)
  • Mi/MfM_i / M_fMi​/Mf​: 질량비 (초기 질량 / 최종 질량)

로켓 방정식의 의미

Δv=vrelln⁡MiMf\Delta v = v_\text{rel} \ln\frac{M_i}{M_f}Δv=vrel​lnMf​Mi​​

  • 배기 속도 vrelv_\text{rel}vrel​이 클수록 더 빨라진다
  • 질량비 Mi/MfM_i/M_fMi​/Mf​가 클수록 더 빨라진다 (연료 비율이 높을수록)
  • ln⁡\lnln 함수이므로, 속도를 2배로 늘리려면 질량비가 제곱 이 되어야 한다

누리호(KSLV-II) 는 3단 로켓이다. 단 분리를 하는 이유는, 빈 연료 탱크를 버려서 MfM_fMf​를 줄이고 질량비를 키우기 위해서다. 1단 엔진 4기(75톤 추력 × 4), 배기 속도 약 3 km/s.

추력(Thrust)

로켓 엔진의 추력(thrust) TTT는:

T=vreldMdt=vrelRT = v_\text{rel} \frac{dM}{dt} = v_\text{rel} RT=vrel​dtdM​=vrel​R

여기서 R=dM/dtR = dM/dtR=dM/dt는 연료 소모율(질량 유량)이다.

외부 중력을 고려하면:

Ma=T−Mg=vrelR−MgMa = T - Mg = v_\text{rel}R - MgMa=T−Mg=vrel​R−Mg

추력이 중력보다 커야 이륙할 수 있다: T>MgT > MgT>Mg.
